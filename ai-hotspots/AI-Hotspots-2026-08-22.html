AI 热点综述 - 2026-08-22

2026-08-22 00:40 AI热点

🚀 Codex 三连击：透明图片、ChatGPT Site、以及针对 sub2api 的”自证”

Thibault Sottiaux（OpenAI Codex 团队）连续放出多条高热度消息，其中一条还顺带回应了社区对用量限制的质疑：

“我们调查了关于 codex 用量限制不一致的反馈。这不是我们会不跟社区沟通就擅自改动的东西。真正受影响的人里，很多在用 sub2api——把订阅转换成 API 流量再转售或共享，这种用法我们不支持，会被欺诈防护系统标记。只要你用 Sign in With ChatGPT（官方客户端或 Pi、OpenCode 等支持登录的 OSS 客户端），就完全没问题。”（2797 ❤️ / 112 🔄）

这条澄清信息量很大：订阅与 API 的边界正在被明确划线，OSS 客户端生态被官方点名认可，也侧面说明 Codex 的用量体系正在收紧风控。

同场还有两条产品消息：

“现在可以用 GPT-Image-2 在 ChatGPT 和 API 里生成透明背景图片了。这是我准备打印贴到笔记本上的仙人掌。”（2503 ❤️ / 86 🔄）

“创建一个 ChatGPT Site 分享出去，一起做点东西。我最近用它和别人一起做了不少小游戏和网站，太好玩了。”（1605 ❤️ / 64 🔄）

透明图生成 + 可分享的多人协作 Site，OpenAI 正在把”生成”变成”一起玩”。

🏛️ Boris Cherny：Mythos 级模型的”企业自托管”要来了

Boris Cherny（Anthropic）预告了一个面向企业客户的重要能力（1671 ❤️ / 95 🔄）：

“我们和客户一起推进这件事很久了。Mythos 级模型需要额外的安全措施，企业也要满足自己的隐私与合规要求。客户可以拥有并控制自己的数据，Anthropic 不保留任何数据。今年秋天上线。”

“模型进企业内网、数据完全自持”——大模型的企业级部署正在从”API 调用”走向”可自托管的基础设施”。这对金融、医疗、政府等高合规行业是实打实的信号。

“这场合作早就该来了。Replit 进 YC 之前，PG 就让 Sam 来招我们。这是 Sam 亲口讲我们第一次见面的故事。”

☁️ Guillermo Rauch：Vercel 的野望——“给 agents 用的 AWS”

Guillermo Rauch（Vercel CEO）抛出了一个新的平台叙事（387 ❤️ / 11 🔄）：

“We’re building AWS for agents.”

翻译过来就是：像 AWS 提供云基础设施一样，为 agent 提供运行基础设施。同场还恭喜了 Bun 团队（463 ❤️ / 10 🔄：“Bun 对简单、快速、开放的追求，和 Vercel 看待世界的方式完美契合”），并预告 0.0.5 版”能塞进两张软盘”，明天发布最被要求的功能（512 ❤️ / 12 🔄）。”agent 时代的云”叙事正在成为基础设施公司的新战场。

Thariq（Anthropic）发布 Fable 新能力（543 ❤️ / 15 🔄）：

🎬 Peter Yang：100K 订阅 + 一个有趣的 agent 编排想法

Peter Yang 庆祝 YouTube 突破 10 万订阅（265 ❤️ / 6 🔄），并预告了 Hamel Husain、Replit 产品工程负责人 Amol Jain、OpenAI 产品负责人 Eric Bloch 等一批重磅访谈。

更值得玩味的是他关于 agent 质量提升的”野路子”（484 ❤️ / 21 🔄）：

“我直觉上觉得，很多 AI 输出其实可以更好——只要搭一个循环，让一个 manager agent 不断『否定』另一个 worker agent：『你确定这是你最好的产出？』『我觉得你能更好，再试一次』『再仔细看看，给我 11/10 的输出』。”

“用对抗性提示词逼出更好输出”——从上一期 Boris 的 adversarial code review，到这一期 Peter 的 manager-neg-worker 循环，“AI 审 AI / AI 激 AI”正在成为社区共识级技巧。

📐 Madhu Guru：四层 eval 阶梯

Madhu Guru 的 “How to build great evals” 系列来到第 4 部分（137 ❤️ / 7 🔄），给出企业 AI 系统的阶梯式 eval 策略：

“企业做不好 AI 系统的根源，是没有 eval 策略。你需要一套分层的、覆盖成本/真实度光谱的 eval：

  • Hill-climb evals：持续推高产品边界，需要不断刷新；
  • Regression evals：确认推高边界时没有弄坏现有功能；
  • Smoke test evals：安全与绝对不能出错的底线（比如产品身份）；
  • Launch evals：接近线上真实流量，控制最少、但最真实。”

四层体系清晰可落地，值得转给每个做 AI 产品的团队。

💰 Nikunj Kothari：为什么投资人只看”万亿美金”

Nikunj Kothari 用一个长帖拆解了当下风投的数学逻辑（112 ❤️）：

“Anthropic 成了史上最快从 0 到万亿美元估值的公司；OpenAI 用更长时间做到了同样的事；SpaceX 以 1.77 万亿上市；Cursor 收购是标志性事件——四年从 0 到 600 亿，给早期基金带来真实的现金回报。LP 在用脚投票，基金规模变得巨大，于是每一笔投资都必须按『能不能到万亿』来承销。犯错不投的代价，远高于投错的代价——他们不能错过 Anthropic，即使入场价是 200、300、500 甚至 10 亿都不重要。”

“这就是为什么 pitch 的时候，野心如此重要。”

一针见血地解释了当下 AI 融资的”定价失灵”现象。
