AI 热点综述 - 2026-09-19

2026-09-19 21:59 AI热点

AI 热点综述 · 2026-09-19

今天有两条线同时在说话。

一条是**”便宜和快”本身变成了产品**：Typeface 的 Jev 在周末刷屏，Guillermo Rauch 说它的采用数据”令人震惊”，Nikunj Kothari 给出一个具体到小数点后的成绩——3000 个商品、28 秒、0.11 美元。另一条是开源模型第一次在 token 量上把闭源压到两成出头：Rauch 公布 Vercel AI Gateway 当天的数据，开源占 78.4%。

同一天，Thariq 宣布 Claude Code 开始支持 AGENTS.md——这条推文拿到 25553 赞、2174 转发，是今天绝对的热度第一。No Priors 则请来了扩散模型的奠基者之一 Stefano Ermon，节目标题直接写着”为什么扩散会赢下 AI 推理”。

一、Jev：把”便宜 + 快”做成了产品

今天关于 Jev（Typeface）的讨论密度，是最近少见的。Guillermo Rauch 那条最好懂（1796 赞、53 转发）：

“Free Jev on Vercel. I know what I’m doing this weekend 😁”

而他随后给的解释（711 赞、35 转发）比免费本身更重要：

“关于 Jev 采用情况的数据和轶事数据都令人震惊。所有人都在用它。

我觉得它是个很好的产品，但这也是’AI 太贵/太慢’这种时代情绪的下游产物。人们迫切想要优化，然后把 AI 放进更多地方！”

这条判断值得停一下。当一个模型的卖点是”够快够便宜”而不是”最强”时，它打开的往往是全新的使用面，而不是替换掉旧的使用面。 Aaron Levie 立刻给出了企业侧的具体形态（500 赞、57 转发）：

“Jev 会非常适合让 agent 在工作流里做那些瞬间判断——数据分类、judgment call，以及企业里另外几百个用例。这里有一个 Box + Jev 的快速 demo：它从 Box 里取出一份事件报告，判断它是否面向客户、严重程度如何，把文件移进 escalate / monitor / review 三个文件夹之一，并给结果打上一个 metadata 模板实例。整个过程几乎瞬时完成，且几乎零成本。

你可以想象它在保险理赔、合同管理、贷款审批、安全审查、客户日志分析里的样子。这确实是一类全新的 AI 用例。”

注意 Levie 把关键词放在了”分类”和”判断”上。 这不是”让模型写一篇长文”，而是”让模型在一批高频、低价值、但必须有人做的判断上顶上去”——这类任务的单位经济性极其敏感，$0.11/3000 次 和 $1/3000 次 的差别决定了它到底能不能部署。

Nikunj Kothari 补的两条正好是这种经济性的两种呈现：一条是成本（486 赞、24 转发）——“Jev 用多个标准给 3000 个儿童零食打分，28 秒，0.11 美元”；另一条是社区（300 赞、16 转发）——他顺手做了一个叫 Jevable 的站点，把 X 上所有 Jev demo 收集起来、按类别筛选，任何人都能用 “+” 按钮加自己的项目。

从这个角度看，Jev 今天的热度不是”模型排行榜”意义上的热度，而是”终于有人把价格打到了可以随便乱用的区间”意义上的热度。 一旦单价低到可以忽略，它的用法就不再受”值不值得调一次”约束——这才是 1796 个赞真正在庆祝的东西。

二、开源模型的 token 份额：78.4%

同一时间，Rauch 从基建视角扔出了一组数字（91 赞、3 转发）：

“看起来今天可能会是 Vercel AI Gateway 上开源模型 token 量占比的纪录日：

🟦 Open 78.4%　🟨 Closed 21.6%

虽然花费（spend）通常讲述的是另一个故事，但今天第 3 和第 4 名是 Moonshot AI 和 DeepSeek。加上 Z.ai，它们合计的花费已经超过了 OpenAI（第 2 名）。

（请注意，那是模型在各家供应商上的推理花费，主要在 US，而不是直接流向开源权重实验室的收入。）”

这条要连着上一节读。“便宜 + 快”不只是拿到了新用例，它还在把默认选项从闭源换成开源。 78.4% 是 token 量，不是收入；Rauch 自己也特意点明了这一点——token 份额和花费份额是两条曲线，前者反映”被用得最多”，后者反映”被付得最多”。 而当开源阵营在花费侧也能靠 Moonshot + DeepSeek + Z.ai 三家合起来越过 OpenAI 时，说明它已经不只是”便宜替代品”，而是在承接真实预算。

对做产品的人来说，这里的信号很直接：推理层的可替换性正在变强，模型选择正在从”押注”变成”调度”。 这也解释了为什么”agent 用哪个模型”这个问题，今天越来越像一个路由问题，而不是一个选型问题。

三、Claude Code 接入 AGENTS.md：harness 开始可定制

今天热度最高的单条推文来自 Thariq（25553 赞、2174 转发）：

“我们正在为 Claude Code 添加 AGENTS.md 支持。

从今天的 2.1.277 版本开始，如果一个文件夹里没有 CLAUDE.md，Claude 会去检查并使用 AGENTS.md。

你可以在 /config 里切换这个行为。”

这条的意义远超”多认一个文件名”。 AGENTS.md 是社区已经形成的跨工具约定——同一份项目指令可以被不同 agent 读取，意味着项目里的”给 AI 看的说明”第一次开始脱离单一厂商的私有格式。对同时用多个编码 agent 的人来说，这省掉的是维护两份甚至三份指令文件的成本。

而 Thariq 随后的两条补充（926 赞、20 转发 与 469 赞、11 转发）把背后的机制亮了出来：

“AGENTS.md 支持是建立在 Claude Code mods 之上的，这是我们即将推出的、用来定制 Claude Code harness 的方式。

这是一个内置 mod，但你也将能够按自己的意愿构建自定义版本的项目指令。”

“你可以在这里看到这个 mod 的源码！”

“harness 可定制”是这一节的真正主角。 过去一年关于编码 agent 的竞争，大多发生在模型能力层；而当一个 agent 的骨架（指令注入、上下文组织、行为开关）以 mod 的形式开放，竞争就开始下沉到”谁能被更好地塑造成你想要的那个工具”。AGENTS.md 是兼容他人，mods 是开放自己——两条一起做，才是完整的姿态。

四、播客：扩散模型会赢下推理

今天的 No Priors（2026-09-18）请的是 Stefano Ermon——长期任教于斯坦福、现在创办并执掌 Inception。节目开场是这样介绍他的：

“Stefano 在生成建模领域有着极其宽广的工作，但他尤其以’扩散模型的奠基者之一’而闻名。我们聊了他的公司如何挑战那些大实验室，以及为什么速度和效率将在未来几年成为 AI 领域的关键词。”

把这条和今天前两节放在一起，会发现它们其实是同一件事的三个切面： 开源模型在 token 量上占多数、Jev 靠便宜和快刷屏、扩散路线被请上来讲”推理效率”。今天所有的热度都指向同一个方向——推理的成本与速度，正在取代训练的能力上限，成为下一阶段讨论的中心。 当”够用且便宜”可以在 78.4% 的 token 量上成立，效率就不只是工程优化，而是决定谁能被用起来的分界线。

五、个人 agent 落地：从”能演示”到”替我砍账单”

Peter Yang 今天给了一个非常有说服力的样本（707 赞、57 转发）：

“Meta 的 @Muse 是我到今天为止试过的最好的个人 agent。

它实际上帮我在有线电视和电话账单上每年省下了 800 多美元，对一个免费的 AI agent 来说这是不可思议的价值。

这是我的新视频，我走了一遍我最喜欢的 10 个 Muse 用例，包括个性化早间新闻流、习惯追踪器，以及我是怎么让 Muse 打电话给客服、替我谈账单的。”

他还放出了一段通话转录，Muse 在这通电话里为他的 Comcast 账单谈下了 288 美元/年 的减免，并补了一句观察（230 赞、10 转发）：

“我发现这段来自 @Muse 的电话转录超级有意思……说实话，我觉得大多数公司的客服线路都还没为 agent 做好准备 😅”

这句话是今天最值得记住的一句。 当 agent 开始以消费者的身份打电话、砍价、办业务时，受冲击的不是模型，而是那些默认”对面是人”的业务流程。“客服线路没准备好”意味着 agent 已经跑到了现实世界的接口前面。

另一条同类信号来自 Peter Steinberger（83 赞），他把 agent 放进了团队协作面：

“最酷的部分是：roboclaw 跑着我们的团队服务器，在 Discord 上在线，和 gpt-live 对话，并知道它正在同时处理的所有会话。

我们可以在开会时直接问它当前和过去会话的上下文。”

以及一句关于执行层的补充（13 赞）：”CUA 在所有这些之上都能工作，所以 agent 可以比只用截图更高效。”

“会话感知 + 常驻在团队已有的频道里”，是今天个人/团队 agent 的第二个共同点：它们不再是你要专门打开的一个新窗口，而是被放进了你已经在用的地方。

六、零散但值得记一笔的信号

  • Thibault Sottiaux（3650 赞、105 转发）：OpenAI 正在准备 keynote——“我们今天和 @romainhuet、@sama 一起弄 keynote，最有意思的部分是想清楚怎么跟你们讲清楚这一切，因为里面好东西太多、又挤在一起、有点离谱。下周就会有一些东西放出来，不让你等太久。” 下周值得留意。
  • Zara Zhang（155 赞、11 转发）：”当你消费的大多数东西都是垃圾时，你很难不生产垃圾。想修正输出，先修正输入。” ——在”AI 让产出变得廉价”的这一周，这句话是对所有人的提醒。
  • Dan Shipper（23 赞）：为被指”demo 造假”的 @jackcheng 辩护——“他是我共事过的最聪明、最智识诚实、最在意 craft 的人之一。他的 demo 既真实，也是一个对未来的有趣一瞥。这不是一个好的观感！” 关于”什么算真 demo”的争论，正在成为这个行业的一种常规摩擦。
  • Claude 官号今天照例问了一句”这个周末你在构建什么？”，配着 Jev 免费和 Jevable 刚上线，这句话今天显得格外应景。

收束

如果只留一句话记住 2026-09-19：这一天的主题不是”更强的模型”，而是”更便宜的推理终于让 AI 被放进更多地方”。 开源拿下 78.4% 的 token 量、Jev 用 0.11 美元做 3000 次判断、Levie 说 agent 会在企业里做那几百个瞬间判断、Muse 已经能替消费者打电话谈账单——这些是同一件事在不同层级的投影：成本曲线一旦下来，使用面就会自己长出来。

而 Thariq 那条 25553 赞的 AGENTS.md 提醒我们另一件事：当模型本身开始同质化，真正的差异会跑到 harness 和约定层去。 谁能被更好地定制、谁的说明文件能被更多工具读懂，会越来越像今天的模型排行榜一样重要。
