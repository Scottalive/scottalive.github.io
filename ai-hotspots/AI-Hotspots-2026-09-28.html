AI 热点综述 · 2026-09-28

前天讲的是”你需要一把尺子”。今天几条最重的信号，像是那把尺子量出来的读数——而且读数都不太舒服。

Aaron Levie 说，一旦 agent 开始替用户做最优选择，靠用户惰性活着的那部分经济会被直接抹平；Thibault Sottiaux 说”code freeze 已经不是一回事了“，未来代码甚至可能按需在线生成；Peter Steinberger 更直接——他想让 codex 自己决定哪些测试真的需要跑。三件事在拆同一个前提：我们过去默认”发布是离散的、CI 是检查点、用户是有惯性的”，这套假设正在同时失效。

而人的这一侧，Thariq 留下了今天最诚实的一句：“我最害怕的，是我们把 agent 带来的生产力增益，靠变得更懒给吃掉了。”

一、当 agent 开始替你做选择，摩擦就不值钱了

Levie 今天那条（174 赞、19 转发）把因果链说得很干净：

想象一个 agent 开始替用户做出最好或最有效率的选择，会牵出多少连锁反应。

一方面，经济里有一部分是靠”客户改掉旧习惯很麻烦”来获利的。在这部分市场里，切换成本会下降，竞争会急剧加剧，直到颠覆性替代品和守成者之间达到某个新的均衡。

另一方面，有很多市场恰恰是被摩擦拖累的——agent 会让以前因为太麻烦而做不成的交易变得容易，从而释放出各类经济活动。医疗、旅行、本地服务、某些信息服务，以及一些全新的市场，大概率是 agent 的净受益方。

无论如何，一个被”不知疲倦地为我们和我们的目标工作”的 agent 深度中介的未来，不可能和今天以同样的方式运转。会很野。

这条真正的锋利处在于它把”摩擦”从一个技术词变成了资产负债表上的科目。 过去二十年，商业世界里大量价值来自摩擦——比价麻烦、迁移麻烦、退订麻烦、开新账户麻烦。当执行摩擦的一方从人变成 agent，”麻烦”这个变量就被按了删除键。 靠它吃饭的会掉利润，被它拖住的会凭空长出新生意。

Dan Shipper 用一句话把这件事的荒诞感点满了（156 赞、7 转发）：

一个建立在”把人建模成理性 agent”之上的行业，正在人类真的用上理性 agent 时陷入恐慌。

这里面藏着一个不太好笑的对称： 经济学和广告业花了几十年假设人是理性的，又花了几十年证明人不是；现在agent 真的按理性办事了，那些靠”人类不理性”贡献毛利的地方，反而成了最不稳定的地方。

而这条线其实 Levie 今天讲了两遍，只是尺度不同。他在 Training Data 那期播客里（《Box’s Aaron Levie: On Reinventing Yourself in the AI Age and Enterprise Diffusion》）给的是个人版：

我想给所有大二大三的学生发一条紧急警报：去关注这 20 个账号。还有，上 Twitter……你比人领先一年还是落后一年，仅仅取决于你的信息流。 我的信息流就是这样接进来的。到现在我还会跟二十岁出头的年轻人聊，他们说”我看了一些文章”——我就想，你这是什么意思？

长尺度上，agent 消解的是”用户摩擦”；短尺度上，它消解的是”信息摩擦”。 两者是同一个机制：当”知道”和”做到”的成本同时塌向零，剩下的差异就只有东西本身好不好。

二、”code freeze 已经不是一回事了”

Thibault Sottiaux 今天贡献了全天最重的一条数据（6051 赞、165 转发）：

code freeze 在发布前已经不是一回事了；而在未来，代码甚至可能是按需在线生成的——根据某些约束在请求到来时当场生成。

同一位今天还有一条只留了省略号的帖子（6512 赞），热度更高——这本身就挺说明问题：在最前沿的基础设施团队里，”发布”这个词的语义正在变得可疑。

Peter Steinberger 从工程实践里给出了同一结论的操作版（571 赞、14 转发）：

一样。@useblacksmith 一直是极好的赞助商，但我们得把负载分散开。

我的计划是让 codex 决定哪些测试实际上需要跑，大幅砍掉 CI，改成每小时跑一次测试。

这两条合起来看，”发布”作为一个事件正在融化。 过去 code freeze 之所以成立，靠的是”改动停下来之后才有办法验证”；CI 之所以是检查点，靠的是”每次合并都必须过同一道闸”。而当验证可以按需生成、测试可以按小时跑而不是按合并跑、并且”哪些验证是必要的”这个判断本身交给模型——“冻结”就失去了对象。

顺手接回前天的主题： 判断”什么算验证通过”的能力，正在从人写的流水线配置里搬走。表面上是 CI 被 nix 了，实质上是”验收标准”这个权力被交出去了。 交得对不对，还是那个问题——你有没有尺子。

三、Native is the future：一次自上而下的重新平台化

Guillermo Rauch 今天交了一份很硬的工程作业（508 赞、15 转发）：

我把我的 Mini 浏览器移植到了 Rust & Swift。更快、更安全，而且迭代起来竟然比 Electron + Bun 更舒服。

我一直想要 Safari 那样的体验，但内核是 Chrome 😁。多亏了 cef crate，我能打包最新的 Chromium。

fx acp 让我能在不把 app 撑爆的前提下嵌入一个 agent：它通过 ACP 跟我本地的 fx CLI 说话，fx 再通过 MCP server 去管理浏览器。

扔掉 Electron 之后，我拿到了 Liquid Glass、更快的启动，以及更 Mac 原生的手感。像细粒度焦点和输入控制这种在 JS 里是噩梦的东西，直接就 work 了。

Native is the future，桌面端和云上都一样。 我怀疑整个软件世界会比大家预想的更快地”原生化”，就像 DHH 在 Rails World 上暗示的那样。很兴奋 Vercel 在 Fluid 上的投入会支撑这件事，不管你是选 Rust、Go、Zig 还是 scriptc……

在这个过程中我了解了 ACP，我现在对它非常兴奋——它会让暴露 MCP 工具这件事变得更安全、更直接。

注意他给出的理由的顺序：不是性能第一，而是”能更干净地嵌入 agent”排在最前面。 一次从 Electron 到原生的重写，驱动力是给 agent 留一个不出血的接口——ACP 管 app 与本地 CLI 的对话，MCP 管 CLI 与浏览器的动作。这是今天最具体的一张”新架构图”：原生外壳 + 本地 agent CLI + MCP 触手。

“整个软件世界会更快地原生化”这句话如果成立，含义不只是技术栈换代。 过去十年那批”用 Web 技术重做一遍桌面软件”的公司，其护城河是跨平台和迭代速度；如果这两项的收益被”原生 + agent 嵌入”反超，它们会同时失去当年颠覆别人的理由。

四、最诚实的恐惧：别把增益吃成更懒

Thariq 今天这句（4322 赞、92 转发）被转得最多，也最值得抄在本子上：

我最害怕的，是我们把 agent 带来的生产力增益，靠变得（自己）更懒给吃掉了。

为什么这句话比”AI 会不会取代人”更值得讨论？因为它描述的是一个不需要任何灾难就能发生的失败。 不需要模型变坏、不需要对齐出事——只要把省下来的时间交还给刷信息流，增益就自动归零了。 而这件事没有任何外部指标会报警：产出还在，效率看着还高，只是不再有人往深里走。

Zara Zhang 那条正好是它的人格版本（354 赞、22 转发）：

问”你为什么一直发内容却不变现”的人，不理解两件事：

  1. 自我表达是人的本能，不需要理由，也不需要功利动机
  2. 影响力比钱值钱得多

配套还有一条更冷的（68 赞、1 转发）：

新技术可以耀眼到让我们看不见它哪里不行——而且有时会让你觉得，如果有什么东西不工作，那大概是你的问题，不是技术的问题，因为世界跑得这么快，所有人都好像跑在你前面。

“所有人都好像跑在你前面”和 Thariq 的”吃成更懒”是同一个心理结构的两个面。 一个用忙碌掩饰没有深挖，一个用焦虑掩饰没有判断。而 Matt Turck 那句（53 赞、5 转发）恰好给出了对照：

一直很值得注意的是：很多真正懂 AI 怎么运作的 AI 研究者，既不信 AI 末日，也不信不可控的加速；而那些对 AI 了解有限的非研究者，观点却非常明确且笃定。

了解得越少，答案越确定。 在一个”所有人都像跑在前面”的年份，能容忍自己说”我还不确定”，本身是一种被低估的能力。

顺便记一条今天的减压片段——Amanda Askell 的香水实验（869 赞、14 转发）：

我想弄清楚，我讨厌香水是不是只因为我从没拥有过一瓶好的。于是我研究了一堆最贵、评价最好的香水，每样买了一小瓶试用装。现在我确信：所有香水都很难闻。

（以及前面那句更狠的：“那些号称写实的柑橘调香水，闻起来最多也就是橘子叠在臭鼬上。”）

一句话总结今天： 今天几条最重的信号都在拆同一套旧前提——**Levie 说 agent 替用户做选择之后，靠”切换很麻烦”活着的那部分经济会被抹平（而他自己在播客里给出的个人版本是”你的信息流决定你领先还是落后一年”）；Thibault 说 code freeze 已经名存实亡、未来代码可能按需生成；Steinberger 干脆把”哪些测试该跑”交给 codex；Rauch 用一次 Electron→Rust/Swift 的重写说明，原生化的第一驱动力是”能干净地嵌入 agent”。而在人的这一侧，Thariq 给出了今天最该被记住的警告——最大的风险不是 agent 不够强，是我们把省下来的时间又交还给了懒惰。尺度不同，机制同源：当摩擦和信息差同时塌向零，剩下的只有东西本身好不好，以及你有没有一把自己的尺子。
