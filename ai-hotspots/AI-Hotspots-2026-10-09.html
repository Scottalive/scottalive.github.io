一、OpenAI：Thibault 的”Day 4”，把 steering 做成实时

Thibault Sottiaux 今天延续连播式发版，头两条分量都不轻（19591 赞、486 转发；8346 赞、268 转发）：

Today, we are announcing ChatGPT. It is here:

Day 4/ We have improved steering to be instant, leading to the model now reacting much faster to adjustments you make, allowing you to course-correct direction in realtime and not have the model waste effort. Also releasing GPT-6.1 Sol ultrafast. The two work very well together.

“即时 steering”解决的是一个很具体的老问题：以前你发现模型跑偏，得等它跑完这一轮才能纠；现在它能在过程里被”掰回来”。这比单纯堆能力更接近”和 agent 一起干活”的真实手感——也正好呼应了同一天 Madhu Guru 说的”agent 是主要用户”：当交互变成实时协作，“能不能随时改方向”比”一次答得对不对”更影响体验。

五、Madhu Guru：agent 是一等用户，整个计算栈要重建

Madhu Guru 今天给出一条野心很大的判断（387 赞、36 转发）：

There are massive startup opportunities hiding in plain sight: every layer of the computing stack will need to be rebuilt for agents. For the last few years, most of the focus has been on making enterprise software agent-ready: APIs, connectors, MCPs. Now personal agents are forcing the same conversation for consumer products — e-commerce is an early example… Desktop and mobile OSes where agents are first-class users. Cloud infra built for agents to operate directly. Identity, permissions and security designed for thousands of agents acting on our behalf. Interfaces designed for agent and human users or both working together. If you’re looking for startup ideas, go through each layer of the computing stack and ask: what has to change when the primary user is an agent?

“当主要用户是 agent，每一层要改什么”——这是一个可以照抄的选题框架，也是一种立场：过去几年是”帮人用的软件适配 agent”（加 API、加 connector、加 MCP），接下来是”为 agent 原生重造软件”。 这和阿隆·莱维同一天说的”未来是 headless”（见下节）几乎是同一句话的两种说法。

六、Aaron Levie：对 AI 好一点，与 Box Mount 的”无头未来”

Box 的 Aaron Levie 今天两条从”政策”到”产品”各占一头。先是那条容易被当段子、其实逻辑很硬的话（337 赞、24 转发）：

This sounds weird, but it is actually probably a good policy. Even if you don’t believe AI is conscious (I don’t), it stands to reason that you don’t want future models trained on endless content of humans being rude to models… So if you want safe and aligned models we probably want AI to have lots of good interactions in their training data… this is sort of an easy Pascal’s wager for AI. Just be nice to the AI.

另一条则把”agent 需要像人一样用文件系统”落成产品（99 赞、16 转发）：

We built Box Mount to allow developers to mount Box as a file system directly in any agent sandbox. As agents do more complex work, they need to be able to work with files and data just like a person would. The future is headless.

“训练数据里别塞满人类对模型的粗鲁”——这个论证很刁钻：它不诉诸”AI 有没有意识”，而诉诸”你想要什么样的模型”。而 Box Mount 那句”The future is headless”则是第五节 Mike-式判断的落地版：agent 要直接操作文件与数据，“界面”对 agent 而言可以不存在，底下的文件系统才是真接口。

七、Nikunj Kothari：种子轮创始人的三个选项

Nikunj Kothari 今天把一段”每周至少发生两次”的对话写了出来（222 赞、5 转发）。朋友公司”增长有客户、跑得快没到起飞、快到 100 万美金收入“，但跑道在缩，且觉得模型还没追上自己想要的能力。他给的框架只有三条：

  1. 如果你对公司有极强信念，就做一只蟑螂，先做到默认盈利；等能力到位、需求能被感知，再融大轮去搏一把。
  2. 找一个正交、且正在疯长的领域，借新能力的”衣尾”用不对称优势快速吃下。
  3. 卖掉 / acquihire，进一家更狠的公司，1–2 年后找到下一个想做的事再出来创业。

他的落点是（原文）：“…the bar continues to get harder every month on how to cross the chasm from seed -> Series A. The old school metrics are just not relevant anymore… you could lament that this is the state of the market, but it’s better to know it’s happening than be oblivious.” “蟑螂模式”这个词值得记：在能力尚未追平野心的窗口期，先活下来、先默认盈利，比急着证明 TAM 更务实。 这也和昨天 Agarwal 那句”我能造正在变成更弱的答案”遥相呼应——在模型还差的领域，赌的是”你比别人多扛几个月”。

八、Dan Shipper：Checks——给”模型够不够好”一个个人化答案

Dan Shipper 今天放出一条招聘（147 赞、10 转发）：

NEW JOB ALERT: @every we’ve built a personal benchmarking platform, Checks, to help anyone measure how good new models are for their real work… we’re looking for someone who understands why this is so important.

“个人化基准”正好补上了模型评测的一块空白：公开榜单衡量的是平均能力，但”这个模型对我这摊活到底行不行”没有榜单。当模型一代比一代密集地出，”用你自己的任务去测“会成为刚需——这也是第六节 Levie 那句”逻辑不对但值得做”的镜像：价值不在”最强模型”是谁，而在”对我而言哪个够用”。

九、Matt Turck × Andy Pavlo：当数十亿 agent 撞上数据库

Matt Turck 今天放出一期与Andy Pavlo的对谈，信息密度很高（109 赞、18 转发）。他列出的时间轴本身就是一份”数据库 × agent”的速览：

00:00 冷开场 & 介绍 ｜ 01:21 从向量数据库和 RAG 到 agent 时代 ｜ 04:09 Neon 的数据：agent 创造了 80% 的数据库？ ｜ 07:25 为什么 agent 老是删生产库 ｜ 08:19 护栏：“幼儿与楼梯”原则 ｜ 10:51 数据库流量的四个时代：10–100 倍的查询量 ｜ 15:10 agent 记忆：文件 vs. 数据库（”一切皆数据库”） ｜ 23:14 面向数据库的 MCP，text-to-SQL 从 60% 到 99.5% ｜ 27:09 像信任一个初级开发那样信任 agent ｜ 29:57 60% 的开源数据库已有 AI 提交 ｜ 33:52 LLM 改变了什么：85% 的调优在 15 分钟内完成 ｜ 1:08:34 数据库市场是否停滞？”开法拉利的嗑药猎豹“ ｜ 1:10:14 关系模型是算术，SQL 是新的汇编语言

三条最值得抄走： ① “像信任初级开发一样信任 agent”——把权限与审查对标到人，而不是对标到”能或不能”；② “agent 记忆：文件 vs 数据库”——和第六节 Box Mount、第五节”一切为 agent 重建”是同一组技术选择的三个视角；③ “85% 的调优在 15 分钟内完成”——当 LLM 把过去的专家活压到 15 分钟，DBA 的价值会从”调得动”转向”知道什么时候不该调”。
