今天点赞最高的一条，是一个 agent 替主人把税报了：Thibault Sottiaux 写”我的工作 dot『Burger』在我个人 dot『Dorito』的请求下，通过邮件和它协调取文件，然后它再去和我的会计师协调，把一些税务材料报了。全程 20 分钟。我们还太早期了。”（4351 赞、77 转发）。同一天，数据库领域的 Andy Pavlo 在播客里说了一句更冷的实话：“每个月都有故事，某个人因为 agent 删了东西而丢掉了生产数据库。” 一边是 agent 开始有自己的身份、邮箱和委托链，一边是它们已经能删掉你最重要的那张表——今天的主线，是 agent 从”对话框里的助手”变成了”有凭据的同事”，而基础设施还没准备好接住这件事。

一、两个 dot 互相发邮件：agent 第一次像”同事”

Thibault 今天的三条推文构成了一个完整的小叙事：

Done（6188 赞、120 转发）

Landing sometime today by EOD PST（2607 赞、45 转发）

我的工作 dot “Burger” 在我个人 dot “Dorito” 的请求下，通过邮件和它协调取文件，然后它再去和我的会计师协调，把一些税务材料报了。全程 20 分钟。我们还太早期了。（4351 赞、77 转发）

第一条和第二条是发布节奏，第三条才是新闻。 请注意这条推文里藏着三层东西：

  • 身份：”work dot” 和 “personal dot” 是两个独立实体，各有各的邮箱、各有各的权限边界。agent 不再是你账号下的一个会话，而是一个可以被指派的身份。
  • 协议：它们之间的协调方式是邮件——不是某个私有 API，不是 MCP 工具调用，而是最古老、最通用、跨组织零门槛的那套协议。当 agent 要跨越”我的”和”别人的”边界时，它落回人类已经铺好的那层轨道。
  • 委托链：我的 dot → 我的会计师。中间没有任何一步需要我出现。20 分钟做完的，是过去要来回几封邮件、等几天的事情。

“我们还太早期了”这句话，值得单独拿出来看。 说这话的人是 OpenAI 负责 Codex 的人，他刚让两个 agent 替他办完了一件真实的、有法律后果的事，然后说”太早期”。这不是谦虚，是产品负责人对”可靠性”的诚实校准：这次成了，但没人敢说下次一定成。而 agent 的产品化，恰恰卡在这个”下次一定”上。

二、Pavlo 的警告：agent 最终会撞上数据库

今天唯一的播客来自 The MAD Podcast with Matt Turck，嘉宾是 Andy Pavlo，主题是《What Happens When Billions of AI Agents Hit Your Database?》：

什么是文件系统？它就是数据库。对吧？一切都是数据库。

每个月都有故事，某个人因为 agent 删了东西而丢掉了生产数据库。

对不了解数据库历史的人来说，这就是蛮荒西部。这就像……给一只猎豹喂了大量可卡因，然后把它塞进法拉利。人们开发这些东西的速度，疯得离谱。

“一切都是数据库”这句话，是理解 agent 基础设施的起点。 模型可以重跑，prompt 可以重试，但 DELETE 不能重试。agent 的记忆、状态、任务队列、工具调用日志，最后都落在某张表里；而一旦它拿到写权限，它就成了你系统里权限最大的那个用户——同时也是最不可预测的那个。

Pavlo 的比喻里恰好有三个要素：猎豹（能力）、可卡因（速度与激励）、法拉利（基础设施）。危险的从来不是单项，而是组合：一个跑得极快、被激励着不断行动的东西，被放进一台你舍不得踩刹车的机器里。这也解释了为什么”给 agent 一个沙箱”这件事，正在从最佳实践变成硬性要求——分支数据库、最小权限、可回滚的快照，本质都是在给法拉利装刹车。

配上第一节看，今天的两条最高热其实在说同一件事的两面：agent 已经能代表你去和第三方交涉（能力），也已经能在没人盯着的时候删掉生产库（风险）。中间缺的那一层，不是更聪明的模型，而是授权、审计与回滚。

三、Levie：不是软件变少了，是”值得变成软件的东西”变多了

Aaron Levie 今天拿到了技术圈最高的一条（806 赞、92 转发）：

所有预测软件工程终结的人，最大的误读是：他们以为世界只需要一定数量的软件，所以把自动化带进这个领域就会减少对劳动力的需求。

事实恰恰相反——几乎所有东西都在变成软件。因为 agent 会使用工具、会操作电脑、会现场写软件、会像人一样（但快得多）处理数据，我们现在可以把”软件”扔向那些过去根本没法合理数字化的问题。

结果是，工程在经济中的角色变得更重要了，因为我们现在能工程的系统和流程，比过去多得多。

是的，未来我们不会再手工写代码。但几乎一切都会是代码，这意味着懂它的人处在一个极好的位置。

这段话的价值在于它把”需求”重新定义了一遍。 争论”AI 会不会取代程序员”时，双方默认软件的总量是固定的——而 Levie 说总量根本不固定，边界在往外扩。第一节里那件报税的事就是最好的例子：它本来是文书工作，不是软件需求；现在它变成了一条可以被编排的流程，也就变成了软件需求。

“几乎一切都会是代码”是一句很重的判断。 它意味着未来的工程师不是”写代码的人”，而是决定什么该被写成代码、以及怎么让它可靠运行的人。这和昨天他讲的 RSI、前天讲的”后台 agent 是 100X–1000X token”是同一条线：供给侧在自我加速，需求侧在向外扩张，两边同时打开。

四、Claude Code 更快了，Replit 说 OpenAI 是”首选伙伴”

产品层面的两条消息，今天都拿到了不错的互动。

Peter Yang（225 赞、5 转发）：

必须给 @amorriscode 和团队记一功——Claude Code 的 app 现在快多了，而且可以说比 ChatGPT 更好用。

唯一还缺的是更好的浏览器/电脑操作、对全部会话的远程控制，以及实时语音。

Amjad Masad（415 赞、19 转发）：

澄清一下：Replit 依然与模型无关。我们的用户可以选择 Anthropic 的模型，也可以选择许多其他受支持的模型。

我在 TC Disrupt 上想说的是，OpenAI 现在是我们首选的合作伙伴，为 Agent 提供动力，这是基于性能、成本和合作强度做出的选择。

我们相信要给用户模型选择权，同时把默认体验优化到最佳性能与最佳价格。

“模型无关”和”首选伙伴”可以同时成立，这是 2026 年 AI 产品的标准架构：默认值收窄，选择权放开。 默认体验用一个模型调到最好——因为大多数用户不会去调；选择权留给需要的人——因为采购和合规部门会问。把这两件事分开讲，是一种成熟的产品语言。

而 Peter Yang 列的三个缺口很值得注意：浏览器/电脑操作、全部会话的远程控制、实时语音。这三件恰好对应 agent 从”聊天窗口”走向”操作台”的三步：能看屏幕、能离开桌面继续跑、能随时插话。今天的 agent 已经能写代码，但还不能像人一样”在旁边看着它干”。

五、注意力没有变便宜：Swyx 的一组数字

在一片发布与融资之间，Swyx 贴了三组很干的运营数据（互动不高，但信息密度最高）：

我们从五月（AIE EU 之后）起几乎不间断地每月服务超过 100 万独立观众，但即使到现在，每月仍有 58% 的观众是新的。68% 的观众没有订阅，笑。

大多数观众集中在太平洋时间每天早 7 点到 11 点。下午 5 点之后没人看。

（关于推荐曲线的图）基本上前两年无人问津，然后我们慢慢开始被浏览推荐。我们的点击率很烂。

在一个生产变得极其便宜的世界里，注意力是少数没有跟着贬值的资源。 100 万月活、58% 是新观众、68% 没订阅——这组数字说明增长的来源是推荐而不是订阅，也就是说，内容方对分发的控制力比看上去更弱。而”下午 5 点后没人看”这种细节，是任何模型都算不出来的东西：它只能来自长期盯后台。

这三条放在今天很合适。 前面四节都在讲 agent 能做什么，这一节提醒：做出来的东西要被人看见，仍然遵循人类作息。

  • Peter Yang（44 赞、7 转发） 给了一个很实用的 prompt：如果你像他一样有 45 个 app 和 agent 连在 Google 账号上，就让 AI 逐个审计连接、区分”基础登录”和”读取 Gmail/Drive/Calendar”的权限、给出去留建议、并且在改动前先给你看方案。“45 个”这个数字本身就是今天最真实的注脚——权限债已经日常化了。

一句话总结今天： 最高热是 Thibault 的两个 dot 互发邮件、20 分钟把税报了（4351 赞）——agent 第一次以”有身份的同事”而不是”更快的输入框”出现；而给它泼冷水的是 Andy Pavlo 的播客：每个月都有人因为 agent 删了东西而丢掉生产数据库。夹在中间的是 Levie 的 806 赞——不是软件变少了，而是值得变成软件的东西变多了，”几乎一切都会是代码”；以及 Amjad Masad 的”模型无关 + OpenAI 首选伙伴”——默认值收窄、选择权放开，正在成为 AI 产品的标准架构。当 agent 拿到凭据、可以代表你签字、也可能一键删库，真正稀缺的就不再是智能，而是可授权、可审计、可回滚的那层地基。
