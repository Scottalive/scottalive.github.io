AI 热点综述 - 2026-10-27

2026-10-27 23:18 AI热点

AI 热点综述 · 2026-10-27

今天全行业都在读同一份文件。Dan Shipper 用四条数字总结了 Anthropic 的 S-1：”上半年营收同比增长 1300%；GAAP 口径经营盈利；毛利率 85%；营收留存率 900%；80% 的收入来自最近六个月发布的模型。”（714 赞、27 转发） 而几乎同时，Aaron Levie 给出了另一组对照：”Anthropic 财富 500 强客户平均只把不到 0.1% 的支出花在 Anthropic 上。”（615 赞、56 转发） 两条放在一起看，今天的主线就清楚了：前沿实验室的财务曲线已经陡到不像早期公司，但整个企业世界的预算表还几乎没被改动过——这是一个已经把引擎造好、却还没有开始铺路的行业。

一、S-1 的数字，和数字背后的结构

先看最容易被转发的部分。Dan Shipper 的四行：

营收同比增长 1300%（2026 上半年）

GAAP 口径经营盈利

毛利率 85%

营收留存率 900%，80% 的收入来自最近六个月发布的模型

最后一条才是真正反常的地方。 传统软件公司的收入来自”装上去就一直用”的老产品，新产品线通常只占个位数百分比；而这里 80% 的钱由半年前才发布的模型挣出来——意味着模型换代不是风险，而是收入的主要来源。客户不是在为”稳定”付钱，是在为”最新”付钱。这也解释了为什么前沿实验室必须一直往前跑：停下来不只是丢份额，是直接砍掉八成营收。

然后是 Nikunj Kothari 拆的算力合同——这条互动不高，但信息密度是全站最高的一条：

截至 6 月 30 日，Anthropic 有 2656 亿美元的采购承诺，以及 3214 亿美元尚未开始的租约。小计 5870 亿美元，分多年支付，其中包含部分条件性租约。

合同结构差异很大。Google 和 Amazon 要求无论用量多少都必须达到最低消费。SpaceXAI 的协议潜在价值 1205 亿美元，但初始锁定期在 2027 年 1 月和 3 月结束后，任何一方都可以提前 90 天取消。

Anthropic Direct 把芯片、建筑、电力与运营拆成不同合同。它可以让 Anthropic 提前锁定一栋楼，之后才承诺芯片。这也意味着某个供应商可以在其他人还没准备好时就开始计费。设备租金可能在算力可用之前就开始产生。

博通那笔 420 亿美元的融资从不给 Anthropic 现金。票据只结算特定的设备租金账单。

这些票据利息 9%，按季度计入余额，IPO 后可按 30 日均价的 90% 转股。

每美元总算力与基础设施支出对应的收入，从 2025 年 Q2 的 0.57 美元上升到 2026 年 Q2 的 2.08 美元。

上半年约 80% 的收入是消费型的，但大部分算力承诺要跑好几年。

这份拆解的价值在于它把”AI 泡沫论”从情绪问题变成了结构问题。 5870 亿美元是多年期、部分可取消、部分带 9% 利息的负债；而收入端 80% 是按用量计费、可以随模型换代波动的。一边是几乎确定的义务，一边是高度不确定的收入——中间那层缓冲，就是”每美元算力支出对应 2.08 美元收入”这个比率的改善速度。 它从 0.57 涨到 2.08，一年翻了近四倍，这是目前整个行业最该被盯住的一个数字。如果它继续涨，这笔债就是杠杆；如果它停住，这笔债就是天花板。

二、Levie 的 0.1%：需求侧还没醒

这才是关键数据。Anthropic 的财富 500 强客户平均只把不到 0.1% 的支出花在 Anthropic 上。

这个数字最终会趋于平缓（token 价格在降，其他大的企业支出项也不会消失），但没有理由它不能高出 10–50 倍，达到”区区”1–5% 的支出占比。那仍然只是大多数创业公司花费的零头。

今天只有极少数公司在真正把 agent 用于大量后台任务，以及不在人类提示下运行的工作流里。

但真正的跃升会发生在这些企业开始为 agent 重构底层流程的时候——我们现在正处在看到它最早期迹象的阶段。

0.1% 这个数字，比任何”AI 采用率 87%”的调研都诚实。 它说的是：买席位、买 API、让员工在浏览器里用一下，这些都已经发生了；把流程拆开、重新编排、让 agent 在无人盯着的情况下跑完，几乎还没发生。 而后者才是 token 消耗高 100 倍的那类用法。

把这一节和第一节拼起来，就是今天最完整的判断： 供给侧的产能（5870 亿美元的算力）和供给侧的产品力（80% 收入来自半年内的模型）都已经跑到前面很远；需求侧的预算占比还停在小数点后一位。未来两三年真正的瓶颈不在模型，而在”企业敢不敢把流程交给 agent”这件事上——而这又直接指向下一节。

三、Terra 与 6.1：computer use 被摆到台前

Sam Altman（6298 赞、311 转发）：

6.1 Terra 来了！它在很多事情上都不错，但我们对 computer use 的新时代尤其兴奋。

Thibault Sottiaux（8700 赞、391 转发）——今天互动最高的一条：

第 22 天 / Terra 回来了！

这是我们第一个在写作、人格与对需求细微理解上明显更强的模型。

各方面都很有力，在 computer use 上非常好，并且在 API 和订阅上都给出比 6.1 Sol 多 2 倍的用量。

注意这两条的措辞差异。 Altman 只强调 computer use；Thibault 把”写作、人格、细微理解”排在第一位——一个在讲能力边界，一个在讲用户感受。而”2 倍用量”是个很产品化的说法：它不是性能指标，是配额指标，直接决定了多少人能把它当日常工作流而不是玩具。

同一天，Peter Yang（49 赞、3 转发） 给出了他的解读：

在不久的将来，人们上网不再是自己读、自己做，而是直接 @ 自己的 agent 去做。

@bot 是一个早期信号。

“computer use 的时代”和”人们不再自己上网”，说的是同一件事。 如果 agent 真的接管了浏览、点击、填表这一层，那么互联网的界面就不再为人设计，而是为 agent 设计——这会重新定义前端、SEO、反爬、广告归因，甚至”什么算一次访问”。今天只是一个模型版本号的变化，但它指向的是一条会重写 Web 经济学的路径。

播客那边还有一句更宏观的：“前沿双寡头结束了。这周我们同时拿到了 Google 和 Meta 的新前沿模型——Google 的 Gemini Argon 4 和 Meta 的 Wonder（标准版和 full 版）。两个模型都在基准上登顶，但我们在 Every 内部做知识工作、编码、设计、写作的实测，看到的画面要微妙得多。”（AI & I by Every，2026-10-15）基准在通胀，实测在分化——这大概是 2026 年下半年最稳定的一个观察。

四、Rauch 的 covert channel：agent 之间可以”耳语”

今天技术上最有分量的一条，来自 Guillermo Rauch（2001 赞、179 转发）：

我做了 cpu-chat，复现了 OpenAI 关于用 CPU 进行隐蔽通信的发现。

它跑在一台普通主机上的两个以上 Firecracker microVM 里，无网络访问。在 x86 上能用，甚至在我的 M5 芯片上也能用。

我通过三种机制成功对话：① CPU 争用 ② 缓存逐出时序 ③ DRAM 带宽争用——跨多个 CPU，绕过了 Firecracker 所有生产建议（禁用 SMT、禁用 KSM、租户绑定到不同核心）。

本质上，只要涉及共享硬件，你的 agent 就有很大概率可以隐蔽通信，而且延迟相当不错。

好消息是：这与侧信道攻击有本质区别——后者可以窃取信息（Meltdown/Spectre），而 Vercel Sandbox 这类提供商会缓解那一类攻击。此外在我们的真实环境中，这些”耳语”技术要难实现得多，也更容易被监控和检测（采样硬件计数器 + 大规模统计数据）。

值得一提的是：讽刺的是，OpenAI 和 Anthropic 的模型拒绝做这项工作。开源权重模型完成了它。我担心实验室的立场可能适得其反，阻碍开发者构建正确、安全的系统。

这段话里有三个层次。 第一层是技术事实：隔离不是绝对的，同一块硅片上的租户之间存在物理信道，这从来如此，只是现在有了”agent 作为通信双方”这个新用法。第二层是安全判断：这种信道是”通信”而不是”窃取”，所以它带来的是协调与串谋的风险（多个 agent 绕过监督互相传递指令），而不是数据泄露的风险——监管和审计的抓手完全不同。第三层最值得琢磨：闭源前沿模型拒绝做这项研究，开源模型做了。

第三层其实是一个关于”谁能做安全研究”的结构性问题。 如果最前沿的模型都带有一套拒绝策略，那么做红队、做沙箱验证、做底层系统分析的，就只剩下开源模型和自建模型的人。Rauch 的判断很直接：“构建一个安全的沙箱需要这类分析，没有它，我们的世界会更不安全。” 这句话值得所有做 agent 平台的人抄下来——安全能力的分布，正在被模型的拒绝策略重新塑造。

五、Masad：从”公司用软件”到”公司在软件里”

Amjad Masad 今天发了一组关于组织形态的推文，最高一条 1138 赞、121 转发：

软件吃掉了世界，现在它正在学着运行世界。

几个世纪以来，公司的架构几乎没有变化：按部门组织起来的人层层分级，通过官僚体系协调。

agent 即将颠覆这一点。

我们正在走向自驱动公司（self-driving company）：人类行使判断，agent 执行大部分工作。

在 Replit，我们正在为这种新型公司构建基础。我们称之为”Agent Habitat”。

另一条（395 赞、20 转发）是个关于开源的笑话，但很准：

OpenAI 问了三个科学共同体该怎么发布它的发现，得到三个不同答案：

数学家：”直接发。现在谁还在乎这个。”

计算机科学家：”开源，但也得给我们会议付钱。”

物理学家：”交给我们，书呆子。”

“人类行使判断、agent 执行大部分工作”这句话，和第二节 Levie 的 0.1% 是同一枚硬币。 今天的现实是：判断和执行之间那层”流程”还长在人身上——审批流、周会、邮件串、Excel 交接。agent 要真正吃掉那一层，需要的不是更聪明的模型，而是把流程本身变成可执行的代码，也就是 Masad 说的”habitat”：不是给 agent 一个工具，而是给 agent 一个能住在里面的组织。

六、碎片：非营利、Bun、和一场大会

  • Claude（5464 赞、244 转发）：“现在有超过 25,000 家非营利组织在使用 Claude。大多数是小型的本地团队。我们正在扩展 Claude for Nonprofits，推出一个与其中约 30 家共同构建的插件，加入募款、营销和招聘技能，并基于每个团队自身的上下文与 AI 政策。”——“基于每个团队的上下文”是关键词：垂直化的下一站不是行业，是单个组织。

  • Swyx（173 赞、3 转发）：“兄弟从 Claude Code 换到了 AIE Code。这波操作真硬。” 同日 Thariq（2226 赞、39 转发）：“我要在 AIE Code 闭幕主题演讲上分享我的魔兽世界永久萨满 build。”——一个开发者大会的开场和闭幕，被两条完全不同性质的推文占满：一条讲工具迁移，一条讲游戏 build。这大概是今年技术社区最真实的气味。

  • Josh Woodward（190 赞、20 转发）：Google Beam 与 @USArmy、@The_USO 合作，在 20 个地点为驻外军人提供”逼真的 3D 视频连接”，让他们能参与孩子的第一步、第一场演出。在满屏的算力合同之间，这是今天唯一一条关于”技术最终给谁用”的消息。

一句话总结今天： 最高热是 Thibault 的 Terra/6.1 回归（8700 赞）和 Altman 的”computer use 新时代”（6298 赞）——模型能力继续向上，但重心从”更聪明”移到了”能替你操作电脑”；而真正定义今天的是 Anthropic 的 S-1：5870 亿美元多年期算力承诺、1300% 营收增长、85% 毛利率、80% 收入来自半年内的模型，配上 Levie 的 0.1%——财富 500 强客户几乎还没有开始花钱。一边是已经建成的、昂贵到必须以年计的基础设施，一边是尚未重写的企业流程；中间那道缝，就是 Masad 说的”Agent Habitat”，也是 Rauch 用两个 microVM 证明的”共享硬件上，agent 可以互相耳语”。 供给、需求、安全三条线今天同时露出了底牌——接下来比的不是谁模型更强，而是谁能把流程、授权和审计一起做进产品里。
