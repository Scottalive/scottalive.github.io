📰 今日热点

今天的关键词是**「Agent 长出身体」**。GitHub 近一周新增热门项目里，有六个在做同一件事——把 Agent 的手脚接到真实世界上：zhongerxin/iPhone-use 让 Codex 通过 USB 操作一台真机 iPhone，ARahim3/DigUp 把 Google DeepMind 的 EmbeddingGemma 2 塞进本地做全盘语义检索，mhtsec/ARTEX 把自主渗透测试整条链路交给 Agent 集群。

与此同时，“Agent Skill” 正在从概念变成一种分发格式——anatomy、answer-me-with-html、huashu-art-motion、replica-skill 四个项目齐刷刷冲上榜单，全部是把某项具体能力打包成可即插即用的技能包。模型侧则是赤裸裸的价格战：Anthropic 把 Claude Haiku 5.5 的 API 价格砍掉 90%，Google 让 Gemini 4 Argon 限时降到 $2 / $10 每百万 token。

能力在往工具层沉淀，成本在往地板价滑落——两条曲线交叉的地方，就是 Agent 真正开工的地方。

⭐ GitHub 热门 AI 项目

1. openai/math — OpenAI 把数学形式化摆上了台面

  • 语言: Lean
  • Star: 14,883（Fork 1,701）
  • 地址: openai/math

仓库描述为空，名字短到只有一个词，两周内涨到近一万五千星——沉默本身就是公告。一个 openai/math 的 Lean 仓库，含义相当明确：把数学 theorem proving 与形式化验证纳入自己的技术版图。

Lean 这类交互式证明助手，过去是学术圈的硬核玩具（Mathlib 生态）。而它对企业级 AI 的真正吸引力在于：形式化证明是目前唯一一种”输出可以被机器完全验证”的推理形态。 LLM 写自然语言证明确实会编，但写 Lean 代码不会——因为编译器和内核会当场打脸。当整个行业为”如何验证 Agent 的输出”发愁时，数学形式化恰好提供了一条暴力解法：把问题转移到可验证的语言里。

为什么值得关注： 这是继代码生成之后，第二条”生成内容自带验证器”的赛道。代码有编译器，数学有证明检查器，其余领域都还没有。谁先拿下这两块，谁就拿到了可信 AI 的底座。

2. mhtsec/ARTEX — 冠军级自主渗透测试系统

  • 语言: Go
  • Star: 4,227（Fork 6,467）
  • 地址: mhtsec/ARTEX

Fork 数（6,467）大幅超过 Star 数（4,227），这个比例非常反常，通常意味着大量团队在把它当作内部系统的基础去改造——而不是收藏一下了事。它的自我描述只有一句：”AI 自主渗透测试系统 | 百度 ‘agent+’ 攻防挑战赛冠军项目”。

渗透测试是最适合交给 Agent 的攻防场景之一：信息高度非结构化、需要海量试错、反馈信号明确（通了/没通）、且过程可留痕可复现。人类专家的瓶颈是精力，Agent 的瓶颈只是额度。

为什么重要： 攻防这件事的性质变了。过去一个红队的人力预算决定了测试深度，现在决定深度的是编排质量——怎么拆任务、怎么避免 Agent 陷入死循环、怎么让人看懂它最后到底干了什么。ARTEX 的 Go 实现和冠军背书，说明这条链路已经跑得通，剩下的是工程化。

3. zhongerxin/iPhone-use — 让 Codex 用手去摸真实的 iPhone

  • 语言: Python
  • Star: 3,813（Fork 389）
  • 地址: zhongerxin/iPhone-use

“让 Codex 通过 USB 操作真实 iPhone：引导安装、App 自动化、实时屏幕与截图回退。”——这个描述里最值钱的是最后六个字：截图回退。

移动端自动化做不起来，从来不是因为没有点击接口，而是因为没有可靠的反馈闭环。iPhone-use 选择了一条务实的路：Agent 不猜测界面状态，而是拿真实屏幕截图当输入，再决定下一步点哪里；点错了就回退重来。“看屏幕 → 动手 → 看结果” 这个三段循环一旦稳定，移动端就变成了和浏览器一样的可自动化目标。

为什么重要： 桌面和浏览器早已被 Agent 攻占，移动端一直是最后一块硬骨头（沙箱、签名、无障碍接口脆弱）。用 USB + 真实设备 + 视觉反馈绕开这些坑，代价是慢，收益是它真的能用。

4. ARahim3/DigUp — 端侧语义搜索，EmbeddingGemma 2 落地样本

  • 语言: Swift（Mac / Windows / Linux）
  • Star: 3,950（Fork 270）
  • 地址: ARahim3/DigUp

“Search your computer by what’s in your files”——按内容搜你的电脑，而不是按文件名。照片、PDF、文档、录音、视频、代码全都能搜。技术底座是 Google DeepMind 的 EmbeddingGemma 2，跑在本地。

它和榜单上那批云端方案的区别只有一个词：on-device。文件索引这件事，天生的隐私密度极高——你的合同、病历、聊天截图、录屏全在里面。把它交给云端 embedding API，在合规和成本上都是灾难。一旦端侧模型能把语义检索做到”够用”，本地就不再是妥协，而是默认选项。

为什么重要： 这是”小模型 + 本地 + 垂直场景”这套组合又一次跑赢大局面的证据。基础设施层的玩家（DeepMind 出模型、社区出应用）已经开始形成分工。

5. Agent Skill 四连发 — 技能包正在成为一种分发格式

这一批项目单独看都不大，放在一起看就很有信息量：

项目 语言 Star 它把什么打包成了技能
wheresryan22/anatomy JavaScript 12,158 生成机械结构的等距插画（SVG + 可选 WebGL 着色器）
alchaincyf/huashu-art-motion JavaScript 4,043 艺术动画：35 种艺术风格、9 种解说语法
QingYunA/answer-me-with-html JavaScript 3,427 用一页可读的 HTML 回答复杂问题
Jakeschincariol/replica-skill Python 2,697 十一个免费技能：逆向任何 App → 重建 → 测 Bug → 修问题

它们的共同点不是”用了 AI”，而是产出的对象是”给 Agent 用的能力”，而不是”给人用的软件”。anatomy 自己就是给 Agent 写插画用的；answer-me-with-html 定义的是 Agent 的输出格式；replica-skill 更彻底——直接教 Agent 怎么克隆别的 App。

为什么重要： 2024 年大家比的是模型，2025 年比的是 Agent 框架，2026 年下半年比的开始是”技能”。一个技能包能同时被 Claude Code、Codex、以及任何支持 SKILL.md 约定的宿主加载时，它就具备了类似 npm package 的分发价值。生态的胜负手，从”谁的模型强”悄悄换成了”谁的技能库厚”。

6. storytold 的 Rust 重写浪潮 — 一组值得单独看的信号

同一个组织在这一周里，把五个经典桌面软件全部用纯 Rust 重新实现并同时上榜：

项目 Star 对标产品
storytold/wordcraft 12,895 Microsoft Word
storytold/gridcraft 5,060 Microsoft Excel
storytold/cadcraft 5,020 AutoCAD
storytold/deckcraft 3,369 Microsoft PowerPoint
storytold/soundcraft 2,890 Avid Pro Tools

描述里反复出现的词是 clean-room reimplementation（净室重写）——即不接触原实现代码、只依据公开行为重新实现。这在 2026 年不再需要一个几十人年的团队，因为**”依据公开行为重新实现”恰好是 Agent 最擅长的工作**：读文档、读格式规范、写测试、对着行为验收。配套的 bherbruck/solidcraft（参数化 3D CAD，支持 MCP 自动化）说明这条路线已经和 Agent 工具链打通。

为什么重要： 这组项目真正的价值不在”又一个开源 Office”。它证明了一件事——软件复刻的成本曲线已经断裂。 过去只有巨头能养得起 Office 级别的工程团队，现在一个组织一周能并行推进五个。老牌软件最深的护城河是”重写一遍太贵了”，这条护城河正在变浅。

🛠 新工具 / 产品速览

  • Gemini 4 Argon 开放 + 限时降价 — Google 将 Gemini 4 Argon 全面开放，并给出限时 API 定价 $2 / $10 每百万 token（输入/输出）。前沿模型第一次主动按”促销价”卖。
  • Claude Haiku 5.5 降价 90% — Anthropic 发布 Haiku 5.5，API 价格直降九成，直接对标 GPT-6 Luna。轻量档位成为本周厮杀最凶的战场。
  • Google Cloud 持久 Gemini Agent — 为长程任务推出常驻 Agent，并给每个 Agent 配发自己的 Gmail / Calendar / Drive 存储。持久化身份 + 持久化状态，是长程任务的最后一块拼图。
  • Meta Muse Wonder 系列 — 新模型达到前沿性能，但 Via API 只开放较弱的那个版本。开放策略的取舍本身就是一种表态。
  • Starlink 客服由 Grok Voice 3.0 接管 — 每天接听 20,000 通多语言客服电话，约 70% 无人工介入解决，销售通话中每四通有一通在挂断前成交。单个 Agent 负责身份核验、硬件排障、发放抵扣、寄送替换设备。
  • UPS 用 AI 做飞机维护零件管理 — 把 AI 落到航空维修这件极度保守的业务上，落地场景比模型参数更有说服力。
  • 新加坡 GovTech × Google DeepMind 端侧反诈 — 基于端侧 Gemma 构建诈骗检测器。公共安全场景选择端侧，隐私压力是主因。

📊 行业动态

  • 台积电第六个连续创纪录季度 — 第三季净利 NT$763 亿级别（约 240 亿美元），同比增长 69%，并预告 Q4 会更好。芯片端的高景气直接证明了算力需求的持续性。
  • OpenAI 承诺不使用从 Apple 拿到的商业机密 — 在法官表示”极有可能”批准 Apple 禁令后，OpenAI 主动让步：在诉讼结束前不使用相关专有信息做产品开发，并交出 14 名从 Apple 跳槽员工的驱动器取证镜像。
  • 美国银行 CEO 要求支付环节保留人类授权 — Brain Moynihan 明确不希望用户因为 Agent 搞砸交易而回头找银行，主张在风险被”能力进一步发展”消除之前，付款必须有人工授权。
  • 企业对 Agent 自主权的信任在下降 — VB Intelligence 调研显示，信任 Agent 自主变更生产环境的比例从 75% 掉到 56%。能力越强，授权越保守——这个反向趋势值得所有做 Agent 产品的人警惕。
  • CoreWeave 债券承压 — 2032 年到期的无担保债跌破面值 80 美分。如果这家 neocloud 出问题，其他高杠杆的算力租赁商会被一起拖下水。
  • Epic 的”vibe coded”启动器翻车 — 由 Agent 写代码的新版 Epic 启动器在预览版里出现明显视觉故障。“能跑”和”能发布”之间，还隔着一层 QA。

🔍 技术洞见

洞见一：Agent 的竞争，已经从”脑子”转移到”手脚 + 皮肤”

把今天榜单上的项目按 Agent 架构分层，会得到一张很清晰的图：感知层（DigUp 的本地语义索引、iPhone-use 的真实屏幕截图）、技能层（anatomy / answer-me-with-html 这类 Skill 包）、行动层（USB 操作真机、ARTEX 的漏洞利用）、校验层（人类支付授权、审计与报告）。模型能力被压缩成了其中最不起眼的一格。

这张图解释了本周最矛盾的一组数据：企业信任 Agent 自主变更生产环境的比例从 75% 掉到 56%，但 Agent 的行动能力却在飞速变强。 两者并不冲突——正因为 Agent 真的能动手了，才必须给它装闸门。能力上行、授权下行，这是任何新技术进入生产环境的必经阶段。

洞见二：价格战把”前沿能力”变成了”基础设施”

Gemini 4 Argon 限时 $2/$10，Claude Haiku 5.5 降价 90%，Google 给长程 Agent 配发独立存储——这三件事指向同一个结论：前沿模型厂商已经不打算靠卖 token 赚钱了。

降价九成不是慈善，而是把推理成本压到让”Agent 常态化运行”变得划算。一个每天跑几万次循环的长程 Agent，单次调用成本从 $0.1 降到 $0.01，业务模型就完全不同了。与之配套的持久化 Agent（自带 Gmail / Calendar / Drive）则解决了另一半问题——状态。

而芯片侧给出了对称的印证：TSMC 连续六个季度创纪录、同比 +69%，说明需求端完全没有降温。一边是模型单价断崖式下跌，一边是算力需求持续暴涨——唯一能同时成立的解释是：用量增长的速度，远远快于价格下降的速度。 这正是”能力变成基础设施”的标准信号。

结语

今天最值得记住的不是某个具体的项目，而是这件事的位置变了。当 iPhone-use 能给 Agent 接上一台真机、ARTEX 能让它自己去打靶、四个 Skill 包同时冲榜——瓶颈已经不在”AI 能不能做”，而在”我们敢不敢让它做、以及做完之后怎么核对”。下一阶段的竞争，属于那些把闸门、日志和回滚做得和功能一样好的人。
