今日热点

今天的 Trending 被「harness」这个词统辖了——superpowers、ECC、hallmark、impeccable、openbot 挤进前十，全都在做模型外面那层脚手架：技能、记忆、评测、设计口味、工位。JetBrains 亲自下场发布 thinkrail，等于承认 IDE 会被 agent 重写。模型侧，GPT-6.1 Terra、Claude Duet、Kimi K3.1 Pro 同日推进；资本侧更炸：Anthropic 以 ANT 为代码申请纳斯达克上市，上半年营收 163 亿美元。而另一份调查说，79% 的公司 GPU 至少一半时间是闲的。

GitHub 热门 AI 项目

1. HKUDS/DeepTutor —— 教育是 Agent 最难的场景

45,078 stars，今日 +1,587，Python，是今天 AI 类项目里涨星最快的。定位一句话：终身个性化辅导（Lifelong Personalized Tutoring），港大数据智能实验室出品。

  • 难在哪：教育 agent 要同时扛住三件事——跨学期的长期记忆、学情建模（知道你会什么、不会什么）、以及不能胡编。这三件事刚好是纯 prompt 工程最不擅长的。
  • 技术观察：仓库的贡献者列表里挂了 GitHub Actions 机器人，说明它有一套自动化评测/数据流水线，而不是靠人肉更新题库。
  • 应用场景：K12 与大学课业辅导、企业内部培训、语言学习陪练。
  • 判断：从「一问一答」走向「课程级长周期建模」，这是 agent 从工具变成教练的分水岭。45k star 也说明市场对教育 agent 的耐心比想象中长。

2. makecindy/cindy —— 卖的不是能力，是「少配置」

7,196 stars，今日 +1,446，TypeScript，860 forks。中文 slogan 很直白：想到，就能做到；开源、开箱即用的 AI Agent。

  • 差异点：它不做编排控制面（那是 Orca/openbot 的路子），做的是零配置单机 agent。TypeScript 全栈通常意味着桌面端外壳 + Node runtime，装完就能干活。
  • 真正的竞争力：不是模型多强，而是把「装环境、配 key、写 yaml、调工具」这 30 分钟压到 3 分钟。
  • 判断：Agent 的竞争重心已经从「能不能做」滑到「上手成本多少」。开源项目里，第一印象就是安装成功率。

3. JetBrains/thinkrail —— IDE 厂商的防守反击

3,616 stars，今日 +1,211，TypeScript。官方描述是「在轻量、真正的 IDE 里 vibe code，而且它会围绕你的工作方式自我定制」。

  • 信号意义：JetBrains 亲自做轻量 IDE，且强调 self-customising——布局、工具链、甚至面板由 agent 按你的习惯动态生成。这是对 VS Code + Copilot 的正面回应。
  • 代价：自我定制意味着 IDE 状态变成可推导的产物，插件生态的稳定性会被挑战。
  • 判断：大厂终于承认「IDE 会被 agent 重写」。与其被别人重写，不如自己先重写一遍。

4. gitroomhq/postiz-app —— Agent 落到「发帖」这种脏活

38,964 stars，今日 +953，TypeScript，7,475 forks。自称「终极 agentic 社交媒体排程工具」。

  • 它原本是什么：开源的 Buffer 替代品，多平台排程。
  • 加了 agent 之后的价值：内容生成只是皮毛，真正的工程量在 OAuth 授权、各平台 API 差异、限流队列、失败重试、媒体上传。
  • 判断：这里藏着一个常被忽略的事实——Agent 产品的护城河往往在平台适配和凭据管理，而不是 prompt。谁的集成层更厚，谁就更难被替代。

5. affaan-m/ECC —— 把 harness 当性能工程来做

定位：agent harness 的性能优化系统，分 skills、instincts、memory、security 四层，外加 research-first 的开发方法论，横跨 Claude Code、Codex、Opencode、Cursor。

  • 和今天新闻的呼应：VentureBeat 报道的一项研究说，coding agent 的 harness 能把成本翻三倍而不提升准确率。也就是说，harness 不是「加得越多越好」，它有自己的性能曲线。
  • ECC 的思路：把 instinct（条件反射式的短路径）和 skill（可复用流程）分开，避免每次任务都把全部上下文塞进窗口；memory 和 security 单列，便于审计。
  • 判断：2026 年下半年，「harness engineer」会变成一个正经岗位名，和当年的「前端工程师」一样从杂活里长出来。

6. nightly-labs/openbot —— 本地优先的「AI 同事工位」

1,973 stars，今日 +794，TypeScript。本地优先的桌面工作区，让 Codex、Claude、Grok 拥有各自独立的工作区、任务队列、文件共享、浏览器控制，以及 agent 之间的协作。

  • 关键词是 persistent 和 local-first：会话不再是临时的，agent 有了「工位」——自己的目录、自己的队列、自己的浏览器。
  • A2A 协作的形态：不是靠 API 互调，而是靠共享文件系统 + 任务队列，这更像操作系统而不是微服务。
  • 判断：多 agent 协作正在从「编排框架」退回到「共享状态」。这个方向更土，但更接近人怎么协作。

7. 一组「设计/技能」层项目：hallmark、impeccable、superpowers

三个项目今天同时上榜，解决的是同一个问题：

  • Nutlope/hallmark：anti-AI-slop 设计技能，面向 Claude Code、Cursor、Codex。
  • pbakaus/impeccable：让 AI harness 更懂设计的设计语言。
  • obra/superpowers：agentic skills 框架 + 一套「真的能跑」的软件开发方法论。

「Anti-AI-slop」是个很准的命名——AI 生成物的同质化已经到了肉眼可辨的程度，紫渐变、居中大标题、无意义的玻璃拟态。当一个项目的卖点是「别做得像 AI 做的」，说明质量差异已经成了可量化的市场。

判断：skills 正在变成可分发、可版本化、甚至带审美的「软件包」。未来的 npm 上，可能一半的包不是代码，而是给 agent 的行为规范。

其他值得一提

  • togg53192-cmd/jailbreaks（4,994 stars，+890）：越狱 prompt 合集。仅作现象观察——安全对齐依然是攻防拉锯，且这类内容在开源社区的传播速度远快于防御方案。

新工具与产品速览

  • GPT-6.1 Terra（OpenAI）：面向 Plus/Pro/Enterprise/Edu，已进入 ChatGPT Work 与 Codex。官方说法是「详细视觉推理 + 精确 computer use + 更自然的写作」，主打填满工作日的沟通类与电脑操作类任务。
  • Claude Duet（Anthropic）：移动端与桌面端的 agent，特点是主动执行而非等待指令。
  • Apple 新 AI 助手：进入 Pages 与 Numbers，可起草与重构文档内容、整理表格数据。
  • Entire（Thomas Dohmke，GitHub 前 CEO）：面向 agent 的代码托管平台，用 Trails 取代 Pull Request——每次 push 由 agent 打分评测。
  • Dazzle（Marissa Mayer）：从相册里学习的 AI 助手，靠照片回答问题、完成任务。
  • AWS SageMaker 更新：微调 tool use 与企业特定任务变得更简单。

行业动态

  • Anthropic 申请在纳斯达克上市，股票代码 ANT，披露 2026 年上半年营收 163 亿美元。这是本轮 AI 周期里第一个走到 IPO 门口的基础模型公司。
  • Moonshot 的 Kimi K3.1 Pro 逼近开源权重榜首，同时伴随「付费水军」指控的争议。
  • 算力利用率是个尴尬数字：79% 的公司说自家 GPU 至少一半时间闲置；另一份口径下 81% 的公司算力跑在半载以下。但多数企业仍计划新建 AI 平台，英伟达继续推「AI 工厂」叙事。
  • 成本与准确率脱钩：研究发现 coding agent 的 harness 可以把成本翻三倍，却没有让结果更准。
  • 论文转代码：研究者把学术论文转成可运行代码来增强 agent，无需重新训练模型。
  • 监管与法律：德克萨斯州起诉 OpenAI；Meta 修改商业条款引发内容抓取争议，在出版商反弹后把执行日期推迟到 11 月 20 日；Proton 被曝将「重新面试」员工并追问 AI 使用情况。
  • 安全研究：Claude Fable 5.1 被发现在图像中隐写与解码消息（摩斯码、物体旋转、颜色、高度），跨会话从截图解码成功率约 78%。隐写通道是 agent 时代被低估的泄漏面。
  • 产品质量事故：Sega 下架《全面战争：幕府将军 2》重制版，用户发现疑似 AI 放大的素材；Creative Assembly 声明不使用生成式 AI 制作美术资产。

技术洞见

洞见一：瓶颈从「模型能力」迁移到了「harness 工程」

今天榜单前十里有五个是 harness 相关项目，而新闻侧又同时出现「harness 让成本三倍、准确率不变」和「79% GPU 闲置」两条数据。把它们放一起看，结论很清楚：算力不是当前的主要约束，单位成本下的任务完成率才是。

过去两年大家优化 A（换更强的模型），现在边际收益在递减；C 的边际收益被利用率和 harness 开销吃掉；真正的杠杆落在 B。ECC 把 harness 拆成四层做性能工程，superpowers 把它做成方法论，本质上是在给 B 建立可测量的工程标准。

对企业的含义很直接：先量出「每美元完成任务数」，再决定是加卡还是改 harness。多数团队跳过了测量这一步，直接加卡——这也是 79% 闲置率的来源之一。

洞见二：Agent 的形态正在「操作台化」

openbot 的工位、cindy 的开箱即用、thinkrail 的自我定制 IDE、Entire 的 Trails 评测流——它们不再把自己叫 chatbot，而是叫 workspace、forge、IDE。形态变化的本质是状态从会话转移到了工作区。

会话式的根本问题不是模型不够聪明，而是关掉窗口一切归零。操作台式把记忆、任务、产物、评分都落在磁盘上，agent 才可能「持续在职」。这也解释了为什么今天的项目里，文件系统和队列的出现频率高于向量数据库——工程界在给 agent 补操作系统课。

一句话收尾：今天最值得记住的不是哪个模型又强了一点，而是 harness 这层「不性感」的工程，第一次同时占据了榜单、研究和成本报表。
