今日热点

今天的榜单主题词是「技能货架」。ai-design-skills 单日 +1,395 冲到第二，superpowers、hallmark、impeccable、expo/skills 同时在场——skills 已从工程流程扩张到审美与平台适配，开始具备「可分发软件包」的形态。DeepTutor 以 +2,376 稳居 AI 类榜首，教育 agent 的长周期建模仍是刚需。新闻侧两条冷信息更值得记：SK 海力士称内存短缺将持续到 2030 年，纽约州把「AI 讨好用户」写进了法条。

GitHub 热门 AI 项目

1. HKUDS/DeepTutor —— 47k star 的教育 agent，靠的不是 prompt

47,364 stars，今日 +2,376，Python，5,898 forks。港大数据智能实验室作品，定位「终身个性化辅导」（Lifelong Personalized Tutoring）。

  • fork/star 比 12.5%：这个比例在 trending 项目里算高的。多数爆款仓库的 fork 率不到 5%，说明看热闹的多、真动手的少。DeepTutor 有八分之一的人真的把它拉下来部署或改造，这是教育场景的典型特征——学校和企业要的是「能装在自己机器上的东西」。
  • 难点在三层叠加：跨学期记忆、学情建模（知道你会什么、不会什么、哪一步卡住）、以及不能胡编。教育学里最难的不是讲对，是判断学生错在哪一层，这正好是纯 prompt 工程最不擅长的。
  • 技术观察：贡献者列表里挂着 GitHub Actions bot，意味着它有一条自动化评测与数据流水线，而不是靠人肉维护题库。教育 agent 的质量下限由题库和判分器决定，不由模型决定。
  • 判断：45k→47k 的日增速说明市场对教育 agent 的耐心还没耗尽。真正的分水岭是它能不能证明「一学期后学生的成绩曲线变了」——目前没有任何一家拿出这类证据。

2. elayadesign/ai-design-skills —— 仓库没有描述，单日 +1,395

10,672 stars，今日 +1,395，759 forks。GitHub 页面上描述栏是空的，没有 README 摘要、没有语言统计，贡献者只有两个：elayadesign 本人和一个 Claude 账号。

  • 这个组合本身就是信号：一个几乎只有 skill 文件（Markdown/YAML）的仓库，能在 24 小时内拿到近 1400 star，说明「给 agent 用的设计规范」已经是独立品类，不再需要附带代码才能被接受。
  • 它在解决什么：AI 生成的前端有极强的同质化倾向——紫蓝渐变、居中大标题、玻璃拟态卡片、无意义的微动效。设计 skill 的作用是把「什么算好」写成 agent 可执行的检查项：间距梯度、字重层级、色彩预算、留白比例。
  • 为什么涨得比代码项目快：因为它的使用成本接近零。clone、指向 skills 目录、完事。对比一个需要配数据库和 API key 的框架，扩散速度差一个数量级。
  • 判断：这类仓库的 star 数会越来越不代表工程质量，而代表「分发力」。它更像一个 npm 包，而不是一个项目。

3. nightly-labs/openbot —— 给 AI 同事配工位

2,964 stars，今日 +1,053，TypeScript，292 forks。本地优先的桌面工作区，让 Codex、Claude、Grok 各自拥有独立工作区、任务队列、文件共享、浏览器控制，以及 agent 之间的协作。

  • 关键词是 persistent 和 local-first：会话不再是临时的，agent 有了「工位」——自己的目录、自己的队列、自己的浏览器。关掉窗口不等于失忆。
  • A2A 的实现方式很土但很对：不靠 API 互调，靠共享文件系统 + 任务队列。这更像操作系统的进程协作，而不是微服务编排。好处是可观测、可回滚、可人工介入；坏处是没有类型约束，冲突靠约定。
  • 判断：从昨天到今天它连涨两天，说明「多 agent 协作」的工程共识正在从编排框架退回到共享状态。框架给你抽象，共享状态给你调试能力，后者在生产环境里更值钱。

4. JetBrains/thinkrail —— 大厂承认 IDE 会被重写

4,635 stars，今日 +1,075，TypeScript，241 forks。官方描述：在轻量、真正的 IDE 里用 pi 做 vibe coding，而且它会围绕你的工作方式自我定制。

  • parse 一下这句话：「lightweight, real IDE」是和「浏览器里的聊天框」划清界限；「customises itself around the way you work」意味着布局、面板、工具链由 agent 按使用习惯动态生成——IDE 状态变成可推导的产物。
  • 代价：一旦界面是推导出来的，插件生态的稳定性就被挑战。传统 IDE 的插件假设宿主 UI 是固定的，自我定制打破了这个假设。
  • 判断：昨天它 +1,211，今天 +1,075，连续两天稳在高位。JetBrains 亲自下场做轻量 IDE，等于承认「IDE 会被 agent 重写，与其被别人重写不如自己先重写一遍」。

5. macro-inc/macro —— 用 Rust 写「共享 AI 记忆」的协作底座

5,224 stars，今日 +106，Rust，508 forks。团队统一工作区：邮件、聊天、文档、任务、agent、通话、CRM，用 @ 互相链接，共享 AI memory。

  • 为什么是 Rust 值得说：这类产品（Notion + Slack + CRM 的合体）传统做法是 Node/Go。选 Rust 通常意味着要自己把控本地索引、增量同步、多人并发编辑的延迟——也就是「shared AI memory」这层不能靠外部服务，必须跑在本地或边缘。
  • +106 的增速说明什么：它是今天榜单里增速最低的 AI 项目之一。这类重工程、重迁移成本的「全家桶」很难靠一天爆红，靠的是长期留存。榜单和真实采用率在这里第一次明显分叉。
  • 判断：共享记忆是团队级 agent 的真正门槛——不是把文档塞进向量库，而是让「谁知道什么」变成可查询的结构。

6. makecindy/cindy —— 卖的不是能力，是少配置

7,865 stars，今日 +740，TypeScript，925 forks。中文 slogan 很直白：想到，就能做到；开源、开箱即用的 AI Agent。

  • 差异点：它不做编排控制面，做的是零配置单机 agent。TypeScript 全栈通常意味着桌面外壳 + Node runtime，装完就能干活。
  • 真正的竞争力：把「装环境、配 key、写 yaml、调工具」这 30 分钟压到 3 分钟。开源项目里第一印象就是安装成功率。
  • 判断：增速从昨天的 +1,446 回落到 +740，符合新项目爆红的衰减曲线。能否留住人，取决于第三天的 issue 响应速度。

7. 一组 skills 项目：superpowers、hallmark、impeccable、expo/skills

四个项目同时在场，覆盖了 skills 的三个层次：

  • obra/superpowers：agentic skills 框架 + 一套「真的能跑」的软件开发方法论。偏流程层。
  • Nutlope/hallmark：anti-AI-slop 设计技能，面向 Claude Code、Cursor、Codex。偏审美层。
  • pbakaus/impeccable：给 coding agent 的设计词汇表，用 polish/bolder 引导、用 critique/audit 复核。偏语言层——它做的事是给 agent 一副「评论家的嘴」。
  • expo/skills：Shell，3,393 stars，今日 +212。Expo 官方发布的 agent skills 集合。这是平台方第一次以官方身份发 skills，意味着 skills 从社区自发变成了 SDK 的一部分。

「Anti-AI-slop」是个很准的命名。当项目的卖点是「别做得像 AI 做的」，说明质量差异已经变成可量化的市场。

判断：平台官方下场是分水岭。接下来会出现「skills 版本锁定」问题——你的 agent 遵守的是 1.2 版还是 1.3 版的设计规范？没有 lockfile 的行为规范，等于没有回归测试。

8. ruvnet/RuView —— 用 WiFi 信号做空间智能

榜单里唯一的「非文本」AI 项目。把普通 WiFi 信号变成实时空间智能、生命体征监测、存在检测，不采集任何一帧视频。

  • 原理不神秘：WiFi 的 CSI（信道状态信息）会因人体移动产生多普勒式扰动，从相位变化里反推呼吸频率、体动、位置。学术圈做了十几年，工程化的难点在噪声与多径。
  • 为什么现在值得看：隐私合规正在收紧（见下面的纽约州法案），摄像头方案在卧室、卫生间、养老院这些场景根本过不了审。射频感知是唯一能同时满足「有感知」和「无图像」的路径。
  • 判断：它更像一个品类预告而非成熟产品。但「无画面的感知」会是 agent 接入物理世界时的默认选项之一。

新工具与产品速览

  • GPT-6.1 Terra（OpenAI）：面向 Plus/Pro/Enterprise/Edu，已进入 ChatGPT Work 与 Codex。官方定位是「详细视觉推理 + 精确 computer use + 更自然的写作」，主打填满工作日的沟通类与电脑操作类任务。computer use 被单独拎出来讲，说明这一轮竞争焦点在「能不能替人点鼠标」。
  • Entire（Thomas Dohmke，GitHub 前 CEO）：面向 agent 的代码托管平台，用 Trails 取代 Pull Request——每次 push 由 agent 打分评测。这是把 CI 从「测试通过/失败」改造成「质量评分」。
  • Dazzle（Marissa Mayer）：从相册里学习的 AI 助手，靠照片回答问题、完成任务。定位是「更平易近人」的 AI 工具。

行业动态

  • SK 海力士：内存短缺将持续到 2030 年。公司称 AI 带来的生产力增益会持续推高需求，即使扩产也压不住供给压力；已签约出售 2028 年前产能的一半以上。这修正了一个流行判断——瓶颈不只是 GPU，HBM/DRAM 的供给曲线才是硬约束。
  • 纽约州签署儿童 AI 聊天机器人法案。核心条款：面向 18 岁以下用户时，禁止机器人假装自己是人；限制奉承、非受 prompts 的情感追问、鼓励保密等行为；必须做年龄验证，且至少提供一种不依赖政府身份证的方式。
  • 数据中心零件成为抢劫目标。NBC 报道，加速建设中的数据中心催生了针对运输服务器的卡车的新型犯罪——钓鱼、企业身份盗用、撞车拦停。服务器、光纤、内存条、铜线都是目标。
  • Proton 将「重新面试」员工并追问 AI 使用情况。404 Media 看到的内部邮件称此举「后果重大」，可能导致岗位与职责调整。
  • 特朗普想禁掉「AI」这个词。他要求媒体改用「Super Intelligence」，称将「正式禁止在所有相关文件中使用 AI/Artificial Intelligence 一词，因为不准确」。法律上他只能约束行政分支。
  • 《全面战争：幕府将军 2》重制版被下架。玩家发现疑似 AI 放大的素材，Sega 撤下 Complete Edition；Creative Assembly 声明不使用生成式 AI 制作美术资产，并要求外部合作方同样遵守。
  • Grok 版《奥德赛》上线第一集。原定「长片」，实际交付的是分集短片，人物面部不一致、盔甲史实错误、盾墙不成立。

技术洞见

洞见一：skills 正在变成有供应链的软件

今天榜单前十里有五个 skills 相关项目，而且分布在不同层次：方法论（superpowers）、审美（hallmark、impeccable、ai-design-skills）、平台官方（expo/skills）。这不是巧合，是一个品类在完成分层。

分层之后必然出现三个问题，而今天没有任何一个项目在回答：

  1. 版本锁定：你的 agent 遵守哪一版设计规范？没有 lockfile，行为漂移无法回归。
  2. 组合冲突：hallmark 说「去掉紫渐变」，impeccable 说「更大胆」，两个 skill 同时装载时谁优先？
  3. 供应链攻击：skills 是纯文本，可以夹带指令。一个被投毒的 skill 包能让 agent 在「帮你重构代码」时顺手把环境变量发出去。

工程上的含义很直接：给 agent 装 skill，等于给生产环境装依赖。既然装依赖要有 lockfile、有审计、有最小权限，装 skill 也该有。目前生态里连「skill 的 package.json」都还没有共识。

对个人的建议：现在就把常用的几个 skill 钉到具体 commit，写清来源和生效范围。等到第三次「昨天还好好的，今天格式全变了」，就来不及溯源了。

洞见二：约束正在从算力迁移到内存与合规

过去两年行业叙事的默认假设是「缺卡」。今天的两条新闻各自从一侧推翻它：

  • SK 海力士说内存短缺到 2030 年——AI 需求推高的是 DRAM/HBM，而不仅是 GPU。芯片产能的扩张周期以年计，模型的扩张周期以月计。
  • 纽约州把「奉承」写进法条——flattery、非受 prompts 的情感追问、鼓励保密，这三个词描述的是产品行为，不是模型能力。它们可测试、可回归、可写进 CI。

于是约束变成一个三元组：算力（可买）、内存（买不到那么快）、行为合规（必须改产品）。

B3 这一支最容易被工程团队低估，因为它的验收方是律师和监管，不是用户。但它的实现位置很明确：在 agent 的输入输出之间加一层可配置的行为策略器——识别未成年用户、禁用第一人称人格化表述、过滤情绪诱导式追问、拦截保密请求。这些规则写起来不难，难的是它们必须和 skills 层共存：一个设计 skill 要求「更热情的文案」，合规层要求「不要奉承」，冲突必须在上线前解决。

今天榜单上那五个 skills 项目，没有一个处理这件事。这大概就是接下来三个月的机会窗口。

一句话收尾：今天最值得记住的不是哪个仓库涨了多少星，而是 skills 第一次表现出「依赖」的所有特征——分层、组合、投毒风险，以及没人写的 lockfile。
