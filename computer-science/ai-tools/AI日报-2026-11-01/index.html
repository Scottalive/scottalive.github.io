今日热点

今天的榜首换人了，而且换得很有信息量：pingdotgg 的 t3code 单日 +3,100 star，从昨天的第三名直接登顶。它卖的不是模型，也不是 agent 能力，而是”控制 agent 的那块面板”——手机、网页、桌面三端遥控你机器上的 Claude Code、Codex、Cursor。与此同时，昨天那批”多 agent 组织”叙事明显退潮：Claude-Code-Game-Studios 增速从 +1,347 掉到 +970，Orkas 直接掉出榜单。另一条线更值得盯：FreeToken 把 290B 级 MoE 模型塞进游戏主机，Kronos 把 K 线当成一种语言来预训练。热度正从”造更多 agent”转向”控制它们、并且养得起它们”。

GitHub 热门 AI 项目

1. pingdotgg/t3code —— agent 的控制面，成了今天最硬的生意（+3,100）

36,787 stars，今日 +3,100，TypeScript。官方自称 “agent harness control surface”：用一个控制面统一接管你机器上已经装好的 agent CLI——Claude Code、Codex、Cursor、Grok Build、OpenCode、Google Antigravity、fx——并提供 iOS、Android、Web 和 Electron 桌面四套客户端。

昨天它还在第三名、增速 1,148，今天直接翻近三倍。这个跳跃值得拆开看，因为它标记了一个明确的转折：竞争焦点从”谁的模型强”移到了”谁握着遥控器”。

先看它的产品判断。前三年的编码 agent 都在解决”agent 能不能把活干完”，而 agent 一旦能连续干两小时，新的痛点立刻变成：我人在外面，怎么知道它卡住了？在手机上怎么批准那一次危险操作？换台电脑怎么接着看？T3 Code 全部押在这三件事上，甚至明说”我们不卖任何东西”，装好你的订阅就能用。它不生产 agent，只生产注视与干预的能力。

这个结构的关键在于 S 是单点。所有 agent 的 stdout、权限请求、文件改动都要经过它，于是它天然拥有了三样东西：会话历史、审批权、以及”哪个 agent 在哪个任务上更靠谱”的数据。前两样是体验，第三样是未来可以变现的资产——模型路由。今天 VentureBeat 那篇 GitHub Copilot Fusion 的报道已经证明了这一点：把任务分给不同模型、按任务计价，能把单任务成本砍一半。控制面是唯一能拿到”任务 → 效果”配对数据的位置。

但风险同样集中在 S。第一，它寄生在别人的 CLI 上。Claude Code、Codex 的登录态、输出格式、限流策略任何一项改动，都会让控制面变成一块黑屏；而”用自己的订阅遥控”这件事，厂商随时可以在 ToS 里收紧。第二，它是新的信任边界。手机端能批准高危操作，等于把 shell 权限延伸到了口袋里——昨天的 Cursor 扩展投毒事件已经演示过一次，供应链攻击最喜欢挑这种”人人装、人人信”的中转层。

一句话总结：T3 Code 值这个涨幅，因为它卖的是长任务时代的必要配件。但它的护城河是生态位而非技术，能不能守住，取决于它多快从”遥控器”长成”带策略的路由器”。

2. FlashML-org/FreeToken —— 290B MoE 跑在你的游戏主机上（+232）

15,143 stars，今日 +232，Python。定位很直接：边缘原生的 MoE 推理引擎，让 290B+ 的前沿开源 MoE 模型在个人硬件上跑到”可交互”的速度。核心技术点写得相当具体：

  • 带宽自适应 CPU–GPU 协同执行（论文里称作 $q^\star$ 策略），按实测带宽决定每层专家放在哪；
  • 全层双缓冲 prefill 流式，把权重加载和执行重叠起来；
  • 全局 LRU 专家缓存，配合 FTW 快速权重格式；
  • 语义锚点 checkpoint：对循环状态与 KV cache 做语义级快照，agent 的工具调用、思考块被编辑后不必重算整段上下文；
  • 弹性显存管理，运行时在专家缓存与 KV 之间重新分配 VRAM，不用重启引擎；
  • 支持 DeepSeek-V4-Flash、Qwen3.6-35B-A3B、GLM-5.2，量化格式覆盖 MXFP4 / NVFP4 / FP8 / BF16，并暴露 Anthropic / OpenAI 兼容 API。

今天只涨 232，热度不高，但它是这批项目里工程含量最重的一个。原因在于 MoE 的物理现实：一个 290B 的模型每次前向只激活其中一小部分专家，所以真正的瓶颈不是 FLOPS，而是你能不能把需要的专家及时搬到计算单元旁边。消费级显卡的显存装不下全部专家，PCIe 带宽又只有数据中心 NVLink 的零头，于是”每一层都要做一次搬砖决策”。

这张图里最值钱的是那条 q* 分支。纯 GPU 推理要求全部权重驻留，纯 CPU 推理慢到不可用，离线预取又会把宝贵带宽浪费在”猜错的专家”上。FreeToken 的做法是把带宽当成一等公民来做调度——这跟数据库的 buffer pool 管理是同一类问题，只是换了个介质。再叠加”语义锚点”这个设计：agent 场景下上下文经常被编辑（工具返回、思考块折叠），传统 KV cache 只能整段重算，而语义级快照能把重算范围压到一次工具调用之内。这一条才是它敢说自己”给 agent 用”的底气。

要泼的冷水是：宣传口径的”290B 交互速度”必然对应特定硬件与特定量化（多半是 MXFP4 + RTX 50 系 + 大内存），换到笔记本就是另一个故事。而且专家缓存命中率高度依赖任务分布——写代码和闲聊走的是完全不同的专家路径，LRU 在切换任务时会集体失效。想认真评估，别跑 benchmark，跑你自己的真实会话。

3. shiyu-coder/Kronos —— 把 K 线当成一种语言来预训练（+611）

45,011 stars，今日 +611，Python。Kronos 是一个专门为金融市场”语言”预训练的 decoder-only 基础模型族。它的两段式框架很清晰：

  1. 专用 tokenizer：把连续、多维的 K 线数据（OHLCV）量化成分层离散 token；
  2. 自回归 Transformer：在这些 token 上预训练，从而作为一个统一模型服务多种量化任务。

模型动物园覆盖四个尺寸——mini 4.1M（上下文 2048）、small 24.7M（512）、base 102.3M（512）、large，全部开在 Hugging Face 上，还配了一个 BTC/USDT 未来 24 小时预测的可视化 demo。

这个项目最值得学的不是预测准不准，而是它选了”造 tokenizer”而不是”调 prompt”。通用时间序列基础模型（TSFM）在金融数据上普遍表现平庸，原因很朴素：金融序列噪声极高、非平稳、且不同频率（分钟线/日线）的统计性质完全不同。直接喂连续值，模型学到的是”平均走势”，而真正有信息量的是形态——长上影、缩量回踩、跳空缺口。把 OHLCV 分层量化成离散 token，本质上是把”形态”变成词汇表里的词，让 Transformer 用它最擅长的方式（离散符号的共现统计）去学。

顺带说一句它的尺寸选择很有诚意：4.1M 参数的 mini 版能在笔记本上跑，102M 的 base 版一张消费卡就够。这是”垂直基础模型”的正确姿势——先证明小模型在窄领域能打，而不是一上来就对标 GPT。

冷水照旧要泼：预测误差小，不等于能赚钱。真实交易里还有手续费、滑点、冲击成本、以及最致命的 regime shift——模型在 2020 年 3 月那种行情里学到的东西，会在下一个流动性事件里全部作废。把它当成”信号生成器的一个特征来源”是合理的，当成”自动交易大脑”是危险的。

4. beenuar/AiSOC —— 安全运营要的不是更聪明的 agent，是可复核的 agent（+436）

5,920 stars，今日 +436，Python，MIT。开源自托管的 AI 安全运营中心：接入安全遥测 → 归一化 → 跑规则库（7015 条规则中 2530 条可执行）→ 关联成事件 → 由 AI agent 调查，每一步的 prompt 与工具调用都被记录 → 提出处置建议，由人批准后才下发。附带 MCP server，能接 Claude、Cursor、Continue，无需任何 API key 即可自托管运行，当前 v21.0.0。

选它进前四，是因为它回答了一个很实际的问题：安全场景凭什么敢让 agent 动手？

答案是三条工程约束，而不是更高的准确率：

  • 规则先于模型。2530 条可执行规则负责”确定性地过滤”，把告警洪水压到 agent 能处理的量级。模型只负责归因与调查，不负责发现。
  • 决策账本可重放。每个 agent 步骤都有记录，能回放——出问题时你可以指出”它在第 4 步读了这个日志、第 7 步下了这个结论”。这在安全审计里不是加分项，是准入条件。
  • 人批准才落地。响应动作是 proposal，不是 action。这一条把最坏情况的破坏力封在了”误报”级别。

这也正好接上昨天 Cursor 扩展投毒事件留下的教训：安全产品的可信度从来不来自”我判断得准”，而来自**”我错的时候你能查出来我错在哪”**。AiSOC 把 decision ledger 做成核心卖点，说明这个行业的采购逻辑已经成熟了——买的是可审计性。

行业动态

  • “Evil Qwen”与神经元探索：VentureBeat 报道了围绕 LLM 内部神经元的一轮探索热潮。核心观点值得记下来——一个叫嚣要毁灭人类的模型，比一个悄悄利用错误目标、或在”看起来很有帮助”的同时越权行动的模型，更容易被发现。对齐工作的难点从来不是识别怪物，而是识别”过于配合”。
  • 开源权重模型更便宜也更强了，但别自己扛推理成本：VentureBeat 10-31 的分析把开源与闭源的关系类比成 Linux/Windows、Android/iOS——不是赢者通吃，而是各服务不同市场。对企业的实际建议是：用开源权重拿能力与议价权，用托管推理拿弹性，别把两者混成”自建机房”。
  • Nvidia 与 Oracle 扩产 Vera Rubin，卖点转向”提高利用率”——因为企业客户普遍报告 GPU 闲置。这一句比任何 benchmark 都诚实：算力过剩与算力浪费同时存在。
  • AI 正在改写计算机科学几十年的研究方式（The Verge）：从论文选题、实验设计到复现，agent 参与度快速上升。与之相伴的争议也很具体——当 AI 能批量生成”看起来成立的实验”，同行评审这套机制要如何自处。
  • 数据中心开始进入地方政治：缅因州参议院选战里，科技富豪的巨额投入与乡村选民对电价、资源占用、”幽灵岗位”的反弹正面相撞。AI 基础设施的选址问题，正在从工程问题变成选票问题。

技术洞见

洞见一：agent 时代的分发入口，是控制面而不是模型

把今天榜单前三名连起来看，会看到一条很清晰的迁移路径：

昨天榜单前十有一半在做”agent 的组织形式”，今天这批项目集体降速，而控制面项目翻倍增长。这不是巧合，是收益递减的必然结果：多加一个角色，边际收益很快被协调成本和 token 消耗吃掉；而”让我在手机上看到它在干什么、并且能叫停”这件事，是每个用户每天都会用到的确定性收益。

更本质地说，模型层已经商品化了。同一个任务，前沿模型之间的差距在缩小，价格却在快速下探（Copilot Fusion 半价、Mistral Large 4 单任务成本降 63%）。当”能力”不再是差异，”注意力”就成了差异——谁占据了你每天打开的那个界面，谁就掌握了路由权、订阅权、以及最重要的任务效果数据的归属权。

风险也在这里：控制面天然是信任的汇聚点。它同时握着你的凭据、你的仓库、你的审批权。T3 Code 用”开源、可 fork”来对冲——真出问题你可以自己改；但大多数用户不会 fork，只会安装。这一层迟早需要类似浏览器扩展市场那样的审核与签名机制，否则昨天的投毒事件只会换个包装重演。

洞见二：垂直基础模型的配方，已经收敛成四步

Kronos（金融）、AiSOC（安全）、FreeToken（把大模型压进个人硬件）看起来毫不相干，但它们的工程骨架是同一个：

四步是：专用编码 → 小主干 → 领域评测 → 边缘部署，闭环靠真实任务分布回流。

这套配方之所以在 2026 年底收敛，是因为通用大模型在垂直场景的三个死穴一直没有解：噪声（金融的高频抖动、安全的误报洪水）、时效（等不起一次云端往返）、可审计（要能指出第几步错了）。前两个用专用编码 + 小模型解决，第三个用决策账本解决。

有意思的是，这三个项目都在同一个方向上做了让步：放弃”通用”，换取”可部署”。Kronos 最小的模型 4.1M 参数，FreeToken 的卖点是消费级显卡，AiSOC 强调”无 API key 也能跑”。这不是技术退步，而是市场分层——当前沿模型的边际能力提升越来越贵，把钱花在”在我这台机器上、针对我这类数据、能被我审计”的模型上，回报率反而更高。

对个人开发者的启示很直接：别再想着训一个更大的模型。找一个噪声大、规则多、又必须本地跑的领域，把它的编码方式做对，用 100M 以内的参数跑通闭环，你就有了一个别人拿 GPT 也替代不了的东西。Kronos 能在一天里涨 611 star，靠的就是这个逻辑被市场认出来了。
