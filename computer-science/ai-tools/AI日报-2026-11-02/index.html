今日热点

榜首又换人了，这次换得很有象征意义：vercel-labs 的 agent-desktop 单日 +2,243 star 登顶。它不做更聪明的模型，只解决一件事——让 agent 可靠地”看见”并操作桌面应用，靠的是操作系统无障碍树，而不是截图猜坐标。同一天，Scrapling（92,315 star）把网页抓取做成了 MCP 工具，colibri（46,240）用纯 C 把 MoE 专家从磁盘流式加载，nanochat（59,672）继续证明 48 美元能训出 GPT-2 级别的模型。主线很清楚：agent 的竞争从”想得多好”转向”看得多准、动得多稳”，而模型本身正在变成可以自己养的家用基础设施。

GitHub 热门 AI 项目

1. vercel-labs/agent-desktop —— 不看像素，读无障碍树（+2,243）

8,265 stars，582 forks，Rust，今日新增 2,243，是今天唯一一个”从零起量”就冲到第一的项目。官方描述只有一句话：给任何 agent 提供可靠的桌面 computer use 能力，通过 OS 无障碍树看到任意应用的真实 UI 结构，从而操作它——引用保持稳定，动作可以安全重试，而不是从像素里猜。

这句话里的每个词都踩在痛点上。过去两年 computer use 的主流做法是截图 + 视觉模型输出坐标，然后模拟点击。这条路在 demo 里很惊艳，在生产里很脆：分辨率与缩放一变，坐标就偏；暗色模式、动画过渡、弹窗遮挡、字体渲染差异，都会让同一次点击落到别处；更麻烦的是失败不可诊断——你只知道点空了，不知道是模型看错了、坐标算错了，还是页面慢了半拍。

agent-desktop 换了一条路：把应用当成一棵有语义的树来读。按钮、输入框、菜单项、列表项都带着角色、名称、状态和层级；agent 拿到的是一个编号引用（ref），动作是”对 ref-17 执行 press”，而不是”在 (812, 466) 处点击”。这带来三个直接收益：

  • 稳定：ref 绑定的是节点身份，窗口移动、主题切换不影响它；
  • 可校验：动作执行后可以回读该节点的状态，确认是否真的生效，而不是靠再截一张图去猜；
  • 省 token：一棵裁剪过的无障碍树通常几百到几千 token，远少于高分辨率截图加视觉推理的成本。

技术上最难的不是读树，而是把三套平台无障碍 API 抹平成一套语义。macOS 的 AX 树、Windows 的 UIA、Linux 的 AT-SPI 在角色命名、事件模型、异步填充时机上都不一样；有些应用（尤其是 Electron、Flutter、自绘 Canvas）树是空的或者严重残缺。所以这类项目的真实工程量藏在”降级策略”里：树可用时走结构，树残缺时退回视觉，两者都失败时给 agent 一个明确的”我看不见这个控件”，而不是让它瞎点。

冷水也得泼：无障碍树能覆盖的是标准控件，覆盖不了游戏、专业绘图软件、自定义渲染的图表。而且它天然是一个高权限组件——能操作任意应用，等于握着你桌面的一切。真正落地时，动作白名单、敏感应用排除、每步人工确认这些边界，比识别准确率更重要。

2. D4Vinci/Scrapling —— 92,315 star，爬虫正在变成 agent 的感官

92,315 stars，9,742 forks，Python，BSD-3-Clause。这个项目不是新面孔（2024 年 10 月创建），但今天重新上榜值得单独说：它已经从”一个爬虫库”长成了一套完整的取数工作流。

它的分层很清晰：

  • 取：快速 HTTP 请求、隐身浏览器、JS 渲染、Cloudflare Turnstile/Interstitial 处理、持久会话、后台 API 捕获；
  • 解：CSS / XPath / 文本 / 正则选择器，自适应元素追踪，相似元素匹配，直接输出干净 Markdown；
  • 爬：并发 spider、代理轮换、重试、AutoThrottle、暂停续跑、流式输出、JSON/JSONL/CSV/XML 导出；
  • 给 agent 用：内置 MCP server 与 Agent Skill，加上 CLI 和交互式 shell。

这里最值得学的是”自适应元素追踪“。写过爬虫的人都知道，维护成本的大头不是写选择器，而是网站改版后选择器集体失效——class 改个名、外面多包一层 div，整条流水线就断。Scrapling 的做法是记住元素的结构指纹与文本特征，改版后按相似度重新定位，把”必然的断”降级成”偶发的偏”。这跟 agent-desktop 读无障碍树是同一个思路的两面：不要依赖最脆弱的表层特征（像素、CSS class），要依赖更稳定的结构语义。

顺带一个对比：昨天榜单上的 lightpanda 是”为 agent 重写一个更轻的浏览器”，Scrapling 是”把抓取、解析、爬取、导出串成一条链，再挂到 MCP 上”。前者省资源，后者省工程。两者都会长期存在，因为 agent 取数的场景本来就分成”打开一个页面看看”和”把这个站点搬成数据集”两类。

合规提醒必须写在这里：隐身浏览器与 Cloudflare 绕过能力是中性的，但用在哪里不是。robots.txt、站点 ToS、个人数据边界，这些不会因为工具变强就消失。

3. JustVugg/colibri —— 46,240 star，纯 C 把前沿 MoE 塞进你的机器

46,240 stars，5,342 forks，C，Apache-2.0，今年 7 月才创建。一句话：在你已经拥有的硬件上跑前沿 MoE 模型——纯 C、零依赖、专家从磁盘流式加载。引擎很小，模型很大。

这跟昨天写的 FreeToken 是同一战场的两个位置。FreeToken 是 Python 的服务层，管调度、量化格式、API 兼容、语义快照；colibri 是极致精简的执行核心，把”能不能跑起来”这件事压到最低门槛。两者共同的物理约束是同一个：MoE 每次前向只激活一小部分专家，所以瓶颈不是算力，而是容量与带宽的矛盾——全部专家装不下显存，那就得决定”这一层要哪些专家、从哪儿搬过来、搬的时候计算单元别闲着”。

colibri 的选择是把磁盘当第二级存储，用流式预读把专家搬进内存；纯 C 零依赖意味着它能在几乎任何有编译器的设备上跑起来，包括那些装不了 Python 运行时、也装不了 CUDA 工具链的老机器。代价也很直接：首 token 延迟会被 IO 支配，机械硬盘上体验会崩，SSD 才勉强可用；并发一高，随机读会把 IOPS 打满。所以它适合的场景是”单用户、能跑就行、隐私优先”，不适合”多租户高吞吐”。

一句话评价：这类项目的价值不在于 benchmark 数字，而在于把”前沿模型只能用 API”这个默认前提打掉。前提一旦松动，后面的产品形态就会跟着变。

4. karpathy/nanochat —— 59,672 star，48 美元的 GPT-2 速度赛

59,672 stars，8,391 forks，Python，MIT。定位是”100 美元能买到的最好的 ChatGPT”，实际是一个极简的 LLM 训练实验装置：单 GPU 节点、代码可读可改、覆盖分词、预训练、微调、评测、推理全流程。

它最漂亮的设计是一个旋钮控制整个模型族：只设 --depth（层数），宽度、头数、学习率调度、训练时长、权重衰减全部按最优比例自动推导。GPT-2 级能力大约对应 depth 26。于是”训练一个大模型”从一堆需要调的超参，变成了一个可复现的、带排行榜的工程问题。

排行榜本身就是内容。GPT-2 在 2019 年花了约 43,000 美元、168 小时；nanochat 目前的最优记录是 8×H100 上 1.65 小时，按 3 美元/GPU/小时算约 48 美元，spot 实例能压到 15 美元左右，CORE 分数 0.2626 已经超过 GPT-2 的 0.2565。这中间压缩的不是某一个技巧，而是七年里整条栈的进步：数据配比（换到 NVIDIA ClimbMix 直接把时间从 2.76 小时砍到 2.02 小时）、fp8、batch size、以及几轮”自动研究”式的调参。

对读者的实际用法有两个：想理解 LLM 全流程，这是目前最短的路径；想验证一个架构想法，这是最便宜的试验台——两小时几十美元就能拿到一个可对话的模型，比读十篇论文直观。

  • Google 的机器人花盆 Sprout：自主寻找最佳光照、缺水时提醒，官方说”只是好玩，不卖”。它的价值是演示了用 AI Studio 从想法到硬件的链路有多短。

行业动态

  • Grok Bot 被限流，理由是”成本相对收入不可持续”。马斯克在 X 上回应了用户对额度提前耗尽的抱怨。这是常驻型 agent 第一次被公开按计算成本踩刹车：一个 7×24 在线的 agent，单位经济模型和按次调用的聊天机器人完全不同，它烧的是持续推理与状态维护，而不是一次问答。
  • Cursor 扩展市场出现恶意的 Claude Code 扩展，约 5,000 人可能安装。修改版在周四 5:27 到 16:35（ET）之间上架，收集主机名、用户名、操作系统、家目录、公网 IP 等信息，现已被下架。这是本周最该被记住的安全事件：agent 生态的中转层（扩展市场、控制面、MCP server）正在成为供应链攻击的首选入口，因为它一次投毒就能触达大量开发者的凭据与仓库。
  • OpenAI 收紧 ChatGPT 的暴力相关内容：青少年账户对武器类信息的获取进一步受限，”即使问题看起来无害”；所有用户关于过往大规模袭击的提问也会得到更少细节。平台责任正在从”事后删除”前移到”默认不给”。
  • Proton 取消了对员工的”AI 面试”。此前 404 Media 报道公司要盘问员工如何使用 AI 以决定岗位去留，引发强烈反弹；CEO 最终取消，并称”不会因 AI 裁员”，但重组仍会发生。企业推 AI 的真正阻力，往往不在技术，而在信任与程序正义。

技术洞见

洞见一：agent 的瓶颈已经从”想”移到”看”

把今天前两名放在一起看，会发现它们解决的是同一个问题的两端：agent-desktop 让 agent 看懂桌面，Scrapling 让 agent 看懂网页。两者都放弃了”用视觉模型猜”，转向结构化语义 + 稳定引用。

为什么结构路线会赢？三个可量化的理由：

  1. token 效率。一张 Retina 截图编码后动辄上千 token，一棵裁剪过的无障碍树通常只保留可交互节点，几百 token 就够。同样预算下，结构路线能多走好几步。
  2. 可校验。像素路线只能”再截一张看看像不像”，结构路线可以直接问”这个按钮的 enabled 变成 true 了吗”。能被断言的动作才能进入自动化流程。
  3. 可重试。ref 是稳定的，重试是幂等友好的；坐标不是，重试只会点偏第二次。

这也解释了 MCP 为什么重要：当”感官”被标准化成工具，agent 本体和感知层就能解耦。今天 Scrapling 自带 MCP server 与 Agent Skill，agent-desktop 也是以工具形态对外——未来的 agent 不会内置一套感官，而是按场景插拔。

但结构路线有自己的天花板：自绘界面、游戏、Canvas 图表没有语义树；跨平台无障碍实现差异巨大；而且它把权限问题放大了——一个能读任意应用结构、并对任意控件下动作的组件，本质上是一个新的 root 级信任边界。能力越结构化，越需要白名单与审计日志。

洞见二：本地推理栈已经三层俱全，还多了个”后处理层”

今天榜单里有一条不显眼但很完整的线：nanochat（训练）、FreeToken（服务）、colibri（执行引擎）。三年前，个人想在本地”拥有”一个前沿模型，缺的从来不是某一个零件，而是整条链——不会训、不会部署、跑不动。

这四层各自独立，但合起来改变了一件事：模型从”只能订阅的服务”变成”可以自举的工件”。你能训、能服务、能跑、还能改行为，整条链路都不需要联网。成本曲线也在配合——两小时几十美元就能得到一个可对话的 GPT-2 级模型，而 2019 年这要四万多美元。

真正的摩擦因此从技术转向了三处非技术问题：

  • 许可。开源权重不等于随便用，AGPL、商用限制、蒸馏条款都会在”改完再分发”这一步咬人。
  • 责任。heretic 这类工具能去掉安全对齐，能力很实用，但一旦被改过的模型出了事，责任在改的人还是原模型方，目前没有共识。
  • 可维护性。自建栈意味着自己负责升级、量化踩坑、IO 调优。省下的 API 费用，往往以运维时间的形式付回去。

所以我的判断是：本地栈会先在”隐私敏感 + 任务固定 + 单用户”的场景里站稳（个人知识库、离线编码助手、行业数据处理），而不是去正面替代云端 API。它的意义不是更便宜，而是把”能不能用”的决定权从服务商手里拿回来——这一点，在 Grok Bot 因为成本被限流的今天，显得格外有说服力。
