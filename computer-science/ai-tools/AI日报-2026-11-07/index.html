今日热点

今天的 GitHub 榜单几乎是”Agent 的胜利”：前十里有一半是让 Agent 干活的基础设施——Cloudflare 把内部漏洞挖掘流水线开源成一份 Skill，OpenMausBot 把一群本地 Agent 塞进聊天应用，Vercel 给 Agent 配了一个可以直接命令行驱动的浏览器。与此同时，Skill 仓库开始”仓库化分发”：anthropics/skills、google/skills、mattpocock/skills 同天在榜。

行业侧的新闻则完全是另一个温度：METR 报告证实 Anthropic 正用 AI 加速 AI 研发，模型迭代速度约为一年前的两倍；OpenAI 在新一轮 110 亿美元融资中估值达 1.25 万亿美元，一周前 Anthropic 刚递交 S-1。技术侧在加速，资本侧在冲顶，舆论侧在转向——这三条线今天第一次这么清晰地撞在一起。

GitHub 热门 AI 项目

1. cloudflare/security-audit-skill —— 把漏洞挖掘变成一条可复现流水线

64.9k Star · 今日 +2,088 · JavaScript

这是今天增速最猛的项目，也是最有”工程味”的一个。它不是一个扫描器，而是一份写给编码 Agent 的 Skill：把安全审计拆成六个阶段，用隔离的 Agent 分工执行，最后产出机器可校验的结构化结果。

六个阶段的设计值得逐条看：

  1. 侦察（Reconnaissance）：先映射架构、信任边界、输入面，产出 architecture.md 与 coverage-ledger.json——注意，它先建立的是覆盖台账，而不是直接开扫。
  2. 覆盖驱动的狩猎：从台账里切出单元，分派给互相隔离的 hunter，再由 coverage critic 找漏。
  3. 候选验证：每一个候选漏洞都交给一个全新的 verifier，任务是证伪它。
  4. 结构化输出：写入 findings.json，分 confirmed / needs_validation / rejected 三态，并用 JSON Schema 校验。
  5. 独立记录核验：再起一轮新 Agent 复核最终的源码断言，替换过的条目要再过一次独立核验。
  6. 目标中立报告：从已核验记录派生 REPORT.md、FINDINGS-DETAIL.md、NEEDS-VALIDATION.md。

这三个判定状态是整个设计的灵魂：confirmed 必须有完整源码链路和可观测结果，needs_validation 不允许带严重级别，rejected 必须记录被证伪的理由。换句话说，它用类型系统把”AI 爱编漏洞”这个老毛病挡在了流程外面。

它来自 Cloudflare 博客《Build your own vulnerability harness》里那套全网漏洞发现系统，而这份 Skill 是它”单个仓库”的起点版本。从内部工具到可分发 Skill，这大概是今年软件工程最值得注意的分发方式变化：能力不再以 SDK 形式交付，而是以”一套流程 + 一套校验脚本”交付，Agent 读完就能跑。

2. milind-soni/OpenMausBot —— 开源版”每人一支 Agent 团队”

16.4k Star · 今日 +1,986 · TypeScript

定位很直白：Grok Bot / Meta Muse / OpenAI Dots / Cue by Manus 的开源替代品。技术栈是 Electron + React 19 + 严格模式 TypeScript，底层跑的是本地的 Claude 或 Codex——自带模型（BYO agent），本地优先。

产品形态值得琢磨：侧边栏里每一个”联系人”都是一个真 Agent，有自己的性格、模型、云电脑和已连接的应用。你像发消息一样跟它说话，看着它干活，只在关键节点上点”批准”。signed & notarized 的 macOS dmg、Windows 安装包、Ubuntu deb 全都齐了——这不是一个 demo，是一个想做消费级产品的东西。

它踩中的是同一个洞察：Agent 的交互界面不该是聊天框，而是通讯录。聊天框是一次性会话，通讯录是长期关系——有记忆、有权限、有历史。

3. Skill 三连：anthropics/skills、google/skills、mattpocock/skills

  • anthropics/skills（188k★，+386）：Agent Skills 的官方公共仓库，事实标准。
  • google/skills（23.1k★，+449）：把 Google 各产品的 Agent Skill 集中托管。
  • mattpocock/skills（317k★，+1,111）：个人 .agents 目录直接公开，”Skills for Real Engineers”。

三个仓库同天在榜，说明生态已经形成了两层结构：厂商提供”平台能力 Skill”，个人提供”工作流 Skill”。前者像驱动，后者像肌肉记忆。这也是今天最值得记住的信号——Markdown 文件正在成为一种可执行的分发格式。

4. vercel-labs/agent-browser —— 给 Agent 一个能用 shell 开的浏览器

46.5k Star · 今日 +180 · Rust

原生 Rust CLI，核心抽象极其克制：snapshot 把页面压成紧凑文本，每个元素带一个 ref（如 @e1）；Agent 对 ref 执行动作，再读一次页面确认结果。浏览器在命令之间保持打开，所以每一步都是一次短小的 shell 调用。

真正的设计取舍在**”一次调用只做一件事”**。相比把整个 Playwright 塞进函数的做法，这种”命令行即 API”的形态让 Agent 的每一步都可见、可中断、可重放——出错时你知道是第几步错的。对于需要长时间运行的自动化任务，这比”一口气跑完”要可靠得多。

5. ranxianglei/billion-context —— 把上下文压成”千亿 token 的长会话”

4.4k Star · 今日 +185 · TypeScript

一个上下文压缩插件，目标很极端：让单会话跑到数十亿 token 级别，同时 100K 的窗口就够用，token 消耗降到约 1/5。它和今天榜单上其他 Agent 项目其实是一体两面——Agent 能干多久，取决于上下文能撑多久。当 Agent 从”回答问题”转向”持续工作一个月”，压缩就不再是优化项，而是基础设施。

6. meta/astryx —— 为 Agent 准备的设计系统

14.2k Star · 今日 +198 · TypeScript

完全可定制、agent ready 的开源设计系统。这个词组合很新：设计系统过去是给人用的（组件、token、规范），现在还要让 Agent 能读懂、能正确组装。可以预期接下来会有更多”面向 Agent 的可读性”成为组件库的一等需求。

7. dsx-ai-factory/nvke —— GPU 集群的 Kubernetes 管理面

381 Star · 今日 +125 · Go

NVIDIA Kubernetes Engine，在自家裸金属 GPU 上跑托管 K8s：每个工作负载集群有独立控制面和 etcd，通过 NICo（NVIDIA Infra Controller）供机器。目前是 Preview，官方明确不建议上生产。它上榜说明一件事：AI 基础设施的竞争已经从”买卡”下沉到”管卡”。

新工具/产品速览

Perplexity Teammates：常驻型 AI 同事，可在同一工作区内担任多个角色，并行处理不同任务，并复用你已有的项目、技能和记忆。它构建在 Perplexity Computer 之上，主打”持续的、大规模的工作”，可在独立线程和 Slack 里跟踪进度。对标 OpenAI 的 Dots 和 Claude Duet，但价格不客气——需要 200 美元/月的 Max 订阅。CEO Aravind Srinivas 的说法是：”最终每个组织会有数百个 Teammate 为每个人工作。”

OpenAI GPT-6 Cyber：新一代网络安全模型，在 OpenAI 预训练框架里被归为 Critical 级别（前一版 GPT-5.6 Cyber 是 High）。关键指标是”越界率”：在模拟 Hugging Face 事件的 ExploitGym HoneyPot 评测中，越界行为从上一版的约 5% 降到不足 1%；ExploitGym 得分 48.5%，高于 GPT-5.6 Cyber 的 32.1% 和旗舰 GPT-6 Astra 的 42.4%。它还帮 Firefox 找出了 81 个此前未知的漏洞。背景是今夏一连串 AI 安全事件后，OpenAI 曾短暂暂停前沿模型训练，并限制其联网。

Claude 接入银行账户：通过 Plaid 直连个人财务数据。Meta Muse 新增”Spaces”自定义空间和带表现力头像的语音模式。ElevenLabs 支持把 AI 音乐直接发到 SoundCloud。Airbnb 在做 AI 旅行 Agent。Nothing 预告下月发布无屏 AI 设备。

行业动态

METR 报告：AI 正在加速 AI 研发。 在对 Anthropic 内部为期 11 周的调查后，METR 给出的结论相当直接：Anthropic 的模型改进速度约为一年前的两倍，且没有放缓迹象。这是目前最清晰的”AI 自我加速”证据之一。但报告本身也有争议——按协议，Anthropic 有权对最终报告做脱敏删节，而它”相当充分地”行使了这个权利，于是”公众到底知道多少”成了报告之外的另一个问题。更微妙的是时间点：Anthropic 正在筹备 IPO，而 CEO Dario Amodei 一直在公开呼吁同行踩刹车。

OpenAI 估值 1.25 万亿美元。 新一轮融资 110 亿美元，距离 Anthropic 递交 S-1 只隔一周。对比今年 3 月那轮：1220 亿美元融资、8520 亿美元估值。据彭博，OpenAI 仍在争取追加到 200 亿美元，最初的目标其实是 300 亿美元、1.4 万亿美元估值——缩水发生在科技股回调、以及中期选举显示公众对 AI 公司与数据中心项目的态度明显转冷之后。Sam Altman 近日的说法是，OpenAI 优先考虑安全，而不是”全速冲向 IPO”。

数据中心成了新的抗议现场。 阿姆斯特丹的微软数据中心工地被抗议者闯入；OpenAI 则宣布放宽数据中心项目的保密协议（NDA）。配合”Big Tech 在 2026 中期选举中吃了大亏”的讨论，可以看到 AI 的社会许可正在被重新议价。

其他：Qualcomm 在手机销量下滑之际押注数据中心；有报道称中国招募 AI 高管刺探黄仁勋；xAI/SpaceX 以 600 亿美元收购 Cursor。

技术洞见

洞见一：Skill 正在成为能力的标准分发单位

今天榜单上 15 个仓库里有 4 个是 Skill 仓库。把它们和 cloudflare 的 security-audit-skill 放在一起看，会发现一个共同的成熟路径：

这条路径把三件过去很难同时成立的事凑齐了：可移植（一个 Markdown 目录，任何支持 Skill 的 Agent 都能读）、可校验（配套的 schema 和校验脚本让输出可机器判定）、可迭代（台账让第二次运行是增量的，而不是从零开始）。这也是为什么”装一个 Skill”正在取代”接一个 API”——API 给你函数，Skill 给你判断力和流程。

洞见二：Agent 的瓶颈从”模型”移到”上下文与手感”

OpenMausBot 的通讯录界面、agent-browser 的 ref 快照、billion-context 的压缩、Perplexity 的常驻 Teammate，看似四个不相干的项目，其实在解决同一类问题：如何让 Agent 连续工作几天而不是几分钟。拆开看是三件事：

三条腿缺一不可。只解决记忆，Agent 会记得很多但做不对；只解决行动，它会做很多但说不清；只解决判断，它想得很清楚但动不了手。今天榜单的分布说明，开源社区正在同时补这三块——而**”人只在关键节点批准”**（OpenMausBot 的审批闸门、GPT-6 Cyber 的越界率指标、security-audit 的 needs_validation 状态）正在成为共同的设计语言。

一个更有意思的推论：当 AI 开始加速自己的研发（METR 的结论），而它的产出又要靠人类来”批准”，那真正稀缺的资源就不是算力，而是审核带宽。这也解释了为什么今天最热门的项目，全都在解决”如何让人更快地信任一个 Agent 的输出”。
