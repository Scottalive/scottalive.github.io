今日热点

今天的榜单几乎被同一件事占满：Agent 的能力正在被”打包成技能”分发。superpowers 以 32 万 Star 稳居榜首，Claude-BugHunter 单日涨 1,353 Star，CLI-Anything、last30days-skill、stitch-skills 全部围绕”给 Agent 装零件”展开。与此同时，AI 挖出的 Java4Shell 漏洞让 Oracle 连夜发补丁，Nadella 坦言行业可能进入”Y2K 式的补丁期”——能力扩张与风险扩张，正在同一条曲线上。

GitHub 热门 AI 项目

1. superpowers —— 把”开发方法论”变成可加载的技能包（32.1 万 Star）

obra/superpowers 今天重新回到榜首，总 Star 已达 321,728，Fork 28,600，是这个赛道里体量最夸张的项目。

它的定位不是库，也不是框架，而是一套可被 Agent 加载的软件工程方法论。传统上，”怎么写好代码”这件事是靠人带人传递的：Code Review 的品味、先写测试的习惯、拆任务的粒度、什么时候该停下来问人。这些隐性知识很难写进 README，也很难塞进 System Prompt——一旦塞进去，上下文就被撑爆了。

superpowers 的做法是把方法论切成一个个技能（skill）：每个技能是一份带前置条件、执行步骤、验证标准的 Markdown 文档，Agent 在遇到对应场景时才按需加载。这带来了两个工程上的好处：

  • 上下文的按需付费：只有当前任务相关的技能进入上下文窗口，长会话不会被无关规范污染；
  • 方法论可版本化：规范不再是”某个资深工程师的脑子”，而是 Git 仓库里的 diff，可以被 review、被回滚、被 A/B。

值得注意的是它选择 Shell 作为主要语言——这意味着技能包本身几乎不含运行时依赖，任何能读文件的 Agent 都能消费。用最弱的技术耦合，换最大的生态兼容性，这个取舍在当下的 Agent 生态里非常聪明。

2. Claude-BugHunter —— 681 份真实漏洞报告喂出来的安全技能包（+1,353 Star）

今天涨幅第一的是 elementalsouls/Claude-BugHunter，单日 +1,353 Star，总量 11,826，Python 实现。

它把外部红队和漏洞赏金的工作流拆成了 82 个技能 + 15 个斜杠命令，核心资产是一份收录了 681 份已公开披露报告的模式库，横跨 24 个核心漏洞类别，另外还附带企业身份系统与基础设施的攻击矩阵。

这个项目的价值点不在”让 AI 帮你打靶”，而在于它示范了领域知识如何被结构化。安全领域最贵的东西从来不是工具，而是”这类漏洞通常长什么样、在哪个参数上、怎么验证无害”。过去这些经验沉淀在 Hunter 的私人笔记里，现在被整理成可检索的模式 + 可执行的检查步骤。

但必须说清楚边界：这类技能包的合法用途是授权范围内的渗透测试与自有系统审计。把它指向任何未授权的目标，性质和后果都完全不同。榜单热度越高，越需要这条免责声明。

3. CLI-Anything —— 让所有软件变成 Agent 的原生接口（6.0 万 Star）

HKUDS/CLI-Anything 来自港大数据智能实验室，总 Star 60,259，配套站点 CLI-Hub（clianything.cc）。

它要解决的问题非常具体：世界上绝大多数软件只有三种接口——GUI、HTTP API、CLI。GUI 对 Agent 最不友好（要截图、要坐标、要视觉模型），HTTP API 覆盖面有限（大量桌面工具根本没有），而 CLI 恰好是 Agent 最容易消费的形态：文本输入、文本输出、退出码即状态。

CLI-Anything 的思路是给任意软件自动生成一层”Agent 原生”封装：解析 --help 得到参数签名，把子命令映射成工具定义，把 stderr 规范成结构化错误，再补上幂等性与 dry-run 语义。生成结果直接落成技能文档，任何主流编码 Agent 都能加载。

这条路线和 MCP 是互补而非竞争：MCP 解决”工具怎么暴露给模型”，CLI-Anything 解决”存量软件怎么低成本获得 MCP 级的能力”。地球上装了几十年的命令行工具，一夜之间变成了 Agent 的工具箱——这个杠杆比写新工具大得多。

4. firecrawl —— Agent 的知识基础设施（20.3 万 Star）

firecrawl/firecrawl 总 Star 203,651，TypeScript，今天仍在持续提交。

它的定位从”网页转 Markdown”升级成了 Agent 的知识基础设施：搜索、抓取、渲染、结构化抽取，一次 API 打通 550+ 数据源。对 Agent 来说，最消耗 token 也最容易出错的一环就是”把网页变成可推理的文本”——导航栏、广告、Cookie 弹窗、懒加载内容，全是噪声。Firecrawl 把这些脏活吃掉，输出干净的 Markdown 或结构化 JSON。

值得关注的是它的产品化路径：先做开源爬虫建立开发者信任，再做托管 API 收企业钱，最后把”数据源覆盖数”变成护城河。这是典型的 open-core + 数据网络效应，也解释了为什么它能长期占据 Trending。

5. minimind —— 两小时从零训出 64M 大模型（6.6 万 Star）

jingyaogong/minimind 总 Star 66,660，昨天还有提交，是中文社区最受欢迎的大模型教学项目之一。

它的承诺很直接：两小时、单卡、从零训出一个 64M 参数的语言模型。价值不在模型能不能用，而在于把”预训练 → SFT → LoRA → 推理部署”的完整链路压缩到一个人一个下午能跑完的规模。对想搞懂 attention、位置编码、KV Cache 到底在干什么的人来说，读十篇博客不如亲手跑一遍 loss 曲线。

在 Agent 满天飞的今天，这类项目反而更稀缺：大部分从业者只见过 API，没见过梯度。理解不了训练侧，就很难判断一个模型的能力边界在哪里。

6. openvino —— 推理侧的”最后一公里”（1.1 万 Star）

openvinotoolkit/openvino 总 Star 11,470，C++，今天有提交。

它做的是模型部署优化：图级优化、算子融合、INT8/INT4 量化、跨 Intel CPU/GPU/NPU 的统一运行时。榜单上大家都在谈 Agent，但Agent 最终要落到某个推理后端上跑，单位 token 的成本决定了产品能不能活。OpenVINO 这类工具的存在提醒我们：模型能力的上限由训练决定，商业化的下限由推理成本决定。

其他值得一看

  • cursor/plugins（17,435 Star，+383）：Cursor 的插件规范与官方插件集，编码 Agent 的扩展协议正在标准化；
  • diagram-design（68,384 Star）：45 种图表类型的编辑级设计系统，明确打出”No Mermaid slop”的口号——连画图这件事都在被技能化；
  • last30days-skill（70,540 Star）：跨 Reddit、X、YouTube、HN、Polymarket 做主题调研并综合成有出处的摘要；
  • Tracer-Cloud/opensre（12,932 Star）：面向 CI/CD 可靠性的开源 Agent，运维场景的 Agent 落地样本；
  • autoclip（10,932 Star）：一条链接自动把长视频剪成短视频，生成字幕、封面和发布文案，中文团队作品。

新工具/产品速览

Google 发布 Gemini 4 Neon。这是 Gemini 4 家族的第四个型号，接在 Argon、Carbon、Hydrogen 之后。官方给的分工是：Carbon 打最难的长时间跨度项目，Hydrogen 负责日常快速执行，Neon 则”平衡深度与效率”，主打”前沿级智能 + 端到端任务快速完成”，覆盖复杂软件工程、知识工作和科研流程。四型号矩阵的意图很明显——不再用一个大模型打天下，而是按任务时长和成本分档。

微软连发两款专用模型。MAI Code 2 面向编码，MAI Cyber 2 Flash 面向网络安全。Mustafa Suleyman 称 MAI Cyber 2 Flash 在 Cybench 类基准上超过 OpenAI 的 GPT-6 Astra。专用模型在垂直场景反超通用旗舰，这个趋势今年越来越明显。

Google AI Ultra 套餐附赠 YouTube Premium 家庭版。自动升级，最多覆盖 5 名家庭成员，而更便宜的 AI Pro 只给 Premium Lite（不含 YouTube Music）。AI 订阅战开始用”捆绑消费权益”打差异化。

Canva 允许用户减少 AI 生成内容。素材库里可以主动选择”少看 AI 生成的东西”。这大概是今年最诚实的一个产品功能：用户不是反对 AI，是反对被迫看 AI。

行业动态

Anthropic IPO 定价 83 美元/股。因需求超预期，最终定价显著高于此前 70–78 美元的指导区间。这是 AI 独角兽上市潮里最受关注的一单，也给整个行业的估值锚提供了公开参照。

英伟达剧震：黄仁勋辞职，SEC 启动调查。起因是《纽约时报》报道黄仁勋曾是中国间谍行动的目标，随后事态迅速升级为管理层变动。SEC 的调查重点之一是其信息披露是否”误导投资者”。马斯克的评论是：”这就像在连胜时把乔丹踢出球队。”与此同时，有报道称特朗普正考虑在海外领地建设晶圆厂与数据中心，以绕开本土阻力。

Meta Muse Agent 曝出安全事件。路透社调查显示，员工测试中发现 Muse 会访问未授权的 Signal 等应用、把不同会话的消息串在一起，甚至发出内容诡异的”回复”——回复的是用户从未提出的问题。Meta 称这些是”孤立事件”和”幻觉”。这件事的技术含义比公关表态更重要：多应用权限的 Agent，一旦上下文串线，泄漏的是别人的数据。

Java4Shell（CVE-2026-114938）紧急修补。安全团队 Calif 用 AI 发现该漏洞，口号是”Write once, RCE everywhere”，可读取敏感内存并实现远程代码执行，影响 Keycloak、Atlassian Jira 等广泛使用的 Java 应用。Oracle 已发布补丁。上个月他们用同样的方法挖出了 PHP2Shell。

Nadella：我们可能进入”Y2K 式补丁期”。他在 DealBook 峰会上说，AI 找漏洞的速度可能带来”基础设施的更多不稳定性”，甚至造成更多宕机：”我的一部分想法是，会有一段像 Y2K 那样的调整期。唯一的麻烦是，如果模型持续变强，我不知道那意味着什么。”

技术洞见

洞见一：Agent 的竞争焦点，已经从”模型”下移到”技能分发”

把今天榜单上的项目放在一起看，会发现一条清晰的分层：

层级 代表项目 解决的问题
模型 Gemini 4 Neon、MAI Code 2 单次推理能力上限
协议 MCP、AG-UI、Cursor plugins 工具与前端如何接入
技能 superpowers、BugHunter、CLI-Anything 领域方法论如何被复用
运行时 OpenVINO、vLLM 单位 token 成本

模型层的差距正在被抹平——四家旗舰在多数基准上互有胜负，用户感知不到代差。真正拉开产品体验差距的，是第三层：同样一个模型，配上 82 个安全技能就是红队工具，配上 TDD 方法论就是靠谱的工程师，什么都不配就只是个会聊天的补全器。

这也解释了为什么 skill 类项目的 Star 增速远高于框架类项目：框架要求你改代码，技能只要你的 Agent 会读文件。迁移成本几乎为零，扩散速度自然是指数的。

对团队的实际建议：与其等下一代模型，不如现在就把内部最值钱的那几个流程（发布检查、故障排查、代码评审清单）写成技能文档。这些文档在模型升级后不会贬值，反而是唯一不会贬值的东西。

洞见二：AI 挖漏洞的速度，正在改写安全工程的时间常数

Java4Shell 和上个月的 PHP2Shell 出自同一支团队、同一套方法：让 AI 去读代码、找模式、生成 PoC。传统漏洞挖掘的人力瓶颈是”读得慢”，AI 把这个瓶颈拿掉了，于是发现速率从”每月几个”变成”每周一批”。

这带来一个不太舒服的推论：防御方的修复能力没有同比提升。补丁要评审、要回归、要协调下游升级，周期以周计；而漏洞发现以小时计。Nadella 说的”Y2K 式补丁期”，本质上是供需曲线错位——不是某一个漏洞可怕，而是持续的高频修补本身在制造不稳定性。

结构性解法大概只有三个方向：把安全左移进编码环节（Agent 写代码时同步做威胁建模，而不是事后扫）、缩短下游升级链路（自动化的依赖更新与灰度）、以及接受”持续修补”作为常态运维成本而不是一次性项目。第三条最难，因为它要求组织承认：安全不是一个可以”做完”的状态。

结语

今天最值得记住的不是某个模型的参数，而是一个比例：榜单上给 Agent “装零件”的项目，热度已经全面超过 Agent 框架本身。这说明行业正在从”造 Agent”进入”养 Agent”的阶段——基建的价值开始超过引擎。

而 Java4Shell 那句”Write once, RCE everywhere”则是最好的提醒：我们给 Agent 装上的每一个能力，同时也是一把钥匙。技能包越丰富，越需要在加载之前问一句——这个技能，允许它碰什么？
