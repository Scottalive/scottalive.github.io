今日热点

今天榜单的关键词是**「把能力装进流程」**。Claude-BugHunter 以单日 +1,660 Star 重回第一，国产的 AutoClip 用一条链接把长视频拆成短视频（+983），App Store 合规手册靠 874 个 Star 证明「合规也能做成技能包」。产品侧，OpenAI 把常驻代理 Dots 下放到 20 美元的 Plus 档；而 Signal 直接开炮，称 AI Agent「对隐私充满敌意」——能力越常驻，边界问题就越尖锐。

GitHub 热门 AI 项目

1. Claude-BugHunter —— 安全技能包的第二春（+1,660 Star）

elementalsouls/Claude-BugHunter 昨日已经详细聊过它的构成：82 个技能、15 个斜杠命令、681 份已披露漏洞报告的模式库，覆盖 24 个核心漏洞类别，外加企业身份系统与基础设施的攻击矩阵。今天它继续霸榜并重回第一（总量 1.35 万 Star，Fork 1,652），有意思的不是数字本身，而是它连续两天被推上榜首这件事。

安全是少数几个「输入输出全是文本、流程高度模式化、经验以文档形式沉淀」的领域。这三条恰好是技能包最擅长的形状：把资深渗透测试者的判断拆成可加载的步骤，把「看到这个报错先查哪三个参数」这种隐性知识写成 Markdown，Agent 遇到对应场景才载入。它替代不了扫描器，也替代不了授权流程——技能包教的是「怎么想」，不负责「能不能做」。真正值得警惕的是另一面：当攻击方也开始用同样的方式批量生产技能，防守方的响应时间窗口会被压缩到以小时计。

2. AutoClip —— 一个链接，一键出片（+983 Star）

今天最「用完即走」的项目是 zhouxiaoka/autoclip：1.19 万 Star，单日 +983，Python 实现，定位是开源的 AI 视频剪辑桌面工具，把播客、访谈、课程这类长视频自动切成短视频，并顺手产出字幕、封面和发布文案，直接适配抖音、小红书、TikTok、Reels 与 YouTube Shorts。

它的价值不在「AI 剪辑」这个词，而在把一条内容再生产的完整链路压成了一个按钮。传统做一条切片视频，要在剪辑软件里拖时间轴、找高光、对字幕、做封面、写标题，一条 30 秒的成片背后是半小时的机械劳动。AutoClip 把这条链路拆成了可自动化的阶段：

技术上没什么黑魔法，难的是打分函数。切片质量的分水岭在这里：切得太碎，观众看不懂前因；切得太完整，前 3 秒抓不住人。所以真正决定成片率的不是 ASR 准确率，而是「什么样的 40 秒值得独立成片」这个判断——它同时依赖语义边界、情绪峰值和平台时长偏好。AutoClip 把这件事做成了可调的本地流程，而不是黑盒 SaaS，这一点对内容团队很关键：素材不出本地，模型可换，规则可改。

值得留意的是它的分发属性：一个工具同时适配五个平台的画幅、时长和文案风格，说明「一鱼多吃」已经从运营技巧变成了产品需求。

3. firecrawl —— 20 万 Star 的「Agent 输入层」（+1,226 Star）

firecrawl/firecrawl 今天 +1,226 Star，总量 20.5 万，TypeScript 实现，自我定位是「让 Agent 更聪明的知识基础设施」：搜索、抓取、爬取，加上 550+ 数据源，统一成一个 API。

它涨得稳，是因为踩中了一个结构性事实：模型的推理能力不再是瓶颈，喂进去的上下文才是。前端渲染、反爬、PDF 解析、分页、去重、转 Markdown——这些脏活每一个 Agent 项目都要重写一遍，而它们跟业务毫无关系。把这一层抽成 API，等于给所有 Agent 装了一个统一的「阅读器」。

真正让它区别于普通爬虫的是输出契约：结构化 Markdown 而不是原始 HTML，按 token 预算裁剪而不是整页倾倒。这直接决定了上游 prompt 的稳定性——同一个页面今天抓和明天抓，如果 DOM 结构变了导致 markdown 排版漂移，下游的抽取逻辑就会莫名其妙地失效。所以这类基础设施的护城河不在「能抓多少站」，而在同一站点长期输出的稳定性。

4. last30days-skill —— 把「调研」做成可调用的技能（+685 Star）

mvanhorn/last30days-skill，7.1 万 Star，Python，单日 +685。一句话概括：一个能跨 Reddit、X、YouTube、Hacker News、Polymarket 和普通网页做主题调研，然后合成一份有出处的摘要的 Agent 技能。

这个项目的定位很聪明：它不生产信息，它生产「带着时间窗和出处的判断」。名称里的 30 days 就是它的产品约束——只看最近 30 天，避免模型拿两年前的结论回答今天的问题。多源交叉还有一层隐含价值：Polymarket 的赔率、HN 的评论区、Reddit 的踩赞比，是三种完全不同的信号，单独看都会偏，放在一起才能看出「这件事到底是真热还是媒体自嗨」。

5. diagram-design —— 45 种图表，「拒绝 Mermaid 垃圾」（+634 Star）

cathrynlavery/diagram-design 的 README 有一句话很冲：No shadows. No Mermaid slop.（不要阴影，不要 Mermaid 垃圾。）项目提供 45 种编辑级图表模板，输出自包含的 HTML + SVG，适配 Claude Code、Codex、Copilot、Cursor、Factory Droid、Qoder、Pi 等主流编码 Agent。

这话说得不好听，但戳中了痛点：Mermaid 的默认渲染确实有股「文档凑数」的味道——节点等宽、连线正交、字号不分层级，读者一眼就知道这是自动生成的。而一份给客户看的架构图，差的就是层级、留白和视觉重心。

当然，本文自己还在用 Mermaid，原因很实在：它在这套静态博客管线里零依赖、可版本化、能跟着 Markdown 一起 diff。两件事不冲突——Mermaid 适合「随手画清楚」，diagram-design 这类方案适合「要拿出去给人看」。真正的信号是：图表生成正在从「语法问题」变成「审美问题」，而审美恰好是 Agent 最缺的一环。

6. app-store-compliance —— 把拒稿史变成技能（+874 Star）

mjmirza/app-store-compliance，总量 2,413，单日 +874，Shell 实现。内容是一份开放的上架避坑手册：117 种有据可查的拒稿模式及修复方式、隐私清单与 Data safety 检查项、95 个跟踪中的合规截止日期（EU AI Act、DSA、COPPA、各州年龄法），以及一个给 AI 编码 Agent 用的技能。

这个项目单日涨了自身总量的三分之一，说明需求真实存在。它代表的是一种新品类：把「行业里的隐性规则」编译成 Agent 可执行的检查表。App Store 审核规则不是文档问题，是判例问题——「4.3 重复应用」「5.1.1 隐私描述不实」这些条款，只有被拒过的人才知道边界在哪。把这些判例结构化，Agent 就能在提交前跑一遍自检，而不是等两周后收到一封模板拒信。

顺带一提，95 个倒计时里的 EU AI Act 部分值得单独看：合规正在从「上线前的一次性检查」变成「持续跟踪的运行时状态」。

7. minimind —— 两小时，把 64M 模型从零训出来（+841 Star）

jingyaogong/minimind 今天 +841 Star，总量 6.7 万。它做的事情一句话能说完：在两小时内从零训练一个 64M 参数的小语言模型，覆盖预训练、SFT、LoRA、偏好对齐到蒸馏的完整链路。

它的价值是教育性的，而且这个价值被低估了。今天大多数人调 LLM 的方式是「写 prompt、调 API、看输出」，对 loss 曲线、学习率、数据配比完全没有体感，于是遇到模型行为异常时只能靠猜。花两小时亲手跑完一遍完整流程，你对「预训练在学什么、SFT 在改什么、RLHF 在惩罚什么」的理解会立刻从名词变成直觉。64M 的模型当然不能干活，但它是一条能跑通的、成本可承受的完整证据链。

其他值得一看

  • opensre（Tracer-Cloud/opensre，+465，1.34 万）：面向 CI/CD 可靠性的开源 Agent，把「构建又红了」这件事交给代理去定位——SRE 场景是 Agent 落地最自然的土壤之一，因为信号全是日志和指标。
  • AFFiNE（toeverything/AFFiNE，+686，7.55 万）：Notion + Miro 的开源替代，隐私优先的知识库。它不算 AI 项目，但「AI 原生的文档协作」是它正在押注的方向。
  • stitch-skills（google-labs-code/stitch-skills，+315，1.09 万）：Google Labs 出的 Agent Skills 库，围绕 Stitch MCP server，遵循 Agent Skills 开放标准，可与 Antigravity、Gemini CLI、Claude Code、Cursor 互通。
  • cursor/plugins（cursor/plugins，+292，1.77 万）：Cursor 的插件规范与官方插件，TypeScript 实现，本质是在给编辑器生态定标准。
  • Ghost-Downloader-3（XiaoYouChR/Ghost-Downloader-3，+1,082，1.34 万）：非 AI 项目，但今日涨幅排进前三。下载器这个古老品类还能被重做一遍，说明「体验债」在成熟软件里依然是最肥的市场。

新工具/产品速览

OpenAI 把常驻代理 Dots 下放到 Plus 档。 此前 Dots 只对 Pro（月费 100 美元起）及以上开放，现在「一小部分」20 美元的 Plus 用户开始拿到访问权限，同时向所有 ChatGPT Business Standard 用户推送。Dots 的定位是常驻式 AI Agent——不是等你提问，而是在后台持续观察、主动给建议。

ChatGPT 移动端在测试新结构。 底部标签栏改成「主页 + 你的 Dot 代理」，还可以把 Codex、Images 固定上去。这个改动的信号意义大于交互意义：Agent 正在从「一个功能」变成「和聊天平级的一等公民」。

Nothing 将于 12 月 8 日发布首款「AI 原生设备」。 官方说法是围绕 AI 当前最大的局限——上下文缺口（context gap）——来设计：「智能已经在了，缺的是上下文。」产品形态据此前泄露是无屏的随身记录设备。这个叙事和 Dots 完全同频：大家都认定瓶颈从「模型够不够聪明」转向了「模型知不知道你现在在干嘛」。

Apple 在招人做跨应用 Agent。 招聘描述写得很直白：一个能浏览网页、跨应用操作、调用服务的 AI Agent。Siri 的下一步已经很清楚了。

行业动态

Signal 开始限制移动端截图，并称 AI Agent「对隐私充满敌意」。 这是本周最值得记的一句表态。Signal 的逻辑是：截图能力一旦被常驻代理调用，端到端加密就只能保护「传输」，保护不了「屏幕」——加密通信的终点变成了一个可以随时读屏的本地代理。

Anthropic 的 IPO 定价 83 美元/股。 因需求超额，定价显著高于此前 70–78 美元的指引区间。

美国批准了逾 87.9 万颗 AI 芯片对华销售。 这是众议院外交事务委员会主席在质询英伟达前披露的数据，民主党议员批评审批「缺乏审查」。同一周，据《纽约时报》报道，英伟达 CEO 黄仁勋的辞职源于其被中国间谍行动盯上的调查——资本、算力与地缘政治在同一条新闻线上缠绕。

Google 继续堆 Gemini 4 家族。 继 Argon、Carbon 之后，Hydrogen 进入 Search 的 AI Mode。模型迭代已经进入「按场景切版本」的阶段：同一个代数下，通用、网络安全、搜索各有一个变体。

500 多名 Google 员工联名请愿，要求允许学校使用不带 AI 的搜索。 Alphabet 工会的说法是「教育工作者应当有权选择如何引入 AI」，并批评公司「看起来像在惩罚不用 AI 的学校」。这是「AI 默认开启」引发的第一波内部反弹，值得关注——它预示了接下来所有「AI 优先」产品会遇到的阻力形态。

数据中心的选址正在复制历史上的红线政策。 乔治·华盛顿大学法学院等机构的研究显示：少数族裔占多数的社区出现数据中心的可能性是白人为主社区的两倍以上，亚裔为主社区则高达四倍。算力的物理足迹，正在变成环境正义问题。

DistroKid 向 UMG 和 Sony 提交了 AI 检测工具相关信息。 这是 Suno 版权案的外围战场，唱片公司正在从分发端反向获取训练数据与检测证据。

微软 CEO Nadella 仍然不知道「AI 挖漏洞」的补丁潮何时结束。 他的原话是行业可能进入一段「类似 Y2K 的调整期」，但补丁的另一面是「基础设施的更多不稳定」。

技术洞见

洞见一：常驻 Agent 缺的不是智能，是「上下文 + 权限」的双重契约

今天三条新闻指向同一件事：OpenAI 把 Dots 下放到 20 美元档、Nothing 用「上下文缺口」定义新产品、Signal 因截图权限开炮。把它们放在一起看，常驻 Agent 的真实架构就浮出来了：

这张图最关键的一条边是 E → F：常驻代理的能力上限，取决于它能在本地攒下多少上下文；而它的风险上限，同样取决于这堆上下文能被谁读到。端到端加密保护的是管道，代理读到的是屏幕——这是两套完全不同的信任模型，而今天的产品把它们混在了一起。

所以接下来一年，真正的竞争点不会是「谁的代理更主动」，而是谁先把三件事做扎实：上下文的作用域（这个代理能看到哪些应用）、动作的可逆性（做错了能不能一键回退）、以及审计的可见性（用户能不能看懂它刚才干了什么）。Signal 的抗议不是反对 Agent，是在提醒行业：常驻能力必须先有一套与之匹配的权限语法。

洞见二：技能包正在「职能化」

昨天榜单上的技能包还集中在工程领域——写代码、调 Bug、做 Code Review。今天的新面孔换了行业：合规（app-store-compliance）、设计（diagram-design）、调研（last30days-skill）、安全（Claude-BugHunter）。这个迁移很说明问题。

软件工程之所以最先被技能化，是因为它的产出可验证：测试过不过、代码能不能跑，是二值的。而合规、设计、调研这些领域的判断本来是模糊的，现在也被拆成了检查表和打分函数——把模糊判断显式化，本身就是技能包最大的贡献。117 种拒稿模式一旦写下来，就不再是某个审核老手的直觉，而是可以被 diff 的规则。

这也解释了为什么这些项目的 Star 增速比模型类项目还猛：模型能力是租来的，技能包是攒下来的。租的东西会降价，攒的东西会复利。

结语

今天没有新的基座模型发布，但「Agent 怎么被使用」这件事往前走了一大步：能力在往流程里装（AutoClip、opensre），知识在往技能里装（合规、设计、调研），而常驻能力在往手机上装（Dots）。三件事的共同前提是同一个词——上下文。谁能拿到它、谁该被允许拿到它，会是接下来最吵的一仗。
