今日热点

今天榜单前三名其实在讲同一件事：技能正在变成基础设施。Claude-BugHunter 连续第三天霸榜（+1,794 Star），superpowers 把「软件该怎么做」写成可加载的方法论，CLI-Anything 干脆给每一个软件现造一个 CLI，让 Agent 能开 CAD、能剪视频、能对着真实产物验收。产品侧，OpenAI 把常驻代理 Dots 下放到 20 美元档，Nothing 宣布 12 月 8 日发布无屏 AI 设备——入口仍在变化，但真正的竞争已经沉到了流程层。

GitHub 热门 AI 项目

1. Claude-BugHunter —— 三连冠之后，技能包在证明什么（+1,794 Star）

elementalsouls/Claude-BugHunter 今天 1.53 万 Star、1,770 Fork，单日 +1,794，是它连续第三天站在榜首。版本也在长：83 个技能、15 个斜杠命令、681 份已披露漏洞报告的模式库（其中 433 份已逐条标注出处、可审计），覆盖 24 个核心漏洞类别，外加企业身份系统（M365/Entra、Okta、vCenter、SSL-VPN、SharePoint、云 IAM）的攻击链矩阵。

它的结构值得单独拆开看，因为这是「技能包」这个形态少见的四层设计：

  • Think：bb-methodology + redteam-mindset，给的是五阶段非线性工作流和红队操作员纪律——先想清楚该测什么，再动手；
  • Hunt：58 个 hunt-* 技能，全部从真实披露报告中提炼，每一类都带检测模式、payload、绕过表和串联模板；
  • Perimeter：2024–2026 的企业平台 CVE 链与拿到凭证之后的横向提权；
  • Ship：triage-validation + reporting + evidence-hygiene，包括 7 问门禁、VRT 感知的严重性评级、OOS 申诉话术和 PII 脱敏。

有意思的是第四层。漏洞挖掘圈一直有个公开的秘密：发现漏洞的能力和把漏洞写成报告的能力，是两种完全不同的能力。前者靠技术，后者靠写作、靠对平台规则的理解、靠知道什么样的复现步骤不会被判定为「信息不足」。Claude-BugHunter 把后者也变成了技能，等于承认了一件很多人不愿承认的事——大量「低质量报告」不是技术不行，是流程没被显式化。

这也是它为什么能连涨三天：它的增量不在模型，而在经验的结构化密度。换个模型，技能照样能跑；换掉技能，再强的模型也不知道「GraphQL introspection 开着」应该优先于「去扫目录爆破」。

一个必须说清楚的边界：技能包教的是「怎么想」，不负责「能不能做」。授权范围、法律边界、披露时机，这些都不在任何一份 SKILL.md 里。攻击方同样在用这套方法批量生产技能，防守方的响应窗口正在被压缩到以小时计。

2. superpowers —— 把「开发方法论」做成可加载的技能

obra/superpowers 的自我描述只有一句：「An agentic skills framework & software development methodology that works.」听起来像口号，但看它装了什么就明白了：头脑风暴 → 写计划 → 执行计划 → 测试先行 → 系统性调试 → 请求代码审查 → 完工前验证，一条完整的软件工程链路，每一步都是独立的技能文件，还配了 git worktree 隔离和并行子代理分发的玩法。

这个项目真正的价值不在「又一个技能集」，而在它选了方法论作为切面。市面上绝大多数 Agent 工具在解决「能不能做到」，superpowers 在解决「做的顺序对不对」。

顺序为什么重要？因为模型有一种稳定的失败模式：它会跳过理解直接写代码，会跳过失败用例直接写实现，会在功能勉强跑通时宣布完成。这些不是能力问题，是流程缺失。人类工程师被这些坑训练了很多年，形成了肌肉记忆：先复现、再修复、最后回归。技能包做的事情，就是把这种肌肉记忆写成 Agent 每次都会读到的文件。

但它也有一个内在张力：流程越严格，吞吐越低。TDD 的 RED-GREEN-REFACTOR 在探索性任务上是纯损耗，头脑风暴在需求已经明确时是浪费时间。所以成熟的用法不是「全量加载」，而是按任务类型路由——改一个 typo 和重构一个模块，应该走完全不同的技能路径。

3. CLI-Anything —— 给所有软件现造一个 CLI

HKUDS/CLI-Anything 来自港大数据智能实验室，口号很直接：「Today’s Software Serves Humans. Tomorrow’s Users will be Agents.」——今天的软件为人服务，明天的用户是 Agent。

它要解决的问题非常具体：世界上绝大多数专业软件（CAD、3D、剪辑、GIS、笔记、字幕工具）既没有 API，也没有 MCP，只有一套给人类用的图形界面。Agent 想用它们，唯一的办法是截图 + 点鼠标，这是所有 GUI 自动化方案最脆弱的环节。

CLI-Anything 的解法是：读软件的原生能力（脚本接口、宏系统、插件 API、可调用的命令行参数），生成一个专属于它的 CLI harness——把「打开文件、建图层、布尔运算、导出」这些操作变成带 JSON 输出的子命令，Agent 直接调用。再配三层验证：

  1. 静态校验：生成物要过 pytest 与 schema 检查，仓库自称 100% 通过；
  2. 预览执行（preview / live preview）：操作中途产出缩略图或中间态，让 Agent「看见」自己改了什么；
  3. 轨迹回放（trajectory loop）：把一次完整操作序列录下来重放，确认可复现。

它已经跑出真实产物：CAD 建模、3D 场景、图表、游戏关卡、字幕。注册表 CLI-Hub 用 pip install cli-anything-hub 装，社区提交的新 CLI 合并后即时上架；一个 harness 能被 Pi、OpenClaw、nanobot、Cursor、Claude Code 同时消费。仓库还挂了 arXiv 论文（2606.03854），说明这套方法有可复现的评测，而不只是 demo 集。

这是我今天看到最「基础设施味」的项目。它没有做智能，它做的是把不可自动化的界面翻译成可自动化的接口，而这个翻译工作一旦完成，就永久复用。

4. minimind —— 两小时，从零训一个 64M 的小模型

jingyaogong/minimind 的中文描述朴素得可爱：「两小时从 0 训出你的 64M 大模型。」

它的意义不在于训出来的模型能干什么——64M 参数只能做很轻的对话和分类，质量远不如任何一个 API。意义在于它把整条链路完整地摆在你面前：分词器怎么建、预训练数据怎么洗、pretrain 怎么跑、SFT 怎么配、LoRA 怎么接、DPO 怎么对齐，每一步都有代码、有超参、有可对照的 loss 曲线。用一张消费级显卡，两个小时后你能得到一个会说话的模型，而且你完全知道它为什么这么说话。

这两年「理解 LLM」的路径分化得很厉害：一派读论文，一派调 API。minimind 提供了第三条——造一个小的。当你亲手把 1 万条数据的 SFT 跑完，再去看「对齐税」「灾难性遗忘」这些词，感受会完全不同。它涨得稳，是因为它服务的是所有想从「会用」跨到「会改」的人。

5. stitch-skills 与 cursor/plugins —— 技能标准的两个方向

今天有两个项目的存在本身就是信号。

google-labs-code/stitch-skills（1.12 万 Star、1,422 Fork，+324）是给 Stitch MCP Server 用的一组 Agent Skills，明确声明遵循 Agent Skills 开放标准，兼容 Antigravity、Gemini CLI、Claude Code、Cursor。

cursor/plugins（1.79 万 Star、1,967 Fork，+261）是 Cursor 的插件规范与官方插件集，TypeScript 实现。

一个从开放标准出发，一个从厂商规范出发，方向相反但终点一致：技能与插件正在从「各家私有的 prompt 技巧」变成有规范、有目录、有安装协议的组件。这和 npm 早期、Docker 早期的演化路径完全一致——先有零散工具，再有清单文件，再有注册中心，最后注册中心变成事实标准。

对开发者来说，接下来的判断会变简单：写技能时要问的不是「Claude Code 支不支持」，而是「它符不符合标准，能不能迁移」。

6. 把「审美」和「合规」也写进技能

cathrynlavery/diagram-design 的 README 有句很冲的话：No shadows. No Mermaid slop. 它提供 45 种编辑级图表模板，输出自包含的 HTML + SVG，适配 Claude Code、Codex、Copilot、Cursor、Factory Droid、Qoder、Pi。

骂得难听，但戳中痛点：Mermaid 的默认渲染确实有「文档凑数」的气味——节点等宽、连线正交、字号不分层级，读者一眼就知道是自动生成的。而给客户看的架构图，差的就是层级、留白和视觉重心。本文自己还在用 Mermaid，理由也很实在：静态博客管线里零依赖、可版本化、能跟着 Markdown 一起 diff。两件事不冲突——Mermaid 适合「随手画清楚」，diagram-design 适合「要拿出去给人看」。真正的信号是：图表生成正在从「语法问题」变成「审美问题」，而审美恰好是 Agent 最缺的一环。

mjmirza/app-store-compliance（3,117 Star，+724，Shell 实现）走的是另一条路：把上架拒稿史变成检查表。117 种有据可查的拒稿模式及修复方式、隐私清单与 Data safety 检查项、95 个跟踪中的合规截止日期（EU AI Act、DSA、COPPA、各州年龄法），外加一个给编码 Agent 用的技能。

它单日涨了自身总量的三分之一，说明需求真实。这类项目代表一个新品类的成熟：把行业里的隐性规则编译成 Agent 可执行的判例库。App Store 审核不是文档问题，是判例问题——「4.3 重复应用」「5.1.1 隐私描述不实」这些条款，只有被拒过的人才知道边界在哪。

7. 其他值得一提

  • firecrawl/firecrawl：描述换成了「Knowledge infrastructure to make your agents smarter」，搜索、抓取、爬取，550+ 数据源统一成一个 API。Agent 的输入层这块地已经基本被占住了。
  • openvinotoolkit/openvino：Intel 的推理优化与部署工具箱，端侧与异构硬件上的老牌基础设施，今天重新上榜说明「本地推理」的热度在回流。
  • Tracer-Cloud/opensre：开源的 CI/CD 可靠性 Agent。把 SRE 的排查流程做成 Agent，是「技能包」思路在运维侧的落地。
  • toeverything/AFFiNE（7.6 万 Star，+577）：Notion + Miro 的开源替代，隐私优先。它不算 AI 项目，但它是「AI 时代的知识底座」——文档、白板、数据库在同一个数据模型里，才可能被 Agent 有效读写。
  • XiaoYouChR/Ghost-Downloader-3（1.42 万 Star，+774）与 zhouxiaoka/autoclip：一个是「下载器的集大成者」，一个是「一个链接一键出片」。这两类工具持续霸榜，说明内容生产与内容搬运的自动化仍是最大的民间需求。

新工具/产品速览

Gemini 能直接生成 GIF 了。 用的是 Gemini Omni 1.2 Flash，生成约 3 秒循环的动图，正在美国、加拿大、英国、日本、韩国、澳大利亚、德国、法国全量推送。短视频之后是动图，Google 在补的是「轻量动态内容」这块空白——它比视频便宜得多，比静图有信息量。

Claude 移动端改版。 新增底部 Tab 栏，分 Chat、Projects、Code、Artifacts 四区。时间点很微妙：就在 OpenAI 宣布 ChatGPT 移动端改版（同样是底部 Tab，含首页与 Dot 代理位）的第二天。两家在同一个星期把移动端从「一个输入框」改成了「多入口的工作台」，这不是巧合——移动端正在从聊天窗口变成 Agent 控制台。

OpenAI 把 Dots 下放到 20 美元档。 常驻型 AI Agent 原先只对 Pro（100 美元起）开放，现在「少量」Plus 用户和所有 ChatGPT Business Standard 用户开始获得访问权。常驻代理的成本结构决定了它必须先在高价位验证，再往下走；现在往下走了，说明单位成本已经压到可承受。

Nothing 将于 12 月 8 日发布无屏 AI 设备。 官方说法是围绕「context gap」（上下文缺口）设计：「智能已经在了，缺的是上下文。」这句话其实是整个硬件 AI 赛道最诚实的产品定义——模型不缺，缺的是它知道你此刻在哪、在做什么。

行业动态

Nvidia 一周跌 14%，SEC 在查它的会计做法。 据路透报道，监管关注点落在「会计实践」上。对一家靠循环交易（投客户、客户买卡）撑起营收叙事的公司，这是最敏感的位置。

「数据中心巷」踩了刹车。 弗吉尼亚 Loudoun 县——美国数据中心最密集的地方——正式通过暂停令，一年内不接受新申请，预计影响 33 个在途项目。这是第一个从「欢迎」转向「等等」的核心区域。土地、电力、水资源和居民抗议，四重约束同时到位。

黄仁勋的慈善基金向 CoreWeave 投入 3.5 亿美元。 按 Bloomberg 的说法，这是该基金会上一年度最大的一笔捐赠，其中逾 1 亿美元已花出，用途是给受资助者购买算力。绕了一圈，钱又回到了算力供给方。

一项研究把数据中心选址和 redlining（红线歧视）联系了起来。 乔治·华盛顿大学法学院与美利坚大学的研究者发现：以黑人或有色人种为主的社区，出现数据中心的概率是白人为主社区的两倍以上；亚裔为主的社区则是四倍。算力的地理分布，正在复制上一代基础设施的不平等。

500 多名 Google 员工联名请愿，要求公司撤销「学校若不用 AI 功能就关闭 Search」的决定。Alphabet 工会的说法是：「教育者应当有选择如何实施 AI 的自由。」

特朗普政府批准了逾 87.9 万颗 AI 芯片对华销售（据新披露数据）。这个数字和「出口管制」的公共叙事之间的落差，值得单独写一篇。

Anthropic 一位数学家的新突破被 The Verge 称为「AI 正在多快地改变数学」的又一信号。数学是少数能被自动验证的领域，也因此是最早被真正改变的研究领域。

Etsy 将修订 AI 政策。 在卖家强烈反弹后，Etsy 表示会「尽快把修订条款直接分享给卖家」。此前的条款被解读为允许用卖家内容训练 AI，尽管官方否认。

技术洞见

一、Agent 的竞争，已经从模型层移到了流程层

把今天的东西放在一起看，会看到一条清晰的分层：

三层里，能力层正在商品化——前沿模型之间的差距，在大多数日常任务上已经小于「有没有一个好技能」造成的差距。所以价值正在向两头涌：一头是流程层（谁知道这件事该怎么做，且能写下来），一头是接口层（谁能把不可自动化的东西变得可自动化）。

这对个体的启示很直接：你在这个行业里的护城河，越来越取决于你能否把「我知道怎么做」写成「它知道怎么做」。写不出来，就只是被替代的经验；写得出来，就是可复用的资产。

二、「Agent-native」不是给软件加个聊天框

CLI-Anything 这类项目揭示了一个更根本的判断：所谓 agent-native，不是给软件加一个聊天入口，而是让软件的每一个能力都有确定的、可组合的、可验证的调用方式。

判断一个软件是否 agent-native，可以看四个问题：

  1. 能否无头运行？ 不需要人等它渲染完再点下一步。
  2. 输出是否结构化？ 是 JSON 而不是「一张好看的截图」。
  3. 中间态是否可观测？ Agent 改错了要能看见、能回滚。
  4. 操作是否可复现？ 同一串调用跑两次，产物一致。

四条全否的软件，Agent 只能靠视觉去猜，那是最后手段，不是方案。四条全是的软件，天然能被任何 harness 消费。未来两三年，「这个软件能不能被 Agent 用」会变成和「有没有 API」同等级的采购问题。

而中间那条路——给老软件补 CLI harness——会是未来几年最实在的一门手艺。它不性感，不刷榜，但每完成一个，就永久解锁了一类工作流。
