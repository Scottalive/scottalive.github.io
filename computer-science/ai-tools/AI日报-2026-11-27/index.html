今日热点

今天四条约束同时收紧。算力：Nvidia 继停供中国之后，又把马来西亚、新加坡、泰国、印尼的出货一并停了，而 Bloomberg 同一天曝出未获出口许可的 GB200/GB300 已经躺在中国相关背景的数据中心里；六天前刚说「黄仁勋不会回来」的 Nvidia，今天把他请回了 CEO 位。预算：Uber 在 AI 账单爆掉之后，砍掉了编程工具里的上下文和推理强度。权限：MCP server 现在能直接下发技能，企业开始头疼「连一个 server 等于批准了什么」。评审：近半数受访工程团队承认，写代码的 agent 也在审自己的代码。而 GitHub Trending 上最热的，仍然是那批发技能的仓库。

GitHub 热门 AI 项目

1. Claude-BugHunter：榜首第九天，旁边多出一个「发行商」

elementalsouls/Claude-BugHunter 今天 2.55 万 Star、2,602 Fork、单日 +1,615，Python。内容基本没动：85 个技能、16 个斜杠命令、681 份披露报告模式、24 类核心漏洞。

但今天真正值得看的是「Built by」那一行。Trending 前十六里，有三个技能类项目共用同一个贡献者账号 rudycelekli——Claude-BugHunter（红队）、stitch-skills（UI 组件库）、app-store-compliance（应用商店合规）。三个作者不同、领域毫不相干，却共用同一个贡献者。这种密度不是巧合能解释的。

它说明技能生态长出了第一个中间层：发行。作者只管内容，发行方负责把一份 SKILL.md 翻译成六个客户端各自的目录结构、补好安装说明、推到 Trending 上去。这条路和 npm 早期的包推广、WordPress 插件市场的「上架服务」是同构的——每个生态在内容过剩之后，都会先长出卖货的，而不是先长出品控的。

风险也随之而来：发行方没有维护义务。一个仓库被推到 2.5 万 Star，作者可能三周后就不再管了，而用户是按 Star 数做的选择。所以我现在看这类项目只问三个问题：有没有 CI、有没有 issue 模板、有没有「这条判例上次验证是什么时候」。三个都没有的，Star 再高也只是内容，不是产品。

2. CLI-Anything：把「软件接入」做成工程，难点在命令分级

HKUDS/CLI-Anything，口号是 “Making ALL Software Agent-Native”，配了一个 CLI-Hub。

思路很直白：Agent 操作软件的能力受限于软件有没有 CLI，那就把缺的补齐。这条路绕开了 GUI 自动化最脆的环节——像素坐标和弹窗时序。能用 --json 拿结构化输出，就不该去截图点按钮。

但它把风险从「看不见」换成了「看得见」：CLI 意味着真实副作用，rm、push、deploy 都是一行的事，而且没有确认弹窗兜底。所以这类 Hub 的核心资产不是覆盖率，而是危险等级标注。

图里最容易被跳过的是 E 和 J。没有 dry-run，「AI 帮我整理服务器」和「AI 帮我删服务器」在实践中是同一个动作；没有回滚记录，一次错误的 push --force 之后你连现场都重建不出来。给 Agent 递 CLI，等于递给它一把上了膛的枪——所以要连保险和弹道记录一起给。

3. cursor/plugins 与 stitch-skills：厂商开始写规范了

cursor/plugins 今天 1.99 万 Star、2,200 Fork、+242，TypeScript，内容是 Cursor 的插件规范和官方插件。google-labs-code/stitch-skills 1.35 万 Star、+311，明确说自己遵循 Agent Skills 开放标准，兼容 Antigravity、Gemini CLI、Claude Code、Cursor。

这两件事要连起来看。一年前，让 agent 认识你的项目有一堆互不兼容的写法：.cursorrules、CLAUDE.md、copilot-instructions.md、各种 *.mdc。今天它们开始收敛到 SKILL.md 一个格式。

标准化的真正信号从来不是「发布了规范文档」，而是「竞品之间互相兼容」。 stitch-skills 直接在 README 里写兼容四个竞品客户端——这是标准的特征，不是护城河的写法。反过来说，格式本身已经不是差异化了，接下来的竞争回到两件事：内容质量和分发路径。

4. diagram-design：一个明确反对 Mermaid 的技能

cathrynlavery/diagram-design，支持 Claude Code、Codex、Copilot、Cursor、Factory Droid 等，52 种图表类型，输出自包含的 HTML + SVG。README 里那句 “No shadows. No Mermaid slop.” 基本就是它的产品宣言。

这是我今天看到最诚实的一个技能：它不假装自己在做「通用可视化」，而是把自己的审美主张写在门口。技能生态要成熟，必须允许这种「有偏好的工具」存在——因为默认值的质量，决定了大多数人产出的质量，而 Mermaid 的默认值确实平庸。

（本文还是用 Mermaid，因为 Hexo 渲染零成本。这是成本取舍，不是审美判断。）

5. minimind：两小时训出 64M 模型，理解成本降到「跑一遍」

jingyaogong/minimind 一句话描述：两小时从 0 训出你的 64M 大模型。

把它和动辄几千亿参数的云端模型放同一张榜单上看，反差非常有用：中间的每一层都被抽掉了，只剩 tokenizer、注意力、位置编码、反向传播这几根骨头。理解一个系统的成本，正在从「读论文」降到「跑一遍」，这是今年教育型项目最大的价值变化。

对已经写业务代码的人来说，跑完这一遍的收益不是学会训练模型，而是获得判断力：知道 64M 模型在什么任务上必然失败，就不会被「小模型也能打」的宣传带走；知道 loss 曲线长什么样，就不会把训练不稳误判成数据问题。

6. app-store-compliance：合规也被做成了技能

mjmirza/app-store-compliance，7,339 Star、+531、Shell。125 条有据可查的拒审模式与修法、隐私清单与 Data safety 检查、117 个被追踪的截止日期（EU AI Act、DSA、COPPA、各州年龄法规），外加一个给 AI 编程 agent 用的技能。

单日 +531，占总 Star 的 7%——这个增速说明「法规倒计时」型内容有真实的焦虑支撑，而不是纯技术猎奇。但它同时暴露一个结构性问题：合规知识折旧极快。117 个日期里有一半明年就失效，而仓库里没有任何机制提醒你哪一条已经过期。这类项目最需要的不是更多条目，是一个会自己过期的数据模型。

新工具 / 产品速览

Ubuntu 明年一月上 AI 启动器。 Canonical 的 Didier Roche 放出了预览图：主屏上一个提示框，官方的说法是「统一的、键盘和语音友好的入口，只在你明确要求时连接你的应用、本地上下文和智能助手」。注意那句话里的限定语——只在你明确要求时。桌面端的 AI 和手机端走了相反的路：手机在抢默认入口，桌面在强调不主动。

OpenAI 把 ChatGPT 和 Codex 的用量额度合并了。 一个订阅覆盖两条产品线，表面上对用户是好事，实质是把「写代码」和「聊天」放进同一个成本池。这意味着重度使用 Agent 编程的用户，会开始感知到自己的对话也在花钱。

Thinking Machines 的 Inkling 2 Mini 能在笔记本上跑。 循环 Transformer 的思路，和 GLM-5.4「28 层跑两遍」是同一族手艺——用计算量换参数量。这条路今年集体出现，原因很简单：权重要占显存，多跑一遍只花时间。

Claude Fable 5.2 的成本账被 VentureBeat 算了一笔。 在他们的修 bug 测试里，Fable 5.2 花了 Opus 5.5 三倍的钱，结果几乎一样。这类评测的价值不在排名，在于提醒一件事：同一任务上，贵的模型不一定更对，只一定更贵。

行业动态

芯片管制的边界在往外扩。 Nvidia 此前已停止向中国出售 H200，本周据 FT 报道又停了马来西亚、新加坡、泰国、印尼的出货，背景是美国上周生效的新规，专门堵「通过海外数据中心远程访问先进算力」这条路。同一天 Bloomberg 曝出：未获出口许可的 Blackwell GB200 和 GB300，已经装进了至少两个与 Megaspeed 有关的数据中心——那家公司已被美国列入实体清单。管制写在纸上，芯片躺在机架上，中间的差额就是这门生意真正的利润率所在。

Nvidia 把黄仁勋请回了 CEO 位，距「排除其回归可能」的声明只有六天。 这个反转本身比任何财报都更能说明公司治理的现状。The Verge 引 Dan Davies 的评论值得抄下来：黄作为管理者和生意人受的伤，可能比外界以为的重；而 OpenAI 在 Altman 那次「LOL，没什么大不了」之后，也再没真正恢复过领先。

Anthropic 开始向作者支付版权和解金。 这是训练数据版权案里少见的「真金白银落地」节点。金额不重要，重要的是它给后来者定了一个可参照的价签。

纽约州给 AI 玩具按下五年暂停键。 Hochul 签署的法案禁止生产、分销和销售「通过联网与儿童对话的毛绒玩具、玩偶和机器人」，为期五年。一个月前该州才刚限制聊天机器人对未成年人的交互方式。监管的手正在从「模型输出」伸到「硬件形态」。

Etsy 的 AI 条款风波没平。 平台改了两版措辞，承诺不用卖家内容生成「仿制品」，但卖家仍在成批迁出。用户对「训练」这两个字的容忍度，比对涨价低得多。

Character.AI 被多位州检察长指控拟将未成年人个人数据卖给出价最高者。 两党联合，说明这事已经越过党派分歧线。

近半数工程团队让写代码的 agent 自己审代码。 VentureBeat 的调查数字。这不是懒，是吞吐量压力下的必然——但它在流程上删掉了唯一一个「独立信号源」。

Uber 在 AI 预算爆掉之后，把编程工具里的上下文长度和推理强度调了回去。 这条比任何模型发布都值得记：第一个大规模承认「用多了不划算」的案例，往往标志着技术从尝鲜期进入运营期。

技术洞见

洞见一：上下文从「越多越好」变成一条要算边际收益的曲线

今天有三条独立证据指向同一件事。

T-Mobile 发现自己给 AI 更多材料去读，答案反而更差。Uber 在超预算后主动砍掉上下文和推理强度。Snowflake 在做 token 上限，而且做法很有意思——保留上限，然后从撞线的人身上学，看谁在什么任务上真的需要更多。

这三件事合起来说明：上下文不是免费资源，它有自己的边际收益递减曲线，而且这条曲线在不同任务上形状完全不同。过去两年业界的默认动作是「能塞多少塞多少」，2026 年下半年开始转向「按任务选多少」。

关键的判断点在 H 那条边：答案不好，第一反应是不是「加材料」，而是「材料对不对」。 大多数上下文失效不是量不够，是检索进了噪音，模型把噪音当成了证据。把「加 token」当成默认修复手段，等于用钱买错误。

洞见二：评审被自动化了，但独立信号没有补上

近半数团队让写代码的 agent 也审自己的代码——这在成本上完全合理，在质量上则要看一个前提：评审的价值来自「不同来源的信号」，而不是「第二次意见」。

VentureBeat 那篇讲 ML 测试的文章把这个逻辑讲透了：模型在干净、熟悉的数据上通过所有测试，然后进生产，输入变脏、标签漂移，于是安静地退化。测试通过从来不等于可靠，它只等于「在这批测试上没被证伪」。 同一个模型审自己的代码，是同一个盲区被问了第二遍——它会一致地把「我没想到的边界」继续漏掉。

要补的不是第二个模型，是外部判据：真实流量的金丝雀指标、失败样本的回归集、上线后 24 小时的错误率曲线。这三样东西不依赖模型自证，模型再自信也改不了它们的读数。

同一逻辑也适用于今天的 MCP 技能潮。客户端裁决技能能不能加载，靠的是分类器；而分类器的判断依据，最终还是要落到可回放的审计记录上——没有记录的治理，只是感觉良好。

把今天所有事放一起看，主线其实很朴素：这个行业正在给每一样免费的东西标价。 算力有出口管制，上下文有 token 预算，权限有客户端裁决，评审有独立信号的要求，连「Star 数」都在被发行方定价。技术能力的上限还在涨，但决定它能落地多少的，越来越是这些标价牌上的数字。

而工程判断力，说到底就是知道每一项约束值多少钱。
