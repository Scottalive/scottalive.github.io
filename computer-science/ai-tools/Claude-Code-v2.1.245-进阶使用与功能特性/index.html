2026 年 8 月 25 日，Anthropic 发布 Claude Code v2.1.245。Claude Code 的迭代速度已经是”几乎每日一版“（8 月 17 日～25 日就发了 10 个版本），功能从”终端里的编码助手”长成了”跨终端、桌面、Web、手机的全栈 Agent 工作台“。

本文基于 v2.1.245 及近期更新日志，系统梳理当前版本的功能全景与进阶玩法：多智能体协作、远程控制、MCP/插件生态、沙箱安全、CI 自动化，以及一堆”别人不知道”的效率细节。如果你是老用户，重点看标 ⭐ 的新变化；新用户建议先读系列前作《Claude Code 安装与使用指南》。

三、核心工作流进阶

3.1 Plan 模式与 Auto 模式

  • Plan 模式：先规划后执行，改代码前给你看方案，适合复杂重构；
  • Auto 模式（自动模式）：让 Claude 自己判断哪些命令可以直接跑。近期更新把它做得更稳了：
    • 分类器在 Bedrock / Vertex AI / Foundry / 关闭遥测时也使用与 Claude API 一致的默认策略，按严重度分级评分；
    • Auto 模式下 Monitor 的允许规则会被暂时搁置，与 Bash 命令一样走分类审查，防止绕过；
    • git status 检查不再被 status.showUntrackedFiles=no 骗到。

3.2 Checkpoints + 后台任务 + /goal 长任务看护

  • Checkpoints：任务节点自动存档，随时回滚；
  • 后台任务：长任务扔到后台，/goal 让 Claude 记住目标并主动汇报；
  • ⭐ /goal 的 check-in 频率更聪明了：后台长任务时自动按 30 分钟 → 1 小时 → 每 2 小时递减打扰；从 /resume 选择器恢复会话时也会恢复进行中的 goal。

3.3 上下文管理

  • /compact：压缩历史（技能参数不会被误重放）；
  • /recap：会话要点回顾（自动 recap 文本上限 400 字符，按词边界截断，不再刷屏）；
  • /insights：会话洞察；
  • 长期交互会话的内存问题也修了：子代理工具结果离开显示窗口后即释放，不再无限增长。

3.4 模型、推理强度与成本控制

  • /model：切换模型；⭐ 新增 ANTHROPIC_DEFAULT_MODEL 环境变量——设置新会话默认模型，且 /model 手动选择仍可覆盖并跨重启持久化（区别于旧的 ANTHROPIC_MODEL）；
  • /effort：推理强度（思考深度）；
  • /cost、/usage、--max-budget-usd：成本控制；⭐ /usage 现在对 Team/Enterprise 成员显示 usage-credits 花费行；费用估算已包含数据驻留工作区（data-residency）的 1.1× 美国境内推理溢价。

四、多智能体与跨设备协作 ⭐

这是近期更新最密集的方向，也是”进阶”感最强的部分：

4.1 子代理、队友与跨会话消息

  • ListAgents / SendMessage：现在会列出实时在线的队友（之前只显示子代理和其他会话，队友看着像”不在线”），并且会话能知道自己的名字；
  • ⭐ Windows 跨会话消息正式可用：不同机器上的 Claude Code 会话可以互发消息（此前仅 macOS/Linux）；
  • ⭐ notify_when_idle：跨会话消息的新参数——请求对方”下次空闲时通知我一次”，一次性、免轮询（macOS/Linux）；
  • 消息投递更透明：被拒绝（crossSessionInbound: "refuse"）或队列满被丢弃时，发送方会收到明确提示，不再”假装成功”。

4.2 Remote Control：手机遥控终端会话

  • 从手机/网页/桌面给终端里的会话发消息、看进度；
  • 近期韧性大升级：网络边缘/VPN/代理的短暂 403 拒绝容忍最多 3 分钟自动重连；登录过期自动续期；断线后进程崩溃的会话可复用；模型在手机上切换后终端实时同步；
  • 会话下线状态秒级更新，claude remote-control 的服务端会话也能被 ListAgents/SendMessage 找到。

4.3 Cloud Sessions 与 Claude in Chrome

  • Cloud Sessions：网页 / 桌面 / 移动端无缝续聊；
  • ⭐ 云端插件同步：从 claude.ai 同步的插件显示为 name@synced，支持 claude plugin enable/disable <name>@synced，永远不会覆盖你本地安装的同名插件；
  • Claude in Chrome：/clear 会关闭该会话的 Chrome 标签组；恢复会话时清理空标签组。

五、扩展体系详解

5.1 MCP：连接一切工具

  • 支持 stdio 与 remote（远程）MCP 服务器；远程服务器瞬时 5xx 重连不再永久失败；
  • ⭐ elicitation forms（引导表单）：MCP 工具需要参数时弹表单，全屏模式下表单自适应终端高度，Accept/Decline 始终可见；
  • ⭐ headersHelper：url marketplace 或 catalog 条目可以挂一个”生成 HTTP 头”的命令（如短期 token），安装/更新该插件时执行；项目 .mcp.json 中的 headersHelper 现在要求先接受该目录的信任对话框，且不继承凭据环境变量，从 Claude 配置目录运行——更安全。

5.3 Skills 与 Hooks

  • Skills：技能热加载（SDK/VS Code 会话中修改技能不再报错）；修复了 UTF-8 BOM 开头导致技能/代理/命令被静默忽略的问题；
  • Hooks：PreToolUse 等钩子贯穿会话生命周期；⭐ OpenTelemetry 追踪修复——被 PreToolUse 钩子延迟执行的工具调用会回到原回合的 trace，不再另起一条造成碎片化。

5.4 输出风格与键位：把 CLI 调成你的形状

  • ⭐ 内置 “Concise” 输出风格：直接给结果，砍掉铺垫与叙述，活照干——/config → Output style 里选；
  • ⭐ keybindingFlavor: "readline"：让 Ctrl+W 像 Bash 一样删到上一个空白；Alt+F / Ctrl+→ 跳到词尾、Alt+D 删词、Ctrl+Y 粘贴回来（默认 classic 不变）；
  • vim 模式：agent 视图下 Esc 正常进入 NORMAL 模式且不清空已输入内容；
  • 自定义输出风格/项目/插件中途”漂回默认腔调”的问题已修复。

5.5 其他命令细节

  • 输入斜杠命令拼错时直接报错而不是”模糊匹配跑偏”；前缀和别名仍可用；
  • /config、/model 面板在全屏模式下不再遮挡最新消息（对话保持钉在面板上方）；
  • /workflows 详情对话框超高时不再溢出丢表头。

六、安全与沙箱

  • 沙箱：Linux 下沙箱内 git 命令兼容 extensions.worktreeConfig；⭐ macOS 上通配符读拒绝规则（如 **/.env）在允许读区域内优先，覆盖被匹配目录的全部内容，且不能通过重命名文件绕过；
  • 权限模式：default / acceptEdits / plan / bypassPermissions / auto 五档；
  • 审批体验：权限弹窗的 diff 中 emoji/制表符等宽字符不再被裁切；MCP 权限弹窗带”不再询问”选项；
  • 掩码（密码式）输入框的内容不会被 Ctrl+Y 粘贴走或写入 prompt 历史——登录码这类敏感输入更安全。

七、工程化：CI 与自动化

Claude Code 不只是交互工具，也是自动化引擎：

  • claude -p（print 模式）：无头执行，适合 CI；SIGTERM 退出码 143，不再记录被打断的回合；
  • GitHub Actions：官方 action 一键接入；
  • ⭐ /claude-api upgrade：把 Python 项目从 anthropic 0.x 迁移到 1.x 的一键命令（1.x 超时用 anthropic.Timeout 而非 httpx.Timeout）；
  • ⭐ self-hosted runners：--defer-shutdown-max-min <minutes> 让 runner 收到 SIGTERM 后先服务完附着会话再退出；--proxy-authorization-command/file 支持每次连接都要新签发 Proxy-Authorization 头的出口代理；
  • CLAUDE_CODE_RETRY_WATCHDOG：持久重试模式，遇到组织消费上限/额度耗尽错误立即失败而不是无限等待重置；
  • OpenTelemetry：完整可观测，配合 hooks 追踪工具执行。

九、值得知道的效率细节（近期更新精选）

  • ⭐ fullscreen 渲染器：Bedrock / Vertex / Foundry 等此前排除的平台也支持了，新安装默认全屏；渲染器启动失败会自动回退经典渲染器；
  • 自动更新检查延迟到启动后 10 秒，不再抢启动 CPU；
  • 终端标题只在变化时写入（tmux 不再 960ms 抖动一次）；
  • /resume 不会再因为路径里 _/-/. 的差异跨目录串会话；已删除目录（如移除的 worktree）中的会话自动在当前目录恢复；
  • 工具调用行的长路径中间截断保持单行；
  • 移动端上传的图片会带上保存路径，Claude 可直接拷进它创建的文件；
  • Web 端 Bash 等工具对非 API 域名的请求走会话网络代理，遵守你环境的域名白名单；
  • WebFetch 过期内容不再驻留内存一整个会话（改为 15 分钟）；
  • 修复了 JetBrains 终端里 Edit/Write 卡 5 秒的问题。

十、总结

v2.1.245 的 Claude Code 已经远远超出”终端编程助手”的范畴：

  • 能力：规划/自动双模式 + 检查点 + 后台任务 + goal 看护；
  • 协作：子代理、队友、跨机器跨会话消息（Windows 补齐）、手机远程控制、云端会话——一套多智能体网络；
  • 扩展：MCP 生态、插件市场、Skills、Hooks、可定制的输出风格与键位；
  • 可信：沙箱、五档权限、auto 分类器、费用上限、OpenTelemetry；
  • 工程化：claude -p + GitHub Actions + SDK 1.x + self-hosted runners，直接嵌入你的 CI。

对个人开发者，最值得立刻试的三个新东西：/goal 看护长任务、Concise 输出风格、readline 键位。对团队，跨会话消息 + Remote Control + self-hosted runners 值得立即评估。
