2026 年 8 月 3 日，Nous Research 发布了 Hermes Agent v0.20.0（代号 “The Herald Release”），随后在 8 月 13 日～19 日连续迭代了 v0.20.1～v0.20.5 五个补丁版本。从 v0.19.0 算起，这个窗口累计 3,650 个提交、1,400 个合并 PR、5,200+ 文件变更、~1,200 个 issue 关闭，650+ 位贡献者——是 Hermes 有史以来最大的一次版本跨越。

如果说 v0.17 是”把手伸出去”（The Reach），v0.20 就是”成为信使神”：会说话、会传话、会宣告、会引经据典。本文聚焦 v0.20 系列的核心新特性与实战进阶用法，适合已经安装过 Hermes 的老用户升级，也适合新用户一步到位。

一键更新

想尝鲜最新补丁也可以走全新安装：curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash。

版本脉络速览

先看 6 月 v0.17 到 8 月 v0.20.5 的演进时间线：

一句话概括三个节点：

版本 代号 主题
v0.19.0（7/20） Quicksilver 快如闪电：首 token 提速 80%、智能审批、密码管理器接入
v0.20.0（8/3） Herald 信使神降临：语音对话、A2A 协议、出站 Webhook、可信研究
v0.20.1~0.20.5 补丁流 快速迭代：MCP 2.x、Bot Mode、零密钥 Web 层、cron 持久记忆

一、v0.20.0 “The Herald Release” 核心新特性

1.1 会说话的 Hermes：流式语音对话 + 打断 + 唤醒词

核心痛点解决： 以前的语音模式是”留语音信箱”——说完等半天，然后听一整段音频。现在变成真正的对话。

  • 流式 TTS：回复边生成边逐句播报，不用等全文；
  • Barge-in 打断：你随时可以抢话，Hermes 会停止播报、认真听你新的指令，并告诉模型”用户中途打断了”；
  • 忙碌感知静音检测：你正忙的时候它不会抢着说话；
  • 开放词汇唤醒词："Hey Hermes" 或任意你自定义的词都能唤醒，检测完全在设备端进行，等待期间音频不出本机；
  • 多 Profile 语音路由：不同唤醒词可以路由到不同 Profile，说 “stop” 即可在任何界面结束语音会话；
  • 全平台覆盖：CLI、桌面端、以及所有支持音频的网关平台（WhatsApp / 飞书 / DingTalk / LINE / QQ / Photon / 微信）。发一条语音消息过去，自动转写并回答，TTS 回复还会按平台自适应编码（需要 opus 的地方用 opus，字幕正确附加）。

STT 也全面可配：独立的 hermes 工具类别、GUI 开关、仪表盘下拉菜单、统一语言解析（转写不再跑偏语言），并支持 OpenAI gpt-transcribe。

1.2 Hermes 说上了”同一种语言”：A2A v1.0

A2A（Agent-to-Agent）协议 v1.0 以内置插件形式落地，Hermes 可以发现、对话、并被其他 A2A 兼容智能体驱动——这直接关闭了仓库里最古老的 feature request（issue #514）。

对正在搭建异构多智能体系统的团队来说，这等于拿到了一个标准线缆：不同技术栈的 agent 终于能互相插拔了。

1.3 出站 Webhook：Hermes 主动”宣告”事件

核心痛点解决： 以前把 Hermes 接进自己的系统，只能轮询或被动监听平台消息。现在它能把事件推给你。

  • 注册任意 HTTP 端点，即可接收签名后的生命周期事件：会话活动、回合完成、工具调用事件；
  • 事件带 HMAC 签名，接收方可以验证真实性；
  • 典型场景：接入 CI、家庭自动化、自定义仪表盘——零轮询。

1.4 研究结果”可溯源”：Grounded Citations + 事实核查

新的 grounded-citations 技能让 Hermes 的研究输出每条论断都有可验证出处：

  • 引用会对照真实页面文本匹配（而不是幻觉式引用）；
  • 每条引用都链到确切证据位置；
  • 新增事实核查模式：把任何文档或论断丢给它，它会告诉你哪些查证属实、哪些不成立、哪些无法验证。

对拿 Hermes 做调研的人来说，这是从”听起来对”到”有据可查”的分水岭。

1.5 桌面端从聊天客户端变成”工作台”

  • Artifacts：生成的 HTML / 应用以版本化卡片形式展示，右侧栏沙箱实时预览，安全地跑在聊天旁边；
  • 插件 SDK 正式落地：首个官方插件是 Kanban；插件可用 ctx.download 给用户发文件、支持浮动面板、多窗口；
  • 全局快捷键快速入口：在系统任意角落按下热键，弹出小窗，把灵感记入任意会话；
  • 后续补丁继续打磨：毛玻璃半透明界面、SESSIONS | BOTS 标签页侧边栏、Kanban 原生系统通知。

1.6 CLI 力量型命令一波流

命令 作用
!command 直接执行 shell 命令，不消耗模型回合
/init 扫描项目，自动生成（或更新）AGENTS.md
/diff 任意界面查看 staged / all / 会话内变更
/context 拆解到底什么占满了你的上下文窗口
/focus 精简输出视图，隐藏行可恢复
Ctrl+S 把写了一半的 prompt 存进可浏览的面板
hermes import-agent 一条命令把 Claude Code / Codex CLI 配置迁移过来

1.7 中途纠偏：不用再”停止重来”

Hermes 跑偏了？直接在它干活的时候输入纠正，当前回合会被重定向：进行中的工作保留、原始 prompt 保留、agent 按新指引修正航线。配合双击 ESC 丢弃草稿、输入撤销栈，”操控感”从”重启”变成了”编辑”。

1.8 工具会自愈，长任务不再撞墙

  • 终端输出被截断时，溢出内容自动落盘成文件让模型回读；
  • patch 能检测”已经应用过的编辑”，并诊断空白符不匹配；
  • write_file 写完校验磁盘内容；
  • 搜索无结果时会探测近邻并恢复；
  • 常见失败类型附带可操作提示——模型不再瞎猜；
  • 工具调用迭代上限从 90 提到 500：长时间自主运行不再撞人工墙。

1.9 更”尊重人”的上下文压缩

  • 大窗口模型主动修剪工具结果；
  • 每回合微型压缩摊薄成本，取代一次性的长暂停；
  • 保证保留最近 N 条用户消息，长对话不丢重点；
  • 超时机制感知进度，不再惩罚慢的总结模型；
  • “幽灵技能”防御：被修剪的技能不会悄悄污染会话；
  • 阈值可按模型配置，支持绝对 token 数。

二、回顾 v0.19.0 “Quicksilver”：上一个版本打下的底子

v0.20 是站在 v0.19 肩膀上的，几个关键能力仍然值得单独说：

  • 首 token 提速 ~80%：冷启动从 ~4.3s 压到 ~0.9s，CLI / 网关 / TUI / 桌面 / cron 全平台生效；推理模型的思考过程默认实时流式输出；
  • 桌面端 20+ 性能 PR：markdown 分片快 14 倍、巨型 diff 虚拟化渲染、会话切换不再抖动；
  • 终端里管钱包：/subscription 和 /topup 直接在 TUI 里查看套餐、预览升级费用并完成支付；
  • 智能审批成为默认：被标记命令由 LLM 评审员独立判断，每条命令单独裁决；配合自定义 deny 规则（yolo 模式下也拦得住）和 /deny <reason> 让模型理解你为何拒绝；
  • Bitwarden & 1Password 接入：全新的 SecretSource 接口，API Key 不再需要明文 .env，支持 op:// 引用、多保险库并存、冲突告警；
  • 子代理现场直播：delegate_task 返回实时转录文件，tail -f 就能看每个子代理的每一次工具调用；后台委托结果持久化，进程重启也不丢；
  • 投递义务账本：网关在生成回复与平台确认送达之间崩溃？回复已记录在 state.db，下次启动自动补投——关闭了 Telegram/Discord/Slack 等渠道的静默丢失窗口；
  • 一个网关多个 Profile：单个 bot token 按频道/群/线程路由到不同 Profile，配置、技能、记忆、密钥完全隔离；
  • 推理强度变成旋钮：新增 max / ultra 档位，支持按模型、按 MoA 槽位、按辅助任务分别设置；
  • 会话数据是你的了：hermes sessions export 支持 Markdown / Quarto / HTML / 纯 prompt / Hugging Face trace 格式，--redact 脱敏，配合 prune 与批量归档管理会话库。

三、v0.20.1 ~ v0.20.5：五连击补丁里值得知道的干货

  • MCP 2.x SDK 迁移 + 2026-07-28 无状态协议支持（v0.20.3）；
  • Bot Mode（hermes-bots）内置插件：核心队友协议，支持群聊房间线程、跨机器路由、成员回合（v0.20.3/0.20.5）；
  • 零密钥 Web 层：全新安装即开即用，5 家厂商免费额度环形故障转移，web 搜索不用配任何 key（v0.20.5）；
  • cron 任务获得持久记忆 + 每任务推理强度：定时任务不再”失忆”，还能按任务设定思考深度（v0.20.5）——这对跑 AI 日报/热点这类定时内容生成是刚需；
  • NVIDIA SkillEvaluator Tier 1 咨询扫描：安装技能时自动做许可证 + 安全审查（v0.20.4）；
  • PDF / 文件附件 + 拖拽上传（v0.20.5）；
  • CLI 体验抛光：fuzzy /model 选择器、Ctrl+P 命令面板、更丰富的 /status（v0.20.5）；
  • hermes update 收据 + fleet --plan 验证、hermes worktree list/prune（v0.20.5）；
  • 桌面端：多网关 Connections 注册表、MCP 健康检查与深链、React Compiler 双渲染器性能优化（v0.20.2/0.20.5）；
  • 稳定性：cron 调度器自愈（EMFILE 恢复、陈旧 claim 对账、卡死任务重挂）、会话交接防丢数据、Python 子进程运行时隔离（PYTHONHOME/PYTHONPATH）、/rollback 保留手改（v0.20.3）。

四、进阶实战

4.1 把 Hermes 变成”免提助手”

  1. 在语音设置里配置自定义唤醒词（比如你的名字），确认端侧检测已开启；
  2. 多 Profile 场景：给”工作”和”居家”两个 Profile 配不同唤醒词；
  3. 把飞书 / WhatsApp 等渠道接入网关，出门在外直接发语音消息即可；
  4. 说 “stop” 随时终止所有界面的语音会话。

4.2 用 A2A 编排异构智能体

场景：你的团队同时用 Hermes 和另一套 A2A 兼容 agent。装好内置 A2A 插件后：

  • 让 Hermes 作为编排中枢，把子任务派发给其他 agent；
  • 用实时转录观察每个参与者的工具调用；
  • 所有结果由 Hermes 汇总呈现，你在一个界面里管整个舰队。

4.3 Webhook 把 Hermes 接进你的流水线

注册一个 HTTP 端点接收会话活动 / 回合完成 / 工具事件，服务端用 HMAC 验签后：

  • CI：Hermes 回合完成 → 触发构建或代码审查流程；
  • 家庭自动化：语音让 Hermes 干活 → 事件推送 → Home Assistant 执行；
  • 仪表盘：实时展示每个会话的 token 消耗和工具调用。

4.4 写”可交付”的研究报告

用 grounded-citations 技能做调研，然后开事实核查模式过一遍关键论断：交付物里每条引用都可点击溯源，再也不会被质疑”这个数字哪来的”。

4.6 cron 持久记忆 + 按任务调推理强度

定时任务是 v0.20.5 的最大受益者：cron 作业现在跨运行保留记忆（跑日报的 agent 记得上一篇写了什么，不会重复选题），并且每个任务可以单独设置推理 effort——常规任务用低档省 token，深度分析用高档。

总结

v0.20 系列让 Hermes 完成了从”打字机器人”到”多模态信使”的进化：语音是新的输入输出方式，A2A 是新的协作协议，Webhook 是新的集成接口，Grounded Citations 是新的信任基础，而 v0.20.1~0.20.5 的快速补丁又把稳定性、Bot Mode、零密钥体验和 cron 记忆补齐。

如果你还在 v0.17 或更早，中间的 Quicksilver 提速和 Herald 语音/A2A 足够构成立刻升级的理由。hermes update，然后开口说第一句话吧。
