2026 年 8 月，OpenClaw 发布 2026.8.1 稳定版（同时有 2026.8.1-beta.3 预发布）。这是”All your chats, one OpenClaw”的一次大跨度升级：GPT-5.6 全系推理支持、Puppeteer 兼容 CDP 中继、外部网关监管、SQLite 快照备份……如果你还在 2026.7.x（我写这篇文章时本机就是 2026.7.1-2），升级窗口已经打开。

本文基于 2026.8.1 官方发布说明与 CHANGELOG，系统梳理：新功能亮点、安全模型、Control UI 大更新、通道/语音/移动端能力，以及对应的进阶使用姿势。

二、2026.8.1 六大核心亮点

官方 Highlights 直接划重点：

  1. GPT-5.6 Sol / Terra / Luna / Ultra 推理支持——横跨 OpenClaw 与 Codex 双引擎；
  2. Control UI 首次启动引导升级——验证模型配置后自动进入 Custodian（守门人）与可选的通道配置；
  3. Puppeteer 兼容 CDP 中继——配对的 Chrome 会话可被 chrome-devtools-mcp 等客户端直接驱动；
  4. 显式外部网关生命周期监管——OPENCLAW_SUPERVISOR_MODE=external，带验证的重启交接；
  5. SQLite 快照备份——openclaw backup sqlite create|list|verify|restore，紧凑、可校验、仅限全新目标恢复；
  6. 通道插件共享持久化入站监视器——IRC、Synology Chat、Google Chat 已迁移到共享生命周期。

三、模型与推理：GPT-5.6 全系 + 原子切换

  • GPT-5.6 家族：Sol / Terra / Luna / Ultra 四档全部打通，OpenClaw 与 Codex 引擎共用；
  • ⭐ 模型 / 运行时 / 思考强度原子选择：通过 /model 与 fallback 机制一次切换到位，不再”模型换了思考档位还停在旧的”；
  • 新装默认值：OpenAI API Key 场景默认 openai/gpt-5.6（Sol 别名），Codex/OAuth 场景默认精确的 openai/gpt-5.6-sol，两个运行时默认 Sol + medium 推理；已存在的 primary/fallback/别名和显式 GPT-5.5 选择都会保留；
  • Meta 新 provider：内置 muse-spark-1.1 模型支持（Responses API 流式、工具调用、加密推理回放），可独立 npm/ClawHub 分发；
  • 本地模型引导：Ollama、llama.cpp、LM Studio 在 Control UI / macOS 中作为”提供商自有”选项展示，LM Studio 服务不可用时可原地重试，成功前会校验精确准备的模型。

四、安全模型强化

  • ⭐ Secret egress host binding（秘密出口主机绑定）：每个共享存储 Secret 绑定到精确的 HTTPS 目标主机，CLI / Gateway RPC / Control UI 三处一致生效；未绑定的哨兵替换失败即关闭（fail closed），杜绝明文外泄；
  • 插件安装来源警示：任意可执行插件来源需要显式 --force 确认（CLI 与聊天安装都生效）；ClawHub、捆绑、官方目录、受跟踪更新流程保持无摩擦；Crestodian 安装仅限可信来源；
  • Trusted-proxy 浏览器配对：白名单代理身份的新 Control UI / WebChat 设备可自动批准配对（带非管理员作用域上限），已有设备升级仍需手动；
  • 浏览器扩展中继安全：要求 64 字符中继密钥与安全的 WebSocket 配对 URL；每次执行”现有标签页”命令前在扩展边缘复查标签组授权。

五、多通道与消息能力

  • Discord / Slack 原生 /login：注册到原生命令菜单；配对码仅在私聊与 Web UI 发放；
  • Slack 进度指示：默认使用 Slack 原生 assistant 线程状态 + 轮转加载消息（不再靠静态表情）；
  • Telegram 实时位置：初始/移动/停止的 live-location 更新通过 message_received 钩子暴露，不触发 agent 回合；
  • Buzz（Nostr 通道）全面升级：消息保真（Markdown 保留）、房间/线程级 typing 指示、成员目录（bot/member/room）、NIP-27 原生提及（越界身份与未解析标签会被拒绝）；
  • ClickClack：openclaw onboard / openclaw channels add clickclack 引导配置（URL/token/workspace 提示、网关感知的下一步）；每个 bot 的原生命令发布到 composer 自动补全；bot 协作 opt-in（显式发送者授权、提及门控、防重试循环、独立线程预算，默认拒绝 bot 流量）；
  • 通道插件共享生命周期：持久化入站监视器统一了 admission、轮询、修剪、claim 身份校验、接管交接与关闭——IRC / Synology Chat / Google Chat 已迁移。

六、Control UI：这次更新最密集的地方

  • 首启引导：模型配置验证后自动进入 Custodian（守门人设置），说明”无通道也可用 Web 应用”，并给可关闭的通道配置入口；Custodian 向导在图形端渲染为原生下拉/多选/文本框/掩码密钥输入（文本聊天兼容）；
  • 更新恢复：”有新版本”的 Reload 按钮会等网关重启完成再刷新，不再静默失败；
  • 在线名单：点击侧边栏底部头像组，弹出可滚动在线成员名单（头像/名字/邮箱，自己置顶）；
  • 用户资料：trusted-proxy 用户可管理自己的昵称与头像（Gravatar 代理），他人资料仅管理员可改；
  • 消息上下文：悬停时间戳即可看到该消息的 token、上下文与模型 细节；
  • GitHub 预览卡片：悬停/键盘聚焦展示 issue/PR 的状态、标题、作者、活动、评论与变更统计；
  • 侧边栏导航：自定义固定目的地集合，其余收进 More，Settings 移到底部；
  • 云工作区冲突：云端 worker 保留了本地版本时，展示 staged-ref 指引与冲突路径，侧边栏提醒；
  • 聊天布局：转录以输入框轴线居中，助手/工具输出靠左、用户气泡靠右；快捷键 ⇧⌘B 展开会话工作区、⇧⌘, 打开设置；
  • ⭐ 目录终端（Catalog Terminals）：符合条件的 Codex / Claude Code 会话可直接在网关或配对节点宿主的原生 CLI 中打开（PTY 中继、校验过的 resume 命令、查看器 vs 终端偏好）——macOS 配对节点同步支持双工终端；
  • cron 模型选择：Control UI 快速创建里可为 agent-turn 任务选模型，任务行/详情显示配置或默认模型；
  • Dashboard MCP 应用：把会话来源的 MCP 应用视图钉成常驻仪表盘 widget，续期沙箱视图租约，工具交互受修订绑定的授权保护；
  • Logbook 工作日志插件（默认关闭）：把配对节点屏幕快照变成私有时间线 + 每日站会 + 基于时间线的问答（插件贡献的 Control UI 标签页）。

七、语音：Fish Audio 与 Talk 控件

  • Fish Audio S2.1：托管式流式合成、语音笔记、语音发现、电话场景；
  • 本地 Fish S2 Pro：macOS 原生 Talk 支持参考音色流式合成；
  • Talk 控件：语音/模型/灵敏度等实时默认值统一收在 Settings → Communications → Talk；composer 麦克风小箭头可选择任意浏览器音频输入；
  • Gateway TTS 播放：新增 operator 作用域 tts.speak RPC，远程客户端可获取整段内联音频。

八、移动端与桌面

  • Android：聊天界面内直接切换当前 agent（聊天、Talk、home canvas 保持同一会话）；fenced 代码块渲染 Kotlin/Swift/TS/JS/Python/Bash/JSON 主题色高亮；
  • iOS 离线聊天：预绘制近期会话与规范转录（受保护、有界、按网关缓存），离线时禁发、配对重置时清除缓存；
  • macOS app profiles：命名实例在状态、偏好、Keychain、Gateway 服务、重复实例所有权上完全隔离，宿主全局登录与 node 服务不受影响。

九、运维与生命周期

  • ⭐ 外部网关监管：OPENCLAW_SUPERVISOR_MODE=external 让 OCM 等生命周期所有者接管——保留验证重启与延迟行为，但不暴露原生服务权限，禁止原生服务变更与自更新，提供版本化原子重启交接契约；
  • ⭐ SQLite 快照：
  • Gateway 主机状态：Control UI Settings 直接显示所连网关的主机、网络地址、OS、运行时、uptime、CPU、内存、磁盘；
  • Workboard：请求级 --max-starts 覆盖默认派发上限，保留顺序启动与一人一卡保护；
  • Skill Workshop：agent 发起的 apply/reject/quarantine 默认不再需要额外审批（可 opt-in skills.workshop.approvalPolicy: "pending"）；新增手动”最新优先”历史扫描，把早期实质工作收敛为待定提案（即使关闭自主学习，也最多留 3 条）。

十、进阶使用建议

  1. 升级后先备份：openclaw backup sqlite create 跑一次，验证后再 openclaw update；
  2. 换 GPT-5.6 家族：新装默认 Sol + medium；老用户 /model 原子切换模型+运行时+思考强度；
  3. 给 Chrome 开 CDP 中继：配对 Chrome 后用 openclaw browser extension cdp 打印中继端点与鉴权头，chrome-devtools-mcp 直接驱动；
  4. 团队用 ClickClack / Slack：用原生命令菜单 + assistant 线程状态，反馈更顺滑；
  5. OCM 托管网关：设 OPENCLAW_SUPERVISOR_MODE=external，把生命周期交给外部监管而不暴露原生权限；
  6. 敏感环境：给共享 Secret 绑定精确出口主机，插件安装遇警示就用 --force 前先审来源。

总结

2026.8.1 是 OpenClaw 一次”模型、安全、界面、通道、运维”五线并进的升级：GPT-5.6 全系让推理底座一步到位；Secret 出口绑定 + 插件来源警示把安全边界收紧；Control UI 全面翻新（首启引导、在线名单、GitHub 预览、目录终端）让日常管理变舒服；外部监管 + SQLite 快照让生产部署敢用；Fish Audio 语音、Buzz/ClickClack 通道、移动端离线则继续扩展”所有聊天收进一个 OpenClaw”的版图。
